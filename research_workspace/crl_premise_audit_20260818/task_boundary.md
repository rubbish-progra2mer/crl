# 任务边界

- boundary_id: `CRL-PREMISE-BOUNDARY-001`
- accepted_task_setting: 评估大语言模型主研究者在论文知识库、代码工具和本地小实验支持下，长期发现并去风险研究实现种子的可行性。
- rejected_task_setting: 证明模型具有人类同等通用科研智能；评估其能否在消费级显卡上完成所有大规模训练；直接生成本项目下一篇论文的具体构思。
- accepted_input_output_scope: 输入包括公开实证研究、基准和 CRL 已明确的资源约束；输出包括前提分解、支持与反对证据、边界化结论、可证伪预测及对 CRL 设计的含义。
- excluded_subfields: 自动论文写作质量、学术伦理总论、实验室机器人、临床与生物湿实验自动化、通用人工智能意识问题。
- resource_notes: 本阶段只做外部调研与静态判断，不启动正式 CRL Run，不运行本地模型训练，不读取其他 Run 的科研材料。
