# v005 外部持留评价实现

本目录把 CEP 的最小效应契约编译器和匿名关系检测器用于苹果 ToolSandbox 固定提交 `165848b9a78cead7ca7fe7c89c688b58e6501219` 的联系人、消息与提醒工具。上游源文件、四份原始单元测试及许可证按 SHA-256 锁定；自定义 `tools/__init__.py` 只负责避免加载与本实验无关的网络工具，不改变被评价函数。

`run_external_evidence.py` 先运行四份上游测试文件，再执行持留评价。评价标签不是变体名称，而是候选状态差分是否等于同一声明调用在上游干净工具中的状态差分。五类故障算子在 v004 方法冻结后接入：固定目标、环境因素污染载荷、敏感输入引发额外效应、邻接额外同类效应、边界额外异类效应。三类边界为一一错误目标映射、双因素组合触发和共享状态下第二次调用触发。

十个 CEP 探针各自在独立重置克隆上只调用一次；`base_repeat` 是另一克隆上的同声明复测，不是共享状态的连续第二次调用。顺序边界由独立终局在一个共享上下文中连续调用两次后比较上游干净顺序差分。

公平的 `manual_metamorphic_same_information` 基线获得同一十个探针、同一匿名事件和人工写出的同一关系计划；程序强制核验它与编译计划逐字段相等。因此若两者检出相同，结果不支持 CEP 的检出率新颖性，只支持契约编译、不可辨识属性记录与精确覆盖记录这一窄协议增量。
