# 最近工作与组件级差异

## 最强碰撞结论

“对接口执行成对变形测试”不是本候选的新颖点。ARMeta 已从 OpenAPI 说明生成种子/后续调用并比较 HTTP 响应关系；SGVEF-LOOP 已为 MCP 智能体生成语义等价的任务对并比较轨迹稳定性。CEP 若要保留方法潜力，只能把贡献定义为：在工具接入边界，把声明的效应依赖关系编译为影子状态干预，并在匿名化副作用审计上生成带覆盖域的经验接入证书。

## 组件对照

| 最近工作 | 主要对象 | 实际改变的计算 | 与 CEP 重合 | CEP 剩余差异与上限 |
|---|---|---|---|---|
| ARMeta（Khan 等，2026） | OpenAPI 描述的 REST 接口 | 由多智能体生成 Given–When–Then 变形关系与可执行测试，比较种子/后续 HTTP 响应 | 都改变调用或接口状态并比较两次执行关系；它是最直接的软件测试祖先 | CEP 不生成通用接口测试或判断返回正确性；它检查“目标、载荷、环境秘密到副作用轨迹”的允许因果依赖，且审计目标/载荷只暴露稳定匿名令牌。若 ARMeta 获得同一效应审计、关系库和证书语义，它可承载这些测试，因此框架层新颖性不能声称 |
| SGVEF-LOOP（Liu 与 Zhang，ACL 2026） | MCP 智能体及工具转移图 | 生成语义相同、语言表面不同的任务对；期望相同工具轨迹与最终回答 | 都用变形关系和覆盖驱动思想评估工具系统 | SGVEF 固定意图和期望轨迹，测试智能体对语言噪声的稳定性；CEP 固定公开契约关系，干预真实调用参数/影子状态，测试不透明工具实现的副作用依赖 |
| ToolGate（Liu 等，Findings of ACL 2026） | 智能体的可信符号状态 | 前置条件门控调用，后置条件门控返回值入状态 | 都使用契约和运行时验证 | ToolGate 不发现遗漏效应；约四分之一无结构返回模式时后置条件为恒真，且调用后门不能撤销外部效应。CEP 只提供受限的经验效应证据，不能替代 ToolGate 的状态不变量 |
| Cordon（Chen 等，2026） | 多步工具任务的事务状态、外发效应与谱系 | 把可逆修改放入影子状态、外发动作放入发件箱，任务级验证后提交 | 都依赖影子执行、可观察效应和提交前边界；Cordon 已能从受控命令快照发现隐藏写入 | Cordon 只保证被事务运行时中介且可观察的操作，并要求框架映射工具到声明读写/效应。CEP 是接入时探测，不提供任务级事务、回滚或提交保证；它只在原始目标不可见时用成对依赖关系补充单轨迹检查 |
| Towards Practically-Secure Tools for AI Agents（Adam 等，EuroMLSys 2026） | 不受信任工具代码 | 静态发现效应，验证开发者植入的细粒度沙箱并执行上下文策略 | 都针对说明遗漏的工具副作用 | 该方法依赖源码、开发者配合、可信沙箱库与远程证明；CEP 面向源码不可见但有影子凭证与独立审计面的工具，代价是只有经验覆盖而无静态完备性 |
| Governed Individuation（Qin 等，2026） | 学习型智能体的权限上界 | 将执行映射到语义效应格并由固定权限顶限门控 | 都需要效应抽象而非工具名 | 该文明确未解决任意开放动作的可靠保守效应抽象；动态层逐原子效应拦截。CEP 试图产生受限经验抽象，但不提供保守或形式化保证 |

## 公平基线

当前本地实验没有把 ARMeta 或 Cordon 的完整系统作为可执行基线，因为它们的输入、目标和运行边界不同。取而代之的最近同信息计算基线是：

- 与 CEP 完全相同的10次系统探针，只检查每条轨迹的额外事件，不比较成对关系；
- 同样10次调用、同样匿名审计和关系判定器，但探针随机采样；
- 名义配置复测与文档信任。

这些基线只验证“关系检查”和“单因素编排”在当前受控问题中的增量，不能替代真实 REST/MCP 系统上的外部比较。

## 当前贡献上界

可交付的种子不是“新的通用变形测试框架”，而是一个更窄的方法核：

> 把工具效应契约写成因素到匿名审计字段的允许依赖图；通过同构影子账户上的单因素成对干预，验证目标响应性与非输入秘密不影响性；输出明确列出已测干预域的经验接入证书。

当前结果证明这个核在构造型、独立终局判定的范围内值得去真实服务上扩大；尚未证明自动从任意模式生成关系、处理非确定性、覆盖组合/顺序触发或胜过 ARMeta 的通用测试生成能力。
