# v007 最近工作与碰撞审计

检索与核对日期：2026-08-06。只把下列一手论文或官方规范用于方法定位。

## 1. 部分可观测运行时验证

[NuRV](https://link.springer.com/chapter/10.1007/978-3-030-32079-9_23) 从系统假设和线性时序逻辑性质生成在线/离线监控器；其基础工作 [Assumption-Based Runtime Verification with Partial Observability and Resets](https://link.springer.com/chapter/10.1007/978-3-030-32079-9_10) 对与观察一致的系统行为区分确定真、确定假、不确定和模型外。v007 按观察等价类收集所有隐藏世界真值，本质上属于同一条“部分观察下对可能世界求一致判定”的方法谱系。

结论：不能把“不可见时拒绝”“按观察闭包判断”或四值/不确定判定本身作为新颖点。v007 的区别只可能在更窄的工程组合：把工具效应合同、投影族、探针计划、不可识别见证、原始观察重算和接入授权统一为一种可消费工件。

## 2. 最强可监控后果

[The Best a Monitor Can Do](https://drops.dagstuhl.de/storage/00lipics/lipics-vol183-csl2021/LIPIcs.CSL.2021.7/LIPIcs.CSL.2021.7.pdf) 研究不可监控性质的最强可监控后果及最优监控器构造。其逻辑、分支时间语义和目标与 v007 的有限投影商不同，但已经占据“从不可监控规格提取最强可运行时判断部分”的高层方法空间。

结论：v007 不声称一般最优监控性；当前真值表只是有限投影族内的相对可靠且相对完备构造。

## 3. 多轨迹/超性质监控

[RVHyper](https://arxiv.org/abs/1906.00798) 以超线性时序逻辑描述跨多条轨迹的超性质，顺序处理轨迹并返回反例集合。v007 的成对探针关系同样跨执行比较，但表达力远弱于超线性时序逻辑，也未处理无限轨迹或轨迹存储优化。

结论：多探针关系、非干扰式关系和“反例由两世界组成”均不能单独支撑新颖性。

## 4. 黑盒规格监控

[SpecMon](https://arxiv.org/abs/2409.02918) 从网络与密码库插桩取得事件流，把观察匹配到形式规格允许的轨迹，并给出只接纳规格有效事件流的可靠性结论。它证明了“黑盒插桩—规格—可靠监控”已有成熟强基线。

结论：v007 的潜在差异不在黑盒监控，而在显式把观察投影不确定性和接入工件绑定纳入编译结果；扩大实验必须与直接观察规格检查和仅来源证明基线比较。

## 5. 证明与供应链来源

[in-toto](https://www.usenix.org/conference/usenixsecurity19/presentation/torres-arias) 用密码学元数据验证供应链步骤由正确主体按预期执行；[in-toto 官方文档](https://in-toto.readthedocs.io/en/stable/) 已有元数据、双重签名封装、步骤与检查模型。[SLSA 1.2 来源规范](https://slsa.dev/spec/v1.2/provenance) 明确把构建定义、运行细节和构建者身份置于可验证来源中。

结论：签名、主体绑定、随机数、过期和来源记录是必要可靠性修复，不是 v007 的方法新颖点。当前 HMAC 只是单域共享密钥原型，明显弱于公钥签名、透明日志和正式来源链。

## 6. 当前最近公平基线

1. 有限部分观察枚举监控：独立枚举隐藏赋值与投影映射后按观察分组；它与 v007 的语义目标最近。
2. 直接观察规格到测试：在观察令牌上直接执行同一公式，不做投影闭包。
3. 人工变形关系：人工计划同样的成对探针与关系判断；本版本没有独立人工作者，不能声称节省人工时间。
4. 仅来源证明：验证签发者、绑定和结构事件，不验证关系公式。
5. 全拒绝不可识别关系：安全但保守的下界。
6. 隐藏状态规格检查：使用服务真实状态的非公平上界，用于标签而非可部署基线。

## 7. 新颖性裁决前置结论

v007 修复了 v006 的可靠性缺陷，并能检验一个实用组合是否成立，但文献碰撞使高层方法新颖性显著收窄。只有当“工具效应合同到投影商监控、见证和可消费授权工件的统一编译”能够展示独立于现有部分可观测运行时验证与来源框架的必要计算或新评价现象时，才可能保留 CCF-B 方法潜力。单纯取得更高检出率、加签名或生成不可识别见证都不足够。
