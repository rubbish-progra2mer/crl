# v007 有限投影族编译的相对可靠性说明

## 1. 对象与边界

给定有限隐藏域上的合同公式 `φ`、合同声明的探针集合、目标/载荷投影族 `Π`，以及隐藏赋值 `v`。每个 `(v, π)` 产生一个观察签名 `o = Obsπ(v)`；`φ(v)` 是该隐藏世界中的合同真值。当前实现的公式只含字段相等/不等、有限常量以及 `and/or/not`，投影只含明文恒等、跨探针全局双射、探针局部双射和常量遮蔽。事件种类与数量要求明文可见。

这不是无限域、时间逻辑、异步收敛或任意程序上的定理。状态空间超过 200,000 个“隐藏赋值—投影映射”绑定时，编译器拒绝而不是近似。

## 2. 可识别性定义

对每个实际可达观察 `o` 定义：

`Truth(o) = { φ(v) | π ∈ Π 且 Obsπ(v) = o }`。

主张在该投影族下可识别，当且仅当每个非空 `Truth(o)` 都是单元素集合。若某个集合同时含真和假，则存在同观察、异真值的不可识别见证。

## 3. 编译算法

编译器穷举所有有限隐藏赋值和投影族映射，按观察签名分组：

- 若任一组同时含真和假，输出该组中规范排序后的真世界、假世界及重算得到的共享观察；
- 否则为每个观察输出唯一真值，组成真值表监控器；
- 结构主张只在事件元数据明文可见时编译；
- 最终计划要求合同主张被“可识别/不可识别”完备、互斥、无重复地两分。

## 4. 相对可靠性与相对完备性

**命题 1（监控器可靠性）**：若编译器输出监控器 `M`，则对任意声明域内的 `v, π`，`M(Obsπ(v)) = φ(v)`。

理由：编译器把所有 `(v, π)` 放入其唯一观察组。输出监控器意味着该组真值集合是单元素；表项就是该唯一值。

**命题 2（有限域相对完备性）**：在枚举器完整覆盖声明域和投影族、且未触发状态上限时，编译器输出监控器，当且仅当主张按第 2 节定义可识别；否则输出有效的同观察异真值见证。

理由：若所有组真值唯一，算法对每组生成表项；若有混合真值组，算法必遍历到，并从该组各取一个真/假绑定。反方向分别由单元素组和混合组定义直接得到。

**命题 3（消费端条件可靠性）**：若 HMAC 共享密钥未泄露、签发者受信、观察器诚实执行声明投影、随机数缓存持久且时钟判断正确，则接入者只会允许：合同/投影/计划绑定一致、计划规范重编译一致、原始观察重算报告一致、全部合同主张可识别且通过、工具身份与版本一致的记录。

这不是端到端真实性定理。受信观察器若对错误状态签发一份内部自洽的虚假观察，HMAC 只能证明“谁签了什么”，不能证明观察与隐藏状态相符；扩大实验把这种情况保留为反例。

## 5. 可机检不变量

- 合同与投影必须通过严格 UTF-8 规范 JSON 往返；
- `plan_hash`、`report_hash` 和签名分别从实际字段重算；
- 消费端重新编译计划并重新计算原始观察报告；
- 请求同时绑定工具、合同、投影、计划及非空所需主张集合；
- 证明绑定签发者、工具版本、合同、投影、计划、观察、报告、签发/过期时间和随机数；
- 随机数只在全部检查通过后写入重放缓存；
- 不可识别见证的值域、映射族、两个世界真值和声明共享观察全部独立重算。

## 6. 尚未证明

- 投影声明与真实观察器实现一致；
- HMAC 密钥分发、轮换、撤销、硬件保护或跨组织公钥信任链；
- 时间窗、重试、乱序和最终一致性的合同语义；
- 无限域的小模型界；本版本只有域大小 2、3 上的经验稳定性检查；
- 独立团队的合同编写遗漏率或人工维护成本。
