# 选题与转向记录

## 已放弃的宽路线

- 泛化的“事务式工具执行”已被 Cordon、Atomix 等最近工作直接覆盖，继续做提交/回滚框架缺乏足够差异。
- 基于模型审阅器的执行前危险判断已有 ToolSafe、AgentTrust 和 Reinforced Agent 等强近邻，且容易被相同信息与预算的审阅基线吸收。
- 单纯把工具契约加到智能体状态上已被 ToolGate 覆盖；其真正开放问题是契约不完整和外部副作用，而不是再增加一层术语。

## 当前选择

选择“对照效应探针证书”，因为它改变的是接入时的计算对象：从声明/单轨迹变为受控干预下的关系型效应轨迹，并且能在本机用独立事件账本直接反证。它的贡献上限明确受可复制性、可观察性和干预覆盖约束。

## 下一否决动作

先在独立生成的隐藏效应工具套件上比较同预算随机模糊测试。如果 CEP 的优势只来自使用了评测生成器的秘密触发词，或在未见工具族上明显消失，则杀死或大幅收缩当前候选，不把局部失败升级为整个 Run 失败。

## 实验后与最近工作复核

固定种子正式实验中，CEP 在3000个覆盖内实例上检出3000个；同预算随机关系模糊测试检出2061个；完全相同探针但去掉关系比较检出1800个。组合、顺序和不可观察三类各600个反例均未检出，因此主张收缩为单因素、可观察、近确定性工具。

随后检索到 ARMeta 与 SGVEF-LOOP。它们杀死了“接口/MCP 变形测试”这一宽新颖性说法，但没有直接吸收“匿名副作用审计上的允许依赖图 + 影子凭证接入证书”。当前选择继续准备受限 Seed；若 Reviewer 认为该剩余差异只是常规变形测试的领域实例，主研究者将据此判断是继续扩大真实服务实验还是杀死该方法谱系，而不伪称已证明通用新颖性。
