# v002 最近工作与剩余方法差异

## 不再声称的内容

对接口或模型上下文协议系统做成对变形测试并不新。ARMeta 已从 OpenAPI 说明生成种子/后续调用并比较 HTTP 响应；SGVEF-LOOP 已生成语义等价任务对并比较智能体工具轨迹。若通用变形测试框架取得同一副作用审计面、关系词汇和凭证语义，它可以承载 CEP 探针。

## 剩余方法核

CEP 的剩余差异被限制为一个工具接入协议：把公开效应契约编译为因素到匿名副作用字段的允许依赖；在同一匿名比较域的同构影子克隆上执行具体单因素对；输出只绑定精确测试集合、审计投影和见证的经验记录。

相对 ToolGate，CEP 位于契约门之前，寻找返回值后置条件看不到的受限副作用依赖，但不提供状态不变量。相对 Cordon，CEP 不提供事务、回滚或提交，只在接入阶段利用成对关系；Cordon 已能中介受控可观察效应。相对 Adam 等静态效应分析，CEP 面向源码不可见的远程工具，以经验覆盖换取适用性。相对 Governed Individuation，CEP 不声称产生保守效应抽象。

## v002 新增的可辨识边界

仅有实际目标的稳定匿名令牌时，观察者最多得到目标之间的相等关系。对任意非恒等一一映射 `g`，正确执行 `target=t` 与错误执行 `target=g(t)` 产生相同的“随输入变化”模式；未知匿名函数下，目标标签的置换无法由相等模式辨识。

因此 CEP 当前只证明目标响应性，不证明目标身份正确性。要验证身份，独立审计方必须额外给出声明目标和实际目标在同一匿名域中的参考令牌相等性，或提供等价的可信绑定证明。这个最小接口结论比“通用变形测试”更窄，也更可证伪。

## 当前贡献上限

可交付贡献是“匿名副作用依赖关系协议 + 明示不可辨识边界 + 精确覆盖凭证语义”的研究种子，而不是新的通用测试框架或安全证明。CCF-B 潜力取决于真实服务上能否自动编译关系、处理非确定性并在同观察面强基线上保留增益；若 ARMeta/Cordon 完全吸收，或影子克隆间无法建立可靠比较域，则该方法谱系应被放弃。
