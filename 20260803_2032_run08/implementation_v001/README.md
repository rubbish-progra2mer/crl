# CEP 实现说明

`cep_benchmark.py` 同时包含四个彼此隔离的逻辑面：

1. 不透明工具实现与隐藏变体；
2. 信任边界处的目标/载荷匿名化；
3. 只读取匿名审计事件的 CEP 与基线；
4. 读取原始终局和私有内部位的独立评估器。

CEP 的关系检查只有两类：不同声明目标应改变匿名目标令牌；未列为输入的环境秘密不应改变声明效应的匿名载荷令牌。直接出现额外主效应或未声明事件类型也形成见证。方法不分析源码，也不读取隐藏变体标签。

默认命令要求显式输出目录，固定公平预算为每工具10次影子调用。程序写出逐实例 CSV 和聚合 JSON，并把同一聚合 JSON 输出到标准输出。
