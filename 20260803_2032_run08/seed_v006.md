# 观察闭包效应证书：黑盒智能体工具的可辨识主张编译与失败关闭接入

## 摘要

黑盒智能体工具的上线审计面经常匿名化目标和载荷。此时，效应合同中“目标随声明改变”“实际目标就是声明目标”“载荷不受敏感输入影响”等主张并不都能从同一审计投影中判定。若规格到测试的编译器忽略这一点，它会把信息论上不可辨识的主张包装成看似通过的检查；run08 v005 的 `exact_primary_count=2` 静默漏检正暴露了“接受合同但没有生成义务”的具体危险。

本 Seed 提出**观察闭包效应证书**：输入一元工具副作用合同和审计投影类型，只为在观察等价类上真值恒定的主张生成关系探针；对真值不恒定的主张输出一对投影合法、观察相同而主张真值相反的隐藏世界；执行后签发绑定工具、合同、投影、探针、计划、证据和不可辨识见证的覆盖记录；接入消费者只接受属于合同、可辨识、已通过且全部绑定一致的请求。

正式验证穷举 864 种支持的合同—投影组合。候选与一个不导入候选实现、通过枚举隐藏输出和允许投影映射构造观察等价类的语义预言机比较 1,440 个主张，零分歧；576 份不可辨识见证全部有效；6,048 个陈旧绑定全部被拒绝。忽略投影的规格编译基线仅正确 864/1,440。苹果 ToolSandbox 固定提交上的四种结构不同合同和 23 个变体中，候选与同信息手写变形计划均为 23/23，并逐项产生相同报告。因此本 Seed 不主张新的变形关系或检出率优势；它保留的窄方法增量是“投影感知的主张闭包 + 反例见证 + 可消费证书”这一黑盒工具接入协议。

## 1. 问题定义

设一次工具调用的隐藏世界为 `w`，其中包含实际副作用的类型、数量、目标和载荷。审计方只看到投影：

```text
obs = π(w)
```

投影 `π` 可分别对目标与载荷采用：

- **明文可见**：观察令牌等于规范化隐藏值；
- **跨克隆稳定匿名**：存在对所有探针共享的未知一一重命名；
- **克隆局部匿名**：每个影子克隆可使用不同的一一重命名。

定义观察等价：

```text
w ≡π w'  当且仅当  π(w) = π(w')
```

合同主张 `φ` 在投影 `π` 下可辨识，当且仅当它在每个观察等价类中真值恒定：

```text
Identifiable(φ, π) ⇔ ∀w,w'. w ≡π w' → φ(w)=φ(w')
```

这个定义是部分可观察运行时验证和知识语义的专门化，不是本 Seed 的一般理论新颖性。研究问题是：能否把它落实成黑盒工具接入中的有限合同编译、可执行证据和失败关闭消费闭环。

## 2. 支持域与合同

本实现只接受一次探针调用恰有一个主效应的合同：

```text
C = (version, K, n=1, A, R_target, F_payload)
```

- `K`：主效应类型；
- `A`：允许的辅助效应类型集合；
- `R_target`：无目标义务、目标响应性或目标身份一致性；
- `F_payload`：载荷必须忽略的因素集合，当前为环境金丝雀、敏感输入的任意子集。

编译器对 `n≠1`、未知因素、重复声明、主效应同时作为辅助效应、空版本或未知投影直接失败关闭。它不再像 v005 那样“接受计数却不生成关系义务”。

数量恰一与辅助类型允许性由每个探针的事件集合直接检查。三类关系主张的闭包为：

| 主张 | 明文可见 | 跨克隆稳定匿名 | 克隆局部匿名 |
|---|---|---|---|
| 目标响应性：两个声明目标产生不同实际目标 | 可辨识 | 可辨识 | 不可辨识 |
| 目标身份：实际目标等于声明目标 | 可辨识 | 不可辨识 | 不可辨识 |
| 载荷对单一因素不变 | 可辨识 | 可辨识 | 不可辨识 |

稳定匿名的一一重命名保留相等/不等关系，却不保留与声明身份的同域相等；克隆局部匿名连跨探针相等关系也不保留。

## 3. 实际改变的计算

编译器不是为每个合同返回一个固定十探针模板，而是根据目标义务、载荷因素和投影生成不同探针目录、关系与计划散列：

1. 基础探针总是检查主效应精确计数和辅助效应白名单；
2. 可辨识的目标响应性生成两个只改变声明目标的探针及目标不等关系；
3. 可辨识的目标身份生成两个目标探针及逐探针期望身份关系；
4. 每个可辨识载荷因素生成一对只改变该因素的探针及载荷相等关系；
5. 不可辨识主张不生成伪检查，而是进入 `NonIdentifiabilityWitness`。

见证包含真世界、假世界、两边的隐藏输出、允许投影映射和共享观察。例如在克隆局部匿名下，“目标响应”真世界可以输出两个不同目标，但用独立重命名映射成相同观察；假世界输出同一目标，也产生同一观察。任何只看投影的检测器都无法区分这两者。

执行报告只汇总实际出现且关系通过的主张。证书状态为 `pass` 的必要条件是：探针完整、没有失败关系、合同没有不可辨识主张，并且合同全部主张均在已通过集合中。

## 4. 失败关闭证书消费者

覆盖记录绑定：模式版本、工具身份与版本、合同散列、投影散列、探针目录散列、计划散列、证据散列、合同主张、已通过/失败主张、不可辨识主张及其见证散列。消费者逐项核对接入请求，并拒绝：

- 任一身份、版本或散列不一致；
- 摘要不一致或未知记录模式；
- 记录状态不是通过；
- 空的必需主张集合；
- 合同外、不可辨识或未通过主张；
- 用一次调用证书要求身份、序列或复合触发等域外保证。

SHA-256 摘要只提供字节绑定与意外篡改检测。没有数字签名、签发者信任根、重放防护或远程证明，因此不能把当前记录称为抵抗恶意签发者的生产安全证书。

## 5. 方法独立的核心验证

### 5.1 独立有限语义预言机

独立预言机不导入候选编译器。它对二值隐藏输出和投影允许的一一映射进行穷举，以观察二元组为键分组，再检查每组内主张真值是否恒定。它还重新计算候选见证的投影范围、真/假真值和共享观察。

穷举空间为：2 种主效应类型 × 4 种辅助集合 × 3 种目标义务 × 4 种载荷因素集合 × 3 种目标可见性 × 3 种载荷可见性，共 864 种合同—投影组合。

| 指标 | 正式结果 |
|---|---:|
| 支持组合 / 唯一计划散列 | 864 / 864 |
| 候选—独立预言机主张比较 | 1,440 |
| 分歧 | 0 |
| 有效不可辨识见证 | 576 |
| 无不可辨识主张且允许接入 | 432 |
| 有不可辨识主张且拒绝接入 | 432 |
| 陈旧绑定拒绝 | 6,048 / 6,048 |
| 非一元合同拒绝 | 3 / 3 |

忽略观察投影的规格到关系基线在 1,440 个判断中正确 864 个；其余 576 个错误对应不可辨识主张。该基线只反证“无视投影仍可靠”，不代表所有规格测试或运行时验证系统。

### 5.2 契约差分与接入消费

13 个契约支持/拒绝用例全部正确；12 个主张—可见性判断与独立预言机全部一致；4 个历史故障回归全部命中。改变主效应类型、允许辅助效应、目标义务、载荷因素、投影和合同版本都会实际改变计划语义或绑定，非一元合同会实际拒绝。

17 个接入场景中，候选为 17/17；只看总通过位的消费者为 3/17；只核对绑定而不核对主张语义的消费者为 10/17。场景覆盖七类请求绑定变化、两类记录篡改、未知模式、空请求、失败证据、不可辨识合同及三类越界主张。

### 5.3 ToolSandbox 外部持留面板

评价固定苹果 ToolSandbox 提交 `165848b9a78cead7ca7fe7c89c688b58e6501219`。13 个上游文件散列匹配，四份上游原始测试与候选测试合计 30 项全部通过。四种结构不同合同为：

1. 联系人新增：目标响应性；
2. 消息发送：环境载荷不变性 + 允许联系人辅助效应；
3. 提醒修改：目标响应性 + 敏感输入载荷不变性 + 允许消息辅助效应；
4. 提醒新增：明文目标身份 + 两类载荷不变性。

23 个变体的正确标签由锁定上游干净工具的真实状态差分给出。候选和获得完全相同合同、投影、探针与观察信息的手写变形计划都正确 23/23；两者语义计划与最终报告逐项相同 23/23。16 个真实状态证书消费场景全部正确。

这一平局是重要负结果：关系检测可被公平手写变形测试完全表达，当前没有检出率新颖性。自动化是否降低人工遗漏或成本尚未测量。

## 6. 最近工作与主张边界

部分可观察运行时验证已经提供观察等价与知识/可监测性理论；超性质监测已经研究多轨迹性质；MR-Scout、规格驱动的仿真变形测试和 ARMeta 已覆盖从测试或规格生成变形关系；SPARK/Ada 工作已经从正式合同生成可追踪测试；ToolGate 用霍尔式合同门控工具调用和提交；SGVEF-LOOP 与 Cordon 分别覆盖模型上下文协议智能体评价和任务级语义事务。

因此可辩护的剩余增量只有一个专用组合：在源码不可见但有类型化匿名审计投影的工具上线场景中，把一元副作用合同编译成**观察上合法**的关系计划或反例见证，并让下游消费者只使用闭包内、证据绑定的主张。它不是一般可监测性理论、通用变形测试、新关系发现方法或运行时事务系统。

## 7. 最小可证伪主张

> 在本 Seed 明示的一元效应合同与三类有限投影域内，观察闭包编译器对 864 种合同—投影组合中的 1,440 个关系主张，与独立有限隐藏世界语义预言机零分歧，并为全部 576 个不可辨识主张产生有效的同观察、异真值见证；失败关闭消费者拒绝 6,048 个陈旧绑定。在 ToolSandbox 固定提交的四种结构不同合同和 23 个变体上，编译计划与同信息手写计划逐项相同并均正确 23/23。

该主张不包含：相对手写变形测试的检出优势、一般投影或任意合同、多主效应、序列/复合触发、异步/重试、随机工具、真实远程服务、自然缺陷、生产授权、恶意签发者认证或人工成本下降。

## 8. 局限、扩大实验与杀死条件

当前 ToolSandbox 的正确语义和实现来自上游，但合同映射、适配器与故障变体仍由本 Run 编写；独立语义预言机与候选虽然计算路径不同，仍共享本 Seed 的有限抽象。没有真实远程服务、独立团队适配器、自然缺陷或人因实验。

最有信息量的下一步是：冻结至少两个真实服务的审计适配器和合同，由独立实现者同时编写人工关系计划；比较遗漏率、编写/维护时间、投影声明错误、跨版本失效与接入拒绝；再扩展到有限序列合同，检验观察闭包和见证是否仍可计算。

出现任一情况应杀死或大幅改写本谱系：

1. 通用规格变形工具接收同一合同与投影后，无额外机制即可输出相同的闭包判定、反例见证和可消费记录；
2. 真实审计系统无法提供可验证的投影类型、事件完整性、调用归属或版本绑定；
3. 独立服务/适配器中，有限语义规则与真实可辨识性系统性分歧；
4. 人工计划的遗漏率和维护成本不劣于自动闭包，使协议组合没有实际收益；
5. 扩展到真实需要的序列/复合效应后，状态空间或投影语义使方法无法给出可用计划或见证。
