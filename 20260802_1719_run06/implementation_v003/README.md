# v003 来源绑定联合页链内核

## 输入边界

内核只接收外部验证的结构化主张，不接收自然语言主张。每个主张绑定：量词、谓词、联合范围单元、快照、起始游标和期望来源身份。

来源身份由四个不可为空的字段组成：连接器标识、查询签名、认证主体和范围模式版本。观察还绑定联合单元、当前游标、下一游标、记录、快照、状态、认证标志、权限完整标志和已知截断标志。

## 失败关闭规则

- 记录单元与观察单元不一致：该联合单元证据冲突，不能提供见证或完整覆盖。
- 页面的来源身份或快照与主张不一致：不能进入期望页链。
- 同一来源身份、联合单元、快照和游标出现不同页面摘要：证据冲突并返回未知。
- 游标循环、缺页、孤立页面、权限缺口、未认证页面或已知截断：不能形成完整覆盖。
- 不透明游标不比较大小，只沿精确的 `next_cursor` 声明追踪至可信终止。

存在真和全称假允许由来源绑定且范围内的可信记录早停。存在假和全称真要求主张的每个联合单元都具有完整的来源绑定页链。

## 独立验证

生产内核位于 `joint_coverage_kernel.py`。证书验证器位于 `independent_certificate_verifier.py`，不调用生产 `evaluate_claim()` 或 `_trace_cell()`，而是从证书规范重新检查来源、范围、快照、冲突、页链、见证和覆盖条件。

独立代码路径只能减少“求值器和验证器复用同一漏洞”的风险；它不是形式证明，也不能证明适配器、来源元数据或快照声明真实。
