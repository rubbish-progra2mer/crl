## Independent Opinion

# v005 独立评审报告

## 总体结论

建议**暂不交付 v005，继续同一 Run 修复并推进新科学版本**。

v005 对 v004 的单字段、单侧重标绕过进行了实质修复，但当前相关性定义缺少组合闭包，而且 `record_targets` 在外层键与载荷键冲突时没有明确规定“页面来源与快照”取自哪种表示。现有 81 项面板不能排除“两个表示分别在不同坐标偏离”的路由绕过。

## 主要优点

1. v004 的失败归因清楚，v005 确实改变了路由顺序和证书语义，不是仅增加测试。
2. 真实异源页、真实范围外页、记录反向归属、证书变异及输入顺序均有对照。
3. 证据边界总体诚实：

   - `audit_observation_digests` 只承诺求值输入多重集，没有声称外部日志完整；
   - 第二实现路径被准确限定为观察级第二实现，不是形式化证明或传输级真值裁决；
   - 26,460 回合回归被正确描述为干净行为与工具调用非回归；
   - 270.85/167.26 约为 1.62，宿主开销没有被工具调用数掩盖。

4. 最近工作和贡献上界较克制，没有把动态契约、完整查询或证书本身包装成新贡献。

## 核心漏洞：跨坐标分裂可绕过完整键并集

`targets(K,C)` 是多个坐标同时相等的合取条件。当前相关并集是：

```text
targets(K_outer,C)
OR targets(K_payload,C)
OR record_targets(o,C)
```

81 项核心矩阵主要覆盖“外层某一字段被改写、载荷键仍完整指向主张”；记录反向测试则覆盖“两个请求键自洽地指向范围外、记录指向范围内”。它没有覆盖这两类故障的组合：外层键在坐标甲偏离，载荷键在坐标乙偏离，导致两个完整 `targets` 同时为假。

### 最小两页构造

设主张为：

```text
来源 S，快照 σ，联合范围 U={B}
存在一条属于 B 且满足 P 的记录
```

所有未列字段均取正确期望值。

干净页 `o0`：

```text
K_outer  = (S, B, cursor=0, σ)
K_payload = (S, B, cursor=0, σ)
records = []
可信终止
```

冲突页 `o1`：

```text
K_outer  = (T, B, cursor=x, σ)   # 仅外层来源重标为 T
K_payload = (S, A, cursor=x, σ)  # 真实规范请求，A 不属于 U
records = [r]                    # r.unit=B 且 P(r)=真
可信终止
```

该构造保持：

- 规范载荷真实记录请求 `S/A`；
- 响应确实与该请求关联，没有伪造请求—响应配对；
- `r` 的记录归属 B 和快照 σ 真实；
- 完整输入同时包含 `o0`、`o1`；
- 外层错标正是方法声称要失败关闭的故障，而不是新增信任破坏。

按固定材料中“页面来源”的自然含义，即外层页面来源：

```text
targets(K_outer(o1),C)  = 假，因为来源为 T
targets(K_payload(o1),C) = 假，因为单元为 A
record_targets(o1,C)     = 假，因为页面来源为 T
```

于是 `o1` 被路由出相关集合，`K_outer != K_payload` 和 `record.unit != payload.unit` 都不会执行；其摘要也不会进入 `audit_observation_digests`。`o0` 随后可以错误认证“存在为假”，而记录 `r` 已使该主张为真。

若实际实现把 `record_targets` 的“页面来源”解释为载荷来源，则该实例可能被捕获；但五份固定材料没有给出这一决定性定义，81 项说明也只明确覆盖“两个请求键自洽地范围外、记录范围内”。因此当前 Seed 至少存在阻塞性的规范欠定义，不能凭报告计数排除上述错误认证。

## 证据与主张越界

1. “九类字段统一纳入”“已知不一致一律失败关闭”超过现有相关集合能够支持的范围。单字段覆盖不能推出跨坐标组合覆盖。
2. 第二验证路径共享同一相关性定义；若生产路径把 `o1` 判为无关，第二路径和多重集承诺可以一致地重复这一盲点。
3. 81 项、35 项和 26,460 回合均未在材料中显示上述分裂构造。输入正反顺序不能替代故障维度的组合覆盖。
4. `audit_observation_digests` 的外部完整性表述没有越界；问题是它只承诺“已被当前谓词判为相关”的观察，无法修复相关谓词本身的漏收。
5. 第二实现路径、回归用途和约 1.62 倍宿主开销的表述基本准确，无需因此降级。

## 必须修改项

1. 明确定义 `record_targets` 在两种请求表示冲突时，来源、快照和其他来源身份字段究竟取自外层、载荷、二者析取，还是独立记录级来源。
2. 让相关性对跨坐标分裂闭包，例如至少采用：

```text
(外层来源或载荷来源匹配 S)
AND (外层快照或载荷快照匹配 σ)
AND (外层单元、载荷单元或记录单元触及 U)
```

进入该保守包络后，只要两键不等或记录归属不等于请求单元，就返回 `UNKNOWN`。自洽的 T/T 异源页和 A/A 范围外页仍可忽略。
3. 增加上述精确两页实例及其镜像，至少覆盖：

   - 来源×单元、快照×单元以及来源身份字段×单元的分裂；
   - 存在假和全称真；
   - 两种输入顺序；
   - 规范载荷无法解析但记录侧可能相关的路径。

4. 用独立真值明确断言 `r` 已使存在主张为真，而不是只断言生产方法应返回未知。
5. 修复后重新生成证书、多重集、第二路径验证和三审；这属于核心相关性语义修改，应推进版本。

## 交付建议

当前问题是**阻塞本地种子交付的机制漏洞/规范缺口**，不是可以推迟到真实连接器阶段的扩大问题。建议保留 v005 Decision，继续修复后以新版本重新三审。

可信传输交换标识、只追加日志根、真实连接器故障率、自然语言编译、强动态契约基线和论文级新颖性仍属于下一阶段扩大事项；它们不应替代当前相关集合组合闭包的本地修复。
