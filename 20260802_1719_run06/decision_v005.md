## 最终裁决

我决定不交付 v005，完整保留本版本的 Seed、正式实验、固定送审材料、三份 Reviewer 报告与本 Decision，并继续同一 Run 推进 v006。

三名 fresh Reviewer 互不可见地审阅同一请求字节，三者一致指出：v005 虽修复了 v004 的单侧外层重标绕过，但相关集合仍没有对“外层键、规范载荷键和记录归属在多个坐标上交叉分裂”形成闭包；固定材料还欠缺非规范载荷组合分支及请求键语义唯一性的明确条件。

## 对评审意见的事实核验

我检查并直接调用了冻结的 v005 实现。v005 实际会捕获 Reviewer 示例中“外层来源错误、载荷单元范围外、记录单元范围内且载荷来源与快照均正确”的简单组合，因为实现分别用外层键和载荷键计算 `record_targets`。因此，该具体二坐标示例在实现中不是错误认证。

但是，更强的跨坐标分裂可以绕过实际实现。工作台构造如下：

- 当前主张为来源 `S`、快照 `s1`、范围 `{B}` 的存在主张；
- 干净观察以外层键和载荷键 `S/B/s1` 给出空终止页；
- 冲突观察的外层键给出期望来源 `S`、范围外单元 `A`、错误快照 `s2`；载荷键给出异源 `T`、范围外单元 `A`、期望快照 `s1`；页面含一条真实归属 `B` 且满足谓词的记录。

外层键因快照错误而不相关，载荷键因来源错误而不相关；v005 的两次 `record_targets` 也分别因快照或来源不匹配而为假。冲突页因此没有进入一致性检查或 `audit_observation_digests`。冻结实现返回 `FALSE`，该证书在加入冲突页后仍验证通过，而独立构造真值为 `TRUE`。

复现结果位于 `workbench_v005/v005-cross-coordinate-split-reproduction.json`，SHA-256 为 `83f66e727cd4aca79d94b3649792d718a44bdbadc638665145d25954236f94cd`；复现脚本 SHA-256 为 `2975d9f0eefadce4780a971cffa241c37c8bcad11ddf6a961573a045ef43e8b7`。

这证明 v005 的阻塞项不只是文字歧义，而是可执行的错误认证。81/81 攻击项、35/35 单元测试与 26,460 回合干净回归均未覆盖该交叉分裂，不能抵消这个反例。

## 对三份评审的处置

我接受三份报告关于“相关性分类必须先于不一致检查形成保守闭包”的共同结论，也接受以下两项边界修正：

1. `audit_observation_digests` 只能承诺被当前相关谓词选中的求值输入多重集；它既不证明外部输入完整，也不证明相关谓词完整。
2. 规范 JSON 的字节唯一性不等于连接器语义唯一性。请求键字段必须来自连接器级语义规范化映射；映射的正确性仍是条件声音性前提，必须登记而不能暗示已验证。

Reviewer 3 提出的“范围外请求＋范围内记录＋非规范载荷”在当前 Python 分支中会因外层来源、快照与记录侧共同命中而失败关闭，但固定规范没有无歧义说明此组合，也没有绑定的精确实验项。v006 仍须把解析失败定义为显式全状态，并以组合反例证明行为。

## v005 已经完成但不足以交付的工作

v005 确实把外层与载荷的九类请求字段校验移动到来源过滤、单元分桶、游标建链和见证早停之前；增加了请求范围与记录归属的双向冲突、相关输入摘要多重集、第二实现路径和大规模干净回归。它关闭了 v004 的已知单字段重标漏洞，并保留真正异源、真正范围外页面的可用性。

但这些结果只支持所列的单字段和单类组合构造。对多个坐标分别落在不同表示的情形，v005 仍可把待检查的不一致自身路由出检查域，因此不能称为条件声音的本地研究种子。

## v006 的明确修复目标

1. 将相关性改为逐坐标的“可能相关包络”：每个来源身份坐标、快照坐标和范围坐标分别在外层键、载荷键及适用的记录归属之间取保守析取，再对坐标组取合取；不能要求任一单独表示先完整命中主张。
2. 只要观察进入可能相关包络，外层键与载荷键不等、记录归属与载荷请求单元不等，或规范载荷解析失败，都必须返回 `UNKNOWN`，并进入审计输入多重集。
3. 对无法规范解析的已认证载荷给出完整规则和明确可用性代价；在没有独立可信路由包络时，采用不会产生错误认证的保守处理。
4. 把来源身份与范围字段的连接器级语义规范化版本纳入请求键，并明确登记“语义等价请求映射为唯一键”的条件声音性假设。
5. 增加交叉组合矩阵：来源身份字段×快照×范围、有效与无效载荷、请求范围外×记录范围内、存在与全称、正反输入顺序、旧证书重放、摘要隐藏与真正异源对照；每项必须有独立构造真值。
6. 生产路径与第二验证路径独立实现同一新包络；重新执行单元测试、攻击面板和固定 26,460 回合干净回归。
7. v006 准备交付时，必须由三名全新、互不可见、只读同一固定字节的 Reviewer 重新三审。

## 最终判断边界

本裁决是继续同一 Run，不是方向 No-Go。v005 揭示的是一个仍可在当前本地方法核中修复的组合闭包错误。可信交换标识、只追加外部日志根、真实连接器故障率、自然语言编译、强动态契约基线与论文级新颖性仍属于后续扩大问题，但不会被用来掩盖当前错误认证路径。
