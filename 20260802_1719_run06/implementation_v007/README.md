# v007 实现说明：全局一致性防火墙与语义—表示分离

本目录实现结构化列表连接器上的联合范围证据协议。v007 修复 v006 把表示版本字段用作相关性硬门而产生的绕过：所有保留且带证明的观察先经过全局内部一致性检查，只有通过后才允许做语义路由。

## 文件

- `joint_coverage_kernel.py`：生产求值、全局预检、语义路由、页链追踪、修复义务与证书模式 7。
- `independent_certificate_verifier.py`：不调用生产求值器或追踪器的第二实现路径；独立解析请求、重算全局预检、语义路由、页链和证书条件。
- `run_soundness_counterexamples.py`：166 个原始攻击、证书重放和可用性对照案例。
- `test_joint_coverage_kernel.py`：47 项单元与变形测试。
- `run_joint_coverage_experiment.py`：结构化半真实夹具与七方法回归。
- `compare_v006_v007_regression.py`：逐行比较 v006 与 v007 的配置、初始观察摘要和 13 个行为字段。
- `run_kernel_tests.py`：单元测试运行入口。

## 两层来源模型

`SourceIdentity` 在存储上包含七个字段，但 v007 明确分成两层：

```text
semantic_source = (
  connector_id,
  query_signature,
  authentication_subject
)

representation_metadata = (
  scope_schema_version,
  adapter_version,
  semantic_normalization_version,
  request_serialization_version
)
```

前三项用于判断来源语义是否可能属于同一主张；后四项只用于表示兼容性检查，不能把同语义来源的错配页静默路由出去。真实连接器中语义标识和规范化映射是否完整、唯一仍分别受 A018 与 A028 约束。

## 全局内部一致性防火墙

对求值器收到的每个 `attested=True` 观察，不先看它是否与当前主张相关，而是依次要求：

1. 请求载荷可按精确字段、类型和规范 JSON 字节解析；
2. 外层请求键与载荷请求键完全相等；
3. 每条解码记录的联合单元等于载荷请求单元。

任一观察违反任一条件，当前批次上的主张直接返回 `UNKNOWN`。因此内部损坏但真正异源的页也会污染无关主张，这是有意的安全—可用性选择。

只有整个输入多重集通过上述防火墙后，才计算：

```text
semantic_relevant(o, C) =
  semantic_source(o) = semantic_source(C)
  且 snapshot(o) = snapshot(C)
  且 cell(o) ∈ scope(C)
```

若语义相关但四类表示元数据任一不同，同样返回 `UNKNOWN`。只有语义来源、表示元数据、快照和单元全部兼容的页面可进入当前单元页链。自洽且真正异源的规范页不参与当前页链，但仍进入证书全局审计承诺。

## 证书模式 7

`audit_observation_digests` 是求值器收到的全部保留且带证明观察摘要的排序多重集，不再是相关性分类器的输出。加入任何新观察后旧证书都会失效，即使新观察自洽且语义异源。

这只承诺传入内核的多重集，不能证明调用前没有删页或采集层没有漏页；该风险仍是 A025。第二路径共享有限观察规范与数据类型，只能称为观察级第二实现验证，不能称为传输级独立真值或形式化证明。

## 外部事实前提

全局防火墙只能识别已经表示出来的内部不一致。若适配器把跨租户响应内部一致地解码为当前单元的阳性记录，或把未终止页面内部一致地标成终止，内核无法从同一观察模型恢复外部真相。

因此外部结论明确依赖 A031：请求—响应正确关联之后，记录内容、记录归属、快照、游标、终止、权限与截断元数据忠实反映连接器事实。还同时依赖 A017、A018、A023、A025 与 A028。

## 缓存与顺序

规范载荷解析、请求键和观察摘要只缓存由完整不可变输入决定的派生结果。测试覆盖缓存命中、未命中和容量为 2 的强制逐出，并与未缓存函数逐项比较；输入顺序成对攻击要求证书摘要一致。缓存不会保存主张相关性判定。
