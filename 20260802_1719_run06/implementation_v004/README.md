# v004 请求绑定联合页链内核

## 输入边界

内核只接收已经由外部验证的结构化主张。每个主张绑定量词、谓词、联合范围单元、快照、起始游标和期望来源身份；不负责把自然语言安全地编译成这些字段。

来源身份包含连接器标识、操作签名、认证主体、范围模式版本、适配器版本和请求序列化版本。每张观察页面另外保存规范请求载荷；载荷确定性包含具体实体、时间桶、归档状态、当前游标、快照以及全部来源身份字段。

## 请求绑定

生产追踪器根据主张、当前联合单元和当前游标重新构造规范请求载荷，并与观察保存的载荷做精确字节比较。空页面也必须通过该检查，因此不能只靠页面标注把“请求 A 的空响应”改称“请求 B 的空响应”。

同一期望来源、快照和联合单元中只要出现已认证但请求载荷不匹配的正常页面，该单元就被视为证据冲突。冲突在寻找早停见证之前处理；合法见证不能掩盖同游标冲突或错误绑定的续页。

## 失败关闭规则

- 请求载荷与主张、联合单元、游标或快照不一致：证据冲突并返回未知。
- 记录单元与页面单元不一致：证据冲突，不能提供见证或完整覆盖。
- 来源身份或快照不一致：不能补齐期望页链。
- 同游标存在不同页面摘要、游标循环、孤立页面、缺页、权限缺口、未认证页面或已知截断：不能形成完整覆盖。
- 不透明游标不比较大小，只沿精确的下一游标声明追踪到可信终止。

存在真和全称假允许由请求绑定、来源绑定且范围内的可信记录早停；存在假和全称真要求主张的每个联合单元都具有完整请求绑定页链。

## 证书复核

生产求值器位于 `joint_coverage_kernel.py`。`independent_certificate_verifier.py` 是第二条实现路径，不调用生产 `evaluate_claim()` 或 `_trace_cell()`；它从有限规范重新构造每单元请求载荷、来源过滤、冲突、游标闭合、见证和覆盖条件。

这只是归一化观察级证书的第二实现路径，不是对原始网络请求/响应的外部独立核验。两条路径仍共享数据类型和观察摘要接口，也依赖适配器如实记录实际请求。
