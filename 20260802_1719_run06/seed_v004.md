# 请求绑定的联合页链证据协议：面向大语言模型列表连接器的失败关闭执行与审计种子

## 交付定位

本版本在 v003 的来源绑定页链上补齐“具体请求参数”这一声音性条件：

> 对外部验证的结构化主张，每张用于见证或覆盖的页面必须同时绑定具体联合范围单元、游标、快照、来源身份、适配器版本和规范请求载荷；空响应不能脱离其实际请求被重新标注范围；任何已知绑定冲突都优先于见证并失败关闭。

这是一颗完成本地核心反例验证、值得进入真实连接器扩大阶段的窄系统研究种子。它不声称自然语言主张编译安全，不声称真实连接器或适配器可信，不声称提出新的查询完备性、有限访问、证明驱动规划、动态契约或验证侧车理论，也不声称论文级新颖性已经建立。

## 决定性故障

v003 把页链绑定到连接器、操作签名、认证主体、范围模式和快照，但操作签名在所有联合单元上相同，具体实体、时间桶与归档状态没有进入实际请求身份。

有记录的错标可能被记录单元检查发现，空响应却没有记录可交叉检查。冻结 v003 原实现重放“实际请求 A、观察标注 B 的空终止页”时，v003 为 B 返回 `FALSE`，生成联合范围覆盖证书，且原验证器判有效。该结果证明 v004 不是文案强化，而是修补一种会认证错误否定的表示与实现缺陷。

## 方法内核

### 结构化主张与来源身份

```text
Claim = (
  quantifier,
  predicate,
  joint_scope,
  snapshot_id,
  initial_cursor,
  expected_source_identity
)

SourceIdentity = (
  connector_id,
  operation_signature,
  authentication_subject,
  scope_schema_version,
  adapter_version,
  request_serialization_version
)
```

联合范围单元当前是实体、时间桶和归档状态的离散三元组。内核只支持有限范围上的存在量词与全称量词。

### 每页规范请求

对主张单元 `c`、游标 `u` 和快照 `s`，生产内核确定性构造：

```text
R(c,u,s) = canonical_json(
  connector_id,
  operation_signature,
  authentication_subject,
  filters = {entity, time_bucket, archive_state},
  cursor,
  snapshot_id,
  scope_schema_version,
  adapter_version,
  request_serialization_version
)
```

观察保存实际请求的规范载荷；追踪器根据主张重新计算 `R(c,u,s)` 并做精确字节比较。载荷本身及其 SHA-256 摘要进入观察摘要。请求绑定规则、来源身份、主张范围、快照和起始游标另形成请求绑定摘要，进入证书模式版本 4。

### 冲突优先的页链

每个联合单元只接受满足以下条件的页链：

- 来源身份与主张完全一致；
- 规范请求载荷与当前单元、游标和快照完全一致；
- 状态正常、已认证且权限范围声明完整；
- 页内每条记录的联合单元等于页面联合单元；
- 同一游标不存在不同页面摘要；
- 从起始游标沿精确下一游标声明可达终止；
- 游标无循环、没有孤立页面或已知截断。

错误请求绑定、记录错标、同游标冲突和孤立页面在扫描见证之前处理。因而一张合法见证不能掩盖同一单元中已经出现的已知矛盾证据。来源或快照不同的页面可以保留为审计输入，但不能补齐期望来源页链。

### 许可规则

- 存在真：至少一个请求绑定、来源绑定、范围内的可信记录满足谓词。
- 全称假：至少一个请求绑定、来源绑定、范围内的可信记录不满足谓词。
- 存在假：主张的每个联合单元都有完整请求绑定页链，且没有正面见证。
- 全称真：主张的每个联合单元都有完整请求绑定页链，且没有反例。
- 其他情况：`UNKNOWN`，并报告缺失、权限阻塞或证据冲突。

这是条件声音性而不是无条件事实保证。其前提包括：适配器如实记录实际出站请求；规范载荷覆盖全部响应语义参数；快照与权限声明真实；联合单元分区完备；结构化主张正确。假设账本 A017、A018、A021 仍为未验证。

## 第二证书验证路径

证书验证器位于独立文件，不调用生产 `evaluate_claim()` 或生产 `_trace_cell()`；它重新实现每单元请求载荷、请求绑定摘要、来源过滤、记录归属、冲突检测、不透明游标闭合、见证和覆盖证书检查。

24 项测试包含生产求值器被替换为抛出异常后仍可验证证书的检查。26 项反例还用变异证书攻击跨来源覆盖、隐藏冲突、循环、错误终止、错误单元绑定和范围外见证。

这里应准确称为“第二实现路径的归一化观察级证书复核”。它不是传输级外部独立验证：两条路径仍共享数据类型、观察摘要接口和有限规范，可能共享规范误解。

## 正式实验

- 实际请求 A、空页面标注 B；
- 跨连接器及混合操作、认证主体、范围模式续页；
- 同游标冲突和见证加冲突的双向排列；
- 见证后错误请求绑定续页；
- 合法不透明游标链与游标循环；

## 基线与贡献上界

`claim_aware_planner`、`dynamic_contract_with_executor` 与 `joint_coverage_gate` 共享同一个精确范围执行函数，所以完全等价不是三个独立系统的经验比较。v004 只证明请求绑定收紧了证据合法性且没有改变干净输入的查询行为，不能声称击败强动态契约或证明驱动规划器。

数据库先行工作已经覆盖有限访问下完整答案、访问限制与完整性约束、证明驱动计划、成本搜索以及结果有界接口；ToolGate 和 EG-VAR 已覆盖动态契约、提交验证、证明义务、证书和弃权。当前唯一可能的系统空间是：真实大语言模型列表连接器中，具体请求参数、默认范围、认证主体、快照和空响应如何形成可冻结、可审计的传输级证据。该空间尚未经过真实连接器实验，论文级新颖性未知。

## 已知边界

1. 可信适配器仍是根信任；同时伪造请求与响应超出当前检测能力。
2. 规范请求载荷可能遗漏真实接口的租户、区域、排序、隐式过滤器或特性开关。
3. 联合单元是否互斥、完备和可判定仍由范围模式承担。
4. 快照标识与权限完整声明的真实性未被独立验证。
5. 自然语言主张编译器尚未实现；危险缩小范围仍可能绕过内核。
6. 第二实现路径不是形式化证明或原始传输级独立核验。
7. 差集续查不是调用、延迟、字节或服务器工作量意义的成本最优计划。
8. 三个本地夹具不能估计真实故障频率、适配器成本或端到端效用。
9. 强动态契约与主张感知规划器尚未独立实现。

## 为什么值得继续扩大

v004 已把 v003 最危险的空响应错标漏洞转化为明确、可攻击、可失败关闭的请求绑定协议；又用见证加冲突、混合来源和证书变异补齐了顺序与复核边界，同时保持 26,460 行干净行为零回归。内核是否实现自身有限规范，已经有比 v003 更强的直接证据。

下一次决定性扩大不应继续堆叠模拟器，而应选择两至三个真实列表连接器，分别从可信传输日志与适配器输出采集请求/响应，冻结原始字节，独立标注自然语言主张、具体请求、可见范围与终局事实；并加入独立强动态契约、原生精确查询和原生优先回退系统。主要指标应为错误提交、未知率、请求绑定不一致检出率、延迟、字节、重试、人工标注一致性和适配器开发成本。

若真实接口无法提供可独立核验的请求与快照、请求绑定故障极少、自然语言范围编译错误占主导、强基线完全吸收贡献，或最近工作已覆盖相同传输级协议，则应收缩为连接器完备性审计基准，必要时终止方法主张。
