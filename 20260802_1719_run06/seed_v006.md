# 逐坐标可能相关包络：面向大语言模型列表连接器请求证据的失败关闭研究种子

## 交付定位

本版本把 v005 的“完整键相关并集”推进为“逐坐标可能相关包络”：

> 对外部验证的结构化主张，已认证观察不必由任一单独请求表示先完整匹配主张。只要期望来源身份的各坐标、期望快照和范围信号可以分别由外层键、规范载荷键或记录归属提供，该观察就必须在任何路由、页链构造和见证早停之前进入一致性检查；跨表示不一致、记录—请求不一致或非规范载荷一律失败关闭。

这是一个完成本地决定性反例验证、可进入真实连接器扩大阶段的窄系统研究种子。它不声称自然语言主张编译安全，不声称适配器声明等于传输事实，不声称请求—响应关联或外部输入完整性已经验证，不声称连接器语义规范化映射已经证明唯一，也不声称论文级新颖性已经建立。

## v005 为什么仍会错误认证

v005 分别要求外层键或载荷键在同一表示内同时匹配来源身份和快照，才让请求单元或记录单元进入相关集合。三名互不可见的 v005 Reviewer 一致指出，多种不一致可以分散在不同表示坐标上，使两套完整键同时不相关。

主研究者直接调用冻结 v005 原实现复现：主张为来源 `S`、快照 `s1`、范围 `{B}` 的存在主张；干净页 `S/B/s1` 为空且可信终止；冲突页的外层键提供来源 `S` 但快照为 `s2`，载荷键提供快照 `s1` 但来源为 `T`，两侧请求单元均为范围外 `A`，页面却含真实归属 `B` 的正面记录。

v005 把冲突页路由出相关集合，返回 `FALSE`；独立构造真值为 `TRUE`，证书有效，冲突页摘要未进入审计承诺。复现结果 SHA-256 为 `83f66e727cd4aca79d94b3649792d718a44bdbadc638665145d25954236f94cd`。因此 v006 改变的是相关性计算，不是增加测试数量。

## 方法内核

### 1. 请求身份与语义规范化版本

每张观察有外层请求键 `K_outer`，规范载荷严格解析为 `K_payload`：

```text
RequestKey = (
  connector_id, operation, authentication_subject,
  scope_schema_version, adapter_version,
  semantic_normalization_version,
  request_serialization_version,
  entity, time_bucket, archive_state,
  cursor, snapshot_id
)
```

规范 JSON 必须具有精确字段集合、非空字符串、字符串或整数游标，并以排序、紧凑规则重新序列化为相同字节。`semantic_normalization_version` 把连接器级规范化方案绑定进请求与证书，但不自动证明方案正确。

条件声音性要求 A028：在给定语义规范化版本下，连接器语义等价的请求映射为唯一键，非等价请求不共享键。大小写、统一码、端点、缺省参数和版本别名必须在真实连接器适配器中规范化并验证。

### 2. 逐坐标可能相关包络

令 `F` 为七个来源身份坐标，`U` 为主张联合范围。对规范可解析的观察：

```text
source_possible(o,C) =
  对每个 f∈F：
    K_outer(o).f = C.f
    或 K_payload(o).f = C.f

snapshot_possible(o,C) =
  K_outer(o).snapshot = C.snapshot
  或 K_payload(o).snapshot = C.snapshot

scope_possible(o,C) =
  K_outer(o).cell ∈ U
  或 K_payload(o).cell ∈ U
  或存在 r∈records(o)：r.cell ∈ U

possibly_relevant(o,C) =
  source_possible 且 snapshot_possible 且 scope_possible
```

这个定义允许来源、快照和范围信号来自不同表示，不再要求任一完整键先匹配。若两键完全相等，快速路径与上述一般公式等价：来源身份、快照必须完整匹配，范围信号可来自请求单元或记录单元。

### 3. 先一致性检查，后路由与见证

对进入可能相关包络的观察：

- `K_outer != K_payload`：整项主张返回 `UNKNOWN`；
- 任一 `record.cell != K_payload.cell`：整项主张返回 `UNKNOWN`；
- 载荷无法规范解析：进入显式错误状态并全局返回 `UNKNOWN`。

通过预检后，页链只按载荷键建链；来源、单元、快照、游标可达性、同游标唯一页面、记录归属、权限完整性、可信终止、循环、孤立页和已知截断仍按既有失败关闭规则处理。存在真与全称假可由范围内见证早停；存在假与全称真必须闭合全部联合单元。

### 4. 非规范载荷的可用性选择

若规范解析失败，就无法从载荷获得声音的路由键。v006 在没有独立可信路由包络的条件下采用最保守规则：任何已保留、已认证的非规范载荷污染当前批次中的所有主张。

这关闭“范围外请求＋范围内记录＋非规范载荷”错误认证，但真正异源的非规范页也会让无关主张返回 `UNKNOWN`。这是明确的可用性代价，不是免费安全收益；真实系统应通过可信传输路由或入口拒收非规范观察缩小污染域。

### 5. 证书模式 6

证书除证明页面摘要外，还包含当前可能相关谓词选中的观察摘要排序多重集 `audit_observation_digests`。第二实现路径独立解析规范载荷、重算逐坐标包络、页链与多重集，不调用生产求值器或生产追踪器。

这个字段只承诺“求值器收到且被当前谓词选中的观察”。它可以让加入已识别冲突页后的旧证书失效，但不能证明外部日志完整，也不能证明相关谓词一般完备。第二路径是观察级独立实现，不是形式化证明或传输级外部真值裁决。

## 核心主张与条件声音性边界

在以下前提下：

1. 结构化主张的来源、联合范围、谓词和快照真实；
2. 适配器按真实出站请求生成规范载荷（A017）；
3. 请求键覆盖全部响应语义参数（A018）；
4. 响应与所记录请求正确关联（A023）；
5. 求值器获得可信采集层的完整相关输入（A025）；
6. 语义等价请求映射为唯一规范键（A028）；

则对本地有限规范与所列攻击族，逐坐标包络能阻止已知外层/载荷/记录跨坐标分裂在一致性检查前被路由出去；任何已识别冲突均先于见证或否定认证使主张返回 `UNKNOWN`。

这不是对所有连接器故障的一般证明。两种表示若被同一不可信适配器一致伪造、响应被错配、语义参数遗漏、规范化映射错误，或输入页在进入内核前被删除，均超出当前证明能力。

- 150/150 通过；
- 错误认证提交 0；
- 其中 56 项为七个来源身份坐标×两种镜像分裂×存在/全称×两种顺序；

每个跨坐标存在项显式标注独立世界真值 `TRUE`，全称项标注 `FALSE`；生产路径均返回 `UNKNOWN`，第二路径验证新证书有效，正反输入顺序证书摘要一致。

### 26,460 回合同配置回归

正式尝试 `coordinate-closed-joint-coverage-756x5-r4-v006` 使用与 v005 完全相同的 3 个种子、每种子 18 个世界、756 个任务、5 档预算、7 种方法，共 26,460 回合：

## 贡献上界

当前可辩护贡献是一个窄而具体的系统机制：

1. 揭示“任一完整表示先相关”在冗余请求表示下的跨坐标闭包漏洞；
2. 提出外层键、载荷键和记录归属的逐坐标可能相关包络；
3. 将非规范载荷定义为显式全状态并量化其安全—可用性选择；
4. 把连接器语义规范化版本纳入请求和证书，同时明确唯一性仍是外部假设；
5. 用独立真值组合反例、第二实现路径、输入多重集证书和同配置逐行回归支撑本地方法核。

本版本没有证明优于动态契约、结果有界接口、证明驱动规划或验证侧车工作；实验中的 `dynamic_contract_with_executor`、`claim_aware_planner` 与联合覆盖门共享结构化执行器，不能作为独立强基线。论文级最近工作检索与新颖性碰撞检查仍需扩大。

## 下一阶段最有价值的扩大

1. 在至少两个真实列表连接器上实现并验证语义规范化映射，覆盖别名、缺省参数、租户、区域、排序和版本等价类。
2. 以可信交换标识绑定真实请求与响应原始字节摘要，并注入并发、重试、缓存错配和响应乱序。
3. 将输入多重集绑定到只追加日志根，验证调用者删页攻击。
4. 测量非规范异源页全局污染的真实发生率与可用性损失，并研究可信粗粒度路由包络。
5. 加入独立实现的动态契约/结果有界接口强基线和自然语言主张编译，重新评估端到端价值与论文级新颖性。
