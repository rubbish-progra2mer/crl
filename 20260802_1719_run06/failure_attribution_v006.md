# v006 失败归因与修复边界

## v005 的决定性错误认证

v005 在路由前分别计算：

```text
targets(K_outer,C) 或 record_targets(K_outer,C)
targets(K_payload,C) 或 record_targets(K_payload,C)
```

每个条件都要求同一完整键同时具有期望来源身份和期望快照。三名 v005 Reviewer 一致指出，这个“完整键并集”没有对跨坐标分裂形成闭包；Reviewer 还指出非规范载荷组合分支和请求键语义唯一性没有充分定义。

主研究者用冻结 v005 原实现构造更强反例：

- 主张：来源 `S`、快照 `s1`、范围 `{B}`，判断存在满足谓词的记录；
- 干净页：外层键与载荷键均为 `S/B/s1`，空页可信终止；
- 冲突页：外层键为来源 `S`、范围外 `A`、错误快照 `s2`；载荷键为异源 `T`、范围外 `A`、期望快照 `s1`；记录真实属于 `B` 且满足谓词。

外层键因快照错误而不相关，载荷键因来源错误而不相关；两次记录相关判断也分别失败。v005 返回 `FALSE`，独立构造真值为 `TRUE`，证书仍有效，冲突页摘要没有进入 `audit_observation_digests`。结果文件 `workbench_v005/v005-cross-coordinate-split-reproduction.json` 的 SHA-256 为 `83f66e727cd4aca79d94b3649792d718a44bdbadc638665145d25954236f94cd`。

因此，v005 的 81/81 攻击、35/35 测试和 26,460 行干净回归只证明所列构造，不能支持一般的跨表示失败关闭。`decision_v005.md` 已冻结该版本为不交付。

## 根因

一致性检查的入口仍依赖“任一表示先完整相关”。待检查的不一致可以把期望来源、快照和范围信号分散到不同表示或记录侧，使任何单独完整键都不匹配，从而在检查前把自身路由出去。

此外，规范 JSON 只保证字节唯一，不保证连接器语义等价请求的键唯一；大小写、统一码、端点、缺省参数或版本别名可能形成多个自洽键。这个问题不能靠本地解析器自动证明。

## v006 修复

### 逐坐标闭包

v006 对七个来源身份字段逐字段计算“外层等于期望或载荷等于期望”，对快照在两表示间取析取，对范围在外层单元、载荷单元和记录单元间取析取，再把三个坐标组取合取。进入这个可能相关包络后，两键不等或记录单元不等于载荷请求单元都会在分桶、建链和见证前失败关闭。

这不是把所有异源页都污染当前主张：两种表示自洽且来源身份确实异源的规范页仍不满足来源坐标包络；请求和记录均范围外的自洽规范页也不满足范围包络。

### 非规范载荷全状态

解析结果显式分为有效键与错误。没有独立可信路由键时，任何已保留、已认证但不能规范解析的观察被视为全局冲突。该规则关闭 Reviewer 3 的“范围外请求＋范围内记录＋非规范载荷”组合；代价是确实异源的非规范页也会让无关主张返回 `UNKNOWN`。正式面板把这一项标为可用性成本，而非安全收益。

### 语义规范化版本

`semantic_normalization_version` 被加入来源身份、规范载荷、观察摘要、请求绑定摘要和证书。版本变异会使原证书失效。但“语义等价请求映射为唯一键”仍是假设 A028，必须在真实连接器上验证。

## 性能失败与修复

v006 的第一版在每个单元追踪、证书生成和第二验证中重复扫描并解析同一观察集。正式大规模尝试 `coordinate-closed-joint-coverage-756x5-v006` 运行 1,297.44 秒后被主研究者终止；`runner_exit_code=4294967295`，没有结果文件，证据契约失败。

第一轮复用同次预检后，`coordinate-closed-joint-coverage-756x5-r2-v006` 仍运行 618.28 秒并被终止，同样没有结果文件且证据契约失败。这两次尝试只证明实现成本不可接受，不支持任何正确性或回归结论。

最终实现：

- 在同次求值、规划和第二验证内复用预检；
- 为冻结观察缓存来源键、载荷键和摘要；
- 为规范载荷解析与第二路径派生键使用容量 65,536 的缓存；
- 对两键相等的干净观察采用与一般公式等价的快速路径。

最终同配置 26,460 回合 Harness 时长为 39.13 秒；冻结 v005 为 270.85 秒。正式逐行比较在配置与 13 个行为字段上为零差异。初始观察摘要因新增语义规范化版本而有意变化，没有被伪装成相等。

## 仍未解决

1. 适配器规范载荷是否等于真实出站请求，仍是假设 A017。
2. 响应与记录请求在并发、重试和缓存下是否正确关联，仍是假设 A023。
3. 求值器输入是否来自完整、只追加的可信日志，仍是假设 A025。
4. 连接器级语义规范化是否唯一且完整，仍是假设 A028；规范化版本字段本身不能证明映射正确。
5. 非规范异源页全局污染的真实可用性损失尚未量化。
6. 真实接口中是否遗漏租户、区域、排序、隐式过滤器或特性开关，仍是假设 A018。
7. 第二实现路径共享观察数据模型和有限规范，不是形式化证明或传输级外部核验。
8. 真实连接器故障率、自然语言主张编译、强独立基线、端到端价值和论文级新颖性仍未建立。
