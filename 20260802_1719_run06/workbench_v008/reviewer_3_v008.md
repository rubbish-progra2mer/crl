## 独立评审结论

建议：**继续下一科学版本，不交付当前 v008。**

v008 已经显著修复 v007 的内部一致性漏洞：表示版本在任何语义路由前全局检查；所有已接收观察均进入审计；未证明观察触发保守拒绝；响应承诺覆盖请求、记录序列和分页状态；主实验与六个诊断样例的分母也被明确分离。这些改动使内核成为一个边界清楚、失败时保守拒绝的条件式证明原型，是本版最强价值。

但它仍缺少从“真实响应”到“可信承诺”的可执行信任桥。当前材料明确承认：真实连接器实验不是独立传输捕获、不是密码学日志，也不证明提供方事实；生产解码与审计投影仍在同一进程中完成。因此，v008 验证的是“给定承诺与规范化观察一致”，尚未验证“该承诺确实对应来源返回的完整原始响应”。

### 最小可复现攻击

设查询要证明单元格 B 中不存在满足谓词的记录。真实、已认证可见响应为：

```text
records = [r]
r.cell = B
r.matches = true
terminal = true
```

在进入内核前，错误解码器漏掉 `r`，构造：

```text
records = []
terminal = true
permission_complete = true
silently_truncated = false
attested = true
response_commitment = H(request, [], terminal, ...)
```

随后按该观察重新计算观察摘要和证书。只要响应承诺是基于漏记后的规范化列表生成，而不是由独立可信捕获层对原始响应签发，内核看到的字段全部自洽，仍可能给出否定认证。

这个构造：

- 不需要破坏 A025 所约束的查询范围或快照稳定性；
- 不需要破坏 A028 所约束的联合覆盖关系；
- 违反 A031 的无遗漏、字段与谓词保真前提；
- 若“可信承诺前提”包含独立、不可伪造、先于解码的原始响应承诺，它也违反该前提。

因此，这不是在完整授予 A031 和强可信承诺前提后的定理反例；但它揭示了当前可执行实现无法建立、也无法辨别这些关键前提。攻击中的错误解码器还可以替换为错误终止标记、错误权限完整标记或错误谓词分类，结果相同。

更直接地说，当前“已证明”仍主要是一个普通布尔字段。响应承诺没有外部签名、消息认证码、透明日志或可信清单根时，调用方能够同时重算承诺、观察摘要和证明输入。此时“一致”不等于“真实”。

### 证据与主张边界

180 个反例、55 个单元测试和 26,460 行模拟实验有力支持以下局部结论：在当前合成模型和已编码攻击族内，v008 未出现内部假认证，并保持了预承诺投影上的行为回归一致性。

它们不能支持：

- 对任意连接器实现不存在遗漏、注入或错误终止；
- 已证明全部真实分页响应被接收；
- 已证明谓词、单元格和权限语义忠实于来源；
- 当前响应承诺已经具备密码学真实性或不可重写性；
- 两个真实公开接口实验构成端到端否定认证验证。

真实连接器实验保存原始响应，并成功展示了承诺重算和事后变异检测，这具有集成价值；但只处理有限页面，且生产与审计路径同进程，不能排除共同模式的遗漏或错误解释。它证明的是页级一致性机制可运行，不是完整关系上的真实性或完备性。

因此，当前可守住的主张应严格限定为：

> 在所有接收输入都经过可信、无遗漏、语义保真的外部证明，并且响应承诺不可伪造、不可事后重签的前提下，v008 对表示不一致、未证明输入以及承诺后篡改采取全局保守拒绝。

若材料把这一条件式结论提升为“真实连接器否定认证已经闭合”，即构成越界。

### 必须修改项

下一版本至少需要：

1. 将响应承诺移出普通观察对象，由独立可信适配器对原始响应字节及关键传输元数据签发数字签名或消息认证码；验证密钥、签发策略和适配器版本必须绑定进主张与证书。
2. 承诺中绑定原始响应字节摘要、来源身份、请求身份、快照、游标、页序号、下一游标、状态、权限、截断标志，以及解码器版本或代码摘要。
3. 引入不可删页的会话清单或透明日志根，验证从起始游标到终止页的连续链，拒绝缺页、分叉、重复游标、伪终止和未登记响应。
4. 由独立验证路径从保存的原始字节重新解码记录，并检查记录多重集、字段、谓词、单元格和分页语义；不能仅比较同一进程生成的两个投影。
5. 新增并正式运行至少三类攻击：遗漏记录后重签承诺、伪造终止后重签承诺、篡改证明状态后重算观察摘要。目标不是把这些归类为“违反前提”，而是让实现能够拒绝它们。
6. 将真实连接器实验推进到完整分页会话，或使用具有已知真值和可控错误注入的签名连接器夹具；公开接口样例仍可保留为集成证据，但不得承担真值证明职责。

v008 已经把内核内部的约束做得相当扎实，剩余问题集中在信任根而非又一个局部路由补丁。正因为该缺口直接决定否定认证是否能从模型走向真实连接器，本评审建议继续下一科学版本。
