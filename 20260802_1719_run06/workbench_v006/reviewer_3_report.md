4. `semantic_normalization_version` 被明确描述为方案版本绑定，而不是唯一规范化的证明；A028 被保留为真实连接器上尚未验证的外部前提。

## 可复现核心漏洞

当前规格存在一个阻塞性的“规范化版本既是方案标签、又是相关性硬门”的矛盾。按文中“它只绑定方案版本”和“A028 仅在给定版本内成立”的解释，可以构造如下最小错误认证：

| 对象 | 关键内容 |
| --- | --- |
| 主张 `C` | 来源其余六坐标为 `S`，规范化版本 `v2`，快照 `s1`，联合范围 `{B}`，存在谓词 `P` |
| 干净观察 `o0` | 外层键＝载荷键＝`S/v2/B/s1`；空页、可信终止 |
| 冲突观察 `o1` 外层键 | `S/v1/B/s1` |
| 冲突观察 `o1` 载荷键 | `S/v1/A/s1`，其中 `A∉{B}` |
| 冲突记录 | `r.cell=B` 且 `P(r)=TRUE` |

`o1` 的载荷按 `v1` 严格规范解析。计算结果为：

- 规范化版本坐标上，外层键和载荷键都不是主张的 `v2`，所以 `source_possible=FALSE`；
- 快照可能相关为真；
- 外层单元和记录单元都是 `B`，所以范围可能相关为真；
- 最终 `possibly_relevant=FALSE`。

于是 `K_outer != K_payload` 和 `record.cell != K_payload.cell` 均不会执行，`o1` 的摘要也不会进入审计多重集。求值器只使用 `o0`，可认证存在主张为 `FALSE`；若 `v1`、`v2` 只是同一连接器语义的两代规范化方案，则真实 `B` 记录使真值为 `TRUE`。

该构造不需要删页，也不要求适配器同时伪造请求和响应：

- A017 可成立：载荷准确记录实际发出的 `v1/A` 请求；
- A018 可成立：请求语义参数完整；
- A023 可成立：响应确实绑定到该请求；返回范围外记录是本方法本来就要检测的记录—请求不一致，而不是响应错配；
- A025 可成立：`o0`、`o1` 都已交给求值器；
- A028 可成立：`v1`、`v2` 各自内部都有唯一规范键；文本没有规定跨版本唯一性。

若作者认为 `v1` 与 `v2` 天然属于两个互不相关的真值域，则这个反例不成立；但这意味着该字段不再“只是方案版本绑定”，而是结构化主张的语义/证据域边界。当前五份材料没有作出这一关键选择。

更一般地，当前包络只能关闭“每个期望坐标至少在一份表示中出现”的分裂。任一来源坐标在两键中共同偏离，就能让两键不等和记录—请求不一致先把自身路由出去。对于真正异源身份这可能正确；对于规范化版本等非语义方案元数据则不能直接推出安全忽略。

## 主张或证据越界

1. “跨表示不一致、记录—请求不一致一律失败关闭”必须限定为“已经进入可能相关包络的观察”。当前算法并不无条件检查所有记录—请求不一致。

2. A028 只解决单一版本内部的规范键唯一性。它既没有证明规范化正确，也没有定义跨版本等价请求如何处理。现有文案在这一点上仍有语义空洞。

3. 26,460 行比较排除原始观察摘要是可以理解的，但直接排除不能证明差异只来自新增版本字段。应比较删除该字段后的结构化投影，或验证新摘要恰好等于对旧观察加入预期字段后的重算值。“相同初始观察检查通过”也应说明实际比较了什么。

4. 缓存和快速路径目前只有文字声明及有限回归支撑。它们可作为本地实现证据，但不足以推出任意输入上的语义保持；尤其应明确缓存函数纯度、完整键组成、淘汰后重算等价性。

5. 五份绑定材料只提供结果摘要及结果文件哈希，未包含可逐项检查的攻击清单或原始结果。因此本评审只能确认计数和主张内部一致，不能独立确认 150 项确实覆盖了所称类别。

6. 审计摘要、第二实现路径和最近工作部分总体没有越界。论文级新颖性明确未建立，现阶段不应再扩大贡献措辞。

## 必须修改项

1. 明确定义规范化版本的语义：

   - 若它只是方案标签，应从“允许安全路由出去”的来源坐标中移出；至少在其余语义来源、快照和范围可能相关时，版本不一致必须触发 `UNKNOWN`。
   - 若它是硬证据域，则必须明确不同版本的观察不能影响彼此的真值，并把交付主张收缩为“版本域内声音性”，不能继续称其只是绑定元数据。

2. 加入上述 `v1/v2 + 外层 B + 载荷 A + B 记录` 的双量词、双顺序攻击，并同步覆盖生产求值、第二验证路径、旧证书失效及审计摘要。

3. 给出并验证核心桥接引理：在 A017、A018、A023、A025、A028 下，任何能够改变主张真值或构成冲突的观察都必然满足 `possibly_relevant`。当前材料只证明了公式捕获特定分裂，没有证明该桥接关系。

4. 将所有“一律失败关闭”的表述改成精确的条件表述；或者扩大预检，使表述真实成立。

5. 对回归中的观察摘要做可解释的结构化转换比较，而不是整列排除；补充缓存纯度与完整缓存键的可核查说明。
