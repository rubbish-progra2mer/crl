# 研究种子 v001：执行反事实计划缓存

英文名：Execution-Counterfactual Plan Cache（ECPC）

## 一句话结论

对大语言模型工具智能体的成功计划进行缓存时，不让文本相似度直接决定复用；先主动改变任务槽位并重放参考规划/执行，从规范化工具轨迹的敏感性中学习该缓存项的经验适用性签名，再把它作为复用提交门禁。

当前受控实验说明这项计算能够区分“只需重绑定参数”和“必须改变工具步骤”的文本近邻，值得进入现实基准；它尚未证明真实系统收益，也不能声称首创计划适用性或技能前置条件学习。

## 问题与价值

计划缓存试图复用既有成功轨迹，以降低智能体重复规划的时延和模型调用成本。直接近邻 P071 `Agentic Plan Caching` 已证明这一方向有明显效率价值，但也记录语义缓存的错误命中。对行动型智能体而言，错误命中不只是回答措辞变差：权限、时间范围、对象状态、确认策略或副作用语义的一处变化，可能要求不同工具步骤；旧计划若被直接提交，可能执行错误副作用。

现有文本相似度、关键词或意图分类回答的是“两个请求看起来是否相近”。ECPC 要回答的是更具体的操作问题：这条已经成功过的整段计划，在什么任务邻域里仍可复用？

## 方法核

设成功任务的槽位表示为 `z=(z1,...,zm)`，参考规划/执行产生工具轨迹 `τ`，缓存计划为 `π`。

### 写入期：主动估计复用边界

1. 从任务描述抽取有类型的任务槽位，并给出每个槽位的合法扰动域。
2. 对每个槽位生成单因素反事实 `do(zi←zi')`；若两个单因素都没有改变计划骨架，再对该对槽位生成有限成对反事实，以发现非加性交互。
3. 在同一工具、策略和环境版本的可重放沙箱中重新规划/执行反事实任务。
4. 将原轨迹和反事实轨迹规范化为：工具名序列、步骤间数据依赖、参数来自哪个任务槽位、终局状态类别。实现时允许声明语义等价的工具或子轨迹。
5. 按观测到的差分把槽位或交互记录为：
   - 结构敏感：变化会改变工具步骤或依赖；
   - 可重绑定：骨架不变，只需替换参数；
   - 守卫触发：变化要求额外校验、澄清或拒绝；
   - 探针域内惰性：在已测试扰动上没有可见影响。
6. 将这些条件、证据摘要、工具/环境版本和已知等价关系存成缓存项的经验适用性签名 `Aπ`。

### 读取期：召回与提交分离

文本或向量检索仍用于低成本召回候选计划，但不拥有提交权。新任务只有在结构/守卫条件满足、绑定槽位可安全重绑定、版本相容时才复用 `π`；否则退回重新规划。

这使缓存成为两阶段决策：相似度优化召回，执行证据约束选择性风险。

## 与最近工作的真实差异

### 与大语言模型计划复用系统

- P071 `Agentic Plan Caching`：成功轨迹抽象为计划模板和关键词，再做匹配与轻量适配。ECPC 不替代其模板化或召回，可作为命中后的提交门禁；差异在门禁证据来自任务干预后的实际轨迹敏感性。
- `AgentReuse`（arXiv:2512.21309）：以意图分类判断请求相似性。ECPC 保留意图分类作为召回基线，但不让意图等价直接推出计划等价。

### 与技能契约和主动技能建模

- `SkillOps`（arXiv:2605.13716）已经用类型化技能契约和前置条件过滤技能，`ContractSkill`（arXiv:2603.20340）已经把网页技能表示为可验证、可修复的显式过程契约。因此“给技能加前置条件/契约”不是本种子的贡献。
- `SkillWrapper`（arXiv:2511.18203）已经主动采集黑盒机器人技能数据，并学习具有前置条件和效果的可规划符号模型。因此“主动执行以发现技能适用条件”也不是本种子的贡献。
- ECPC 的剩余差异很窄：对象是文本工具智能体的一条已成功整段计划；干预变量是自然语言任务槽位；观测量是多步工具轨迹骨架、依赖和绑定；输出不是完整世界模型或规划算子，而是这个缓存项的经验提交门禁。

### 与反事实轨迹审计及经典计划复用

- `Counterfactual Trace Auditing of LLM Agent Skills`（arXiv:2605.11946）固定任务，比较带技能与不带技能的轨迹，以审计技能影响。ECPC 固定缓存计划来源，改变任务槽位，以估计复用适用域。
- 案例式规划早已研究旧计划的检索、适配、验证和复杂度；例如 `Parameterized Complexity Results for Plan Reuse`（AAAI 2013）。ECPC 不声称发明计划复用或适用性，只是在缺少完整符号域模型的文本工具智能体中，用受控执行学习一个缓存提交近似。

如果后续公平比较表明上述差异只是把 SkillWrapper 式主动技能建模平移到计划缓存、没有产生独特难题或收益，则应终止该方向，而不是扩大措辞。

## 可证伪主张

在任务槽位可抽取、参考规划可在沙箱重放、工具轨迹可规范化的文本工具工作流中，对召回到的缓存计划使用由槽位干预与轨迹差分得到的经验门禁，有望：

1. 比只依赖关键词、意图或文本相似度更少接受“文本相近但工具骨架不兼容”的任务；
2. 比所有非惰性槽位都要求精确相等的保守键保留更多安全复用；
3. 把单因素探针漏掉的部分交互失败暴露给成对探针。

主张限定为经验风险—覆盖权衡，不包含形式完备性、开放世界安全保证或对现有完整系统的优越性。

### 记录与数据

- 正式尝试：`experiment_v001/attempts/ecpc-controlled-001`
- 固定随机种子：`20260802`

- 实现 SHA-256：`efbc2607fbc8d2d133a80ecb6f0e9649ccba4642cf17127dfc9a2b076d6b38df`
- 正式结果 SHA-256：`285ba3313c462766c9f721b08e901fcd233d0f597eef5375f0e9aeaf8a313978`
- 数据对象 SHA-256：`d189837f6469c2ec7732a61d422ed44969d441dc136e7d9f67a5d910408f2a91`
- 八个确定性合成工具工作流、128 条请求；固定测试集 96 条，其中安全可复用 46 条、不安全 50 条。
- 本机 Ollama `bge-m3:latest` 生成嵌入，`qwen3:8b` 做槽位抽取和直接复用判断；没有付费外部接口。

每个领域的成对签名需要 55 次概念性参考重放：1 次基准、13 次单因素、41 次成对探针。这一成本本身是方法的关键负担。

|---|---:|---:|---:|---:|
| 意图关键词 | 100.0% | 100.0% | 52.08 | 96 |
| 词频—逆文档频率相似度 | 60.87% | 36.0% | 39.13 | 46 |
| BGE-M3 语义嵌入 | 4.35% | 14.0% | 77.78 | 9 |
| 人工部分键 | 100.0% | 38.0% | 29.23 | 65 |
| 所有非惰性槽位精确匹配 | 28.26% | 0.0% | 0.0 | 13 |
| 单因素 ECPC，真值槽位 | 100.0% | 8.0% | 8.0 | 50 |
| 成对 ECPC，真值槽位 | 100.0% | 0.0% | 0.0 | 46 |
| 成对 ECPC，千问槽位 | 100.0% | 4.0% | 4.17 | 48 |
| 千问直接判断 | 41.30% | 6.0% | 13.64 | 22 |

相似度阈值仅在 32 条校准集上按“安全召回率减三倍不安全接受率”选择。BGE-M3 的低召回不能解释为该模型的一般能力结论；在这组近邻上，其连续分数受试者工作特征曲线下面积为 0.5257，词频—逆文档频率为 0.5704。

### 实验支持什么

1. 单因素真值签名漏掉四个双因素交互案例，直接证伪“单因素探针已经足够”。
2. 成对真值签名在构造内把 46 个安全样本全部接受、50 个不安全样本全部拒绝，说明该门禁实现与预设机制一致。
3. 千问槽位抽取总体槽位准确率 99.74%、完整请求准确率 97.66%；端到端仍错误接受两条银行转账请求，均与 `notify` 槽位误解析有关。执行签名不能消除上游语义解析错误。
4. 全槽位精确匹配无错误命中，但只接受 13/46 个安全请求；受控结果展示了“识别可重绑定槽位”可能带来的覆盖收益。

### 实验不支持什么

- 生成器和签名构造器共享同一确定性工作流规格，真值结果是机制一致性检查，不是外部泛化。
- 没有在 FinanceBench、应用世界、真实网页或其他公开智能体基准上评估。
- 没有直接复现 P071、SkillOps、ContractSkill 或 SkillWrapper；不能宣称击败它们。
- 没有证明开放表达下的槽位抽取可靠，也没有覆盖三阶以上交互。
- 没有解决语义等价但表面不同的工具轨迹、不可重放副作用、工具版本漂移或分布变化。
- 没有证明 55 次/领域的离线探针能由后续复用次数摊销。

## 为什么仍值得扩大

这个种子尚有方法潜力，不是因为合成表格中的完美数字，而是因为它把计划缓存的核心错误从“相似度不准”改写为可测试的选择性决策：召回候选后，必须用与实际工具计算相关的证据决定提交。受控实验同时给出正结果和一个明确反例——单因素不够——因此后续可以围绕风险、覆盖、探针成本和交互阶数形成可证伪研究，而不是只换嵌入模型。

## 下一轮实验路线

1. 选择一个具有可重放工具状态和近邻任务变体的真实文本工具基准；优先考察 P071 使用的工作负载能否复现，并补充应用世界一类有状态环境。
2. 公平实现 P071 式模板检索/适配、AgentReuse 式意图判断、SkillOps 式显式前置条件过滤、直接大模型判断和全槽位精确键；统一召回候选、模型预算和风险代价。
3. 把测试集按“绑定变化、单因素结构变化、守卫变化、交互变化、措辞改写”分层，报告选择性风险—覆盖曲线，而非单阈值准确率。
4. 用自适应探针替代完整二次枚举：先按风险和因果依赖选择交互，再以新增拒绝边界/重放成本衡量价值。
5. 学习或声明等价工具轨迹，并把终局、副作用和依赖一致性纳入规范化，检验结构差分假阳性。
6. 做工具版本和策略文档漂移实验，验证何时必须使适用性签名失效。
7. 记录单个缓存项的写入成本、复用次数与避免的规划成本，寻找真正可摊销的任务重复区间。

## 终止条件

出现任一情况应停止扩大：

- 在现实基准上，控制相同安全召回后，ECPC 相对强意图/契约基线不能稳定降低不安全接受；
- 主要收益可由少量人工风险字段或现有技能前置条件直接获得；
- 轨迹等价和槽位抽取误差使门禁收益消失；
- 为发现交互所需的沙箱重放成本无法在现实复用频率下摊销；
- 与 SkillWrapper 或其他最近方法公平对照后，只剩应用对象替换，没有独立计算问题。
