# 运行内失败归因 v001

## 临时运行失败一：成对枚举中的重复替换

首次临时运行在签名构造阶段以 `StopIteration` 退出。原因是成对枚举把两个各自已经改变轨迹的槽位也组合起来，而两个规则都试图替换同一个原工具步骤。修正为：只有两个单因素探针都保持基准骨架时，才继续执行交互探针。该失败没有生成正式结果，也没有进入支撑 attempt。

## 临时运行失败二：Ollama 残留嵌入运行器

一次 256 文本的单批嵌入请求使 BGE-M3 内部推理端口退出，但 Ollama 仍把模型显示为已加载；后续请求返回 HTTP 400 和内部端口连接拒绝。小请求在卸载重载后成功，完整单批会再次触发。实现因此改为每批 32 条，并在结果记录八次嵌入调用。之后临时重放和正式 attempt 均成功。

这些是实现/运行时失败，不支持或反驳科学 Claim；保留它们是为了同一 Run 内避免重复踩坑。
