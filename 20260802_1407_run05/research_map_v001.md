# 研究地图 v001

## 直接问题链

- P071，`Agentic Plan Caching`（NeurIPS 2025）：成功轨迹抽象为计划模板，按关键词检索并适配；知识库证据 `ev-p071-plan-template-reuse`。论文同时记录语义缓存错误命中与完整历史复用噪声；知识库证据 `ev-p071-cache-false-positive-boundary`。
- `AgentReuse`（arXiv:2512.21309）：以意图分类评估请求相似性并复用计划，属于文本/意图判别。
- `Evaluating Temporal Semantic Caching...`（arXiv:2605.20630）：把时间、资产、传感器等指定参数纳入时间语义缓存键，属于人工预定义字段的失效策略。
- `RunAgent`（arXiv:2605.00798）：逐步推导和验证自然语言计划约束，但不从任务反事实执行生成缓存项的适用域。

## 契约、技能抽象与行为审计链

- `SkillOps`（arXiv:2605.13716）：类型化技能契约与前置条件过滤，占用“用契约门禁技能复用”的宽主张。
- `ContractSkill`（arXiv:2603.20340）：把网页技能变成带显式过程结构、前置/后置条件、恢复和终止检查的可验证、可修复制品，占用“显式技能前置条件”的宽主张。
- `SkillWrapper`（arXiv:2511.18203）：主动采集黑盒机器人技能数据并学习可规划的符号前置条件与效果，是“主动执行发现适用条件”的最强机制近邻。
- `Counterfactual Trace Auditing`（arXiv:2605.11946）：在同任务上比较带技能与不带技能的轨迹以刻画技能影响；其干预量是技能存在性，不是任务槽位。
- 案例式规划和计划适配早已研究旧计划的检索、适用性、修改和复杂度；`Parameterized Complexity Results for Plan Reuse`（AAAI 2013）是明确边界参照。

## 跨领域算子链

- P098，`Beyond Objective Equivalence...`：单实例目标等价会漏掉非绑定约束；7347 个样本中有 550 个通过差分测试却被约束注入抓出。知识库证据 `ev-p098-nonbinding-blindness`、`ev-p098-diff-leak-550`。
- P097，`ReLoop`：本应影响行为的参数产生零敏感性，可提示候选计算漏掉该因素。知识库证据 `ev-p097-behavioral-perturbation`。
- P101，`Semantic Evaluation for Text-to-SQL with Distilled Test Suites`：以单点邻居定义覆盖目标并蒸馏判别测试。知识库证据 `ev-p101-neighbor-distillation`。

## 剩余方法空间

宽主张已被占用：计划复用、显式前置条件、技能契约、主动学习黑盒技能条件、反事实比较轨迹均非新概念。当前只保留一个组合后的窄计算对象：

1. 对象是文本工具智能体的一条已成功“整段缓存计划”，不是原子机器人技能或通用技能库；
2. 写入缓存时从任务文本提取槽位，主动构造单因素和有限成对近邻；
3. 对参考规划/执行进行沙箱重放，规范化多步工具名、依赖边、参数绑定和终局；
4. 将观测到的结构敏感性压缩为该缓存项的经验适用性签名；
5. 读取缓存时文本相似度只召回，签名负责提交或退回重新规划。

该组合是否足以构成 CCF-B 方法贡献仍需现实基准、强基线和成本控制证明；当前检索只说明未发现同构实现，不能解释为穷尽性新颖性证明。

## 关键风险

1. SkillWrapper 说明主动技能模型学习已有深厚基础，若 ECPC 不能证明“整段工具计划缓存”带来独特问题与收益，可能只是领域迁移。
2. 生成反事实依赖可控环境，二次探针成本可能抵消缓存收益。
3. 轨迹变化不等于计划语义变化；等价工具路径会造成假拒绝。
4. 自然语言槽位抽取可能成为共同误读点。
5. 合成生成器与签名构造器共享规格会产生构造内优势。
6. 三阶以上交互、工具版本漂移与不可重放副作用尚未处理。
