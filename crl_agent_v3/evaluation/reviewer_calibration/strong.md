# CALIBRATION PACKET: STRONG

## 1. Implementation / Seed Overview
实现研究长时工具智能体在不可逆操作前的错误承诺问题。候选把“执行后自检”改为“执行前证据差异门”：只有计划所依赖的关键事实没有被两个信息来源独立支持时，才暂停执行并调用验证器。机制主张限定为：在相同模型、工具和总预算下，执行前的信息独立性检查减少由单一错误观测导致的不可逆失败。

## 2. Closest Prior Evidence
材料逐项比较三个合成最近工作：P-A 做执行后反思，P-B 在每一步固定验证，P-C 对检索置信度加阈值。对比表明确列出触发时点、可用信息、额外计算、是否检查来源独立性和失败边界。检索覆盖标题、摘要、全文关键词和给定引用邻域，并诚实保留 P-C 可能部分吸收阈值组件的风险；主张差异集中在执行前的来源独立性计算，而不是“增加验证模块”。

## 3. Core Experimental Evidence
600 个保留样本覆盖三个合成任务域，参考标签由与方法构造无关的双人盲评和仲裁产生。五个预注册随机种子下，候选不可逆失败率均低于三个强基线；材料给出逐域、逐种子、置信区间、效应量、逐样本输出和原始统计脚本哈希。主要指标和停止条件在运行前固定。

## 4. Baseline & Budget Facts
所有系统使用同一模型快照、工具、可见信息、最大调用数、令牌上限和调参预算。固定验证基线可以消费候选未使用的剩余调用；同时报告调用数、令牌、墙钟、图形处理器时间和费用。另有等成本、等调用和等延迟三个视角，结果方向一致。

## 5. Ablation / Robustness / Falsification Evidence
完成去除来源独立性检查、只用置信度、执行后检查、随机触发、伪造相关双来源和高置信错误压力测试。候选在相关双来源条件下优势消失，符合预先声明的机制失效条件；跨两个模型规模和两个预算区间方向一致。材料列出尚未覆盖的真实生产域。

## 6. Reproducibility Facts
提供实现清单、代码哈希、环境锁、命令、配置、数据与划分哈希、评价脚本、原始输出、聚合脚本、硬件和运行成本。关键表格中的每个数字都能追到正式执行记录和原始文件哈希。

## 7. Known Limitations
证据仍限于合成工具任务和一个模型家族；真实组织权限、长周期漂移及人工操作成本尚未验证。主张未外推到开放网络智能体或所有错误类型。
