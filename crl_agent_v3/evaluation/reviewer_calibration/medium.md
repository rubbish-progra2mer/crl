# CALIBRATION PACKET: MEDIUM

## 1. Implementation / Seed Overview
实现针对合成工具路由任务：基础智能体先给出工具选择及置信度；只有置信度低于开发集阈值时，第二次调用独立提示的验证器，再由固定规则选择最终工具。主张限定为“在相同两次调用上限内，条件验证比始终单次路由更可靠”。

## 2. Closest Prior Evidence
材料比较了两个合成最近工作：P-A 始终调用验证器，P-B 让同一模型自由反思。当前差异是按预先阈值在决策后、执行前触发结构化验证。检索只覆盖 12 个给定条目，没有引用邻域扩展，也未充分排除其他条件计算工作。

## 3. Core Experimental Evidence
120 个保留测试样本具有独立人工标签。三个随机种子的准确率为候选 67/69/69%，同调用上限基线 62/64/63%。报告了逐种子结果和原始结果哈希，但没有置信区间；只覆盖一个合成任务域。

## 4. Baseline & Budget Facts
候选与主要基线使用相同模型、相同工具集合、两次调用上限和 4000 令牌上限。候选的阈值在开发集调节；材料没有说明基线获得了多少调参机会。墙钟时间和费用未记录。

## 5. Ablation / Robustness / Falsification Evidence
给出了“关闭验证器”和“随机触发验证器”两个消融，二者低于条件触发。没有跨模型测试、阈值敏感性、负控制或专门构造的高置信错误压力测试。

## 6. Reproducibility Facts
提供代码哈希、运行命令、配置、数据划分哈希和逐样本输出哈希。缺少依赖锁文件和完整硬件信息。

## 7. Known Limitations
最近工作覆盖有限；仅一个合成任务域；基线调参公平性、统计不确定性和边界压力测试不足。
