# Main Codex Nearest Prior Record

## External closest composition

P085, *Retrieval Models Aren't Tool-Savvy: Benchmarking Tool Retrieval for Large Language Models*, is mandatory. It creates a target-aware instruction from target-tool functionality and compares retrieval with and without that instruction. It does not report a same-source label-disjoint wrong-target donor distribution.

The successful v004 search record covered recent tool-retrieval systems, target-aware tool retrieval, retrieval label leakage, clarification, negative controls, and the local knowledge base. It found no exact ToolRet implementation combining aligned instructions, matched wrong-target controls, two retrieval families, and source-cluster Confirmation. This is bounded search evidence, not proof of novelty.

## Collision boundaries

- Negative controls, permutation logic, BM25, MiniLM, NDCG, and bootstrap are established components and are not claimed as inventions.
- Target-aware query enrichment comes directly from P085 and is not claimed as new.
- The proposed contribution is the ToolRet-specific donor-ensemble audit protocol, provenance-complete runnable implementation, and source-cluster interpretation boundary.
- No claim is made that three donors are statistically optimal or causally identify a latent instruction effect.
