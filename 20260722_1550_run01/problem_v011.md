# Research Problem

## User intent

Complete the commissioning Run with a real, falsifiable implementation, untouched Confirmation, three independent leaf Reviewers, and a Main Codex decision. A failed version must remain frozen and the same Run must continue.

## Text/tool LLM Agent scope

The target is compact-menu function selection under semantically related tool expansion. The immediate result variable is top-1 membership of a ground-truth function and best-gold MRR, not JSON validity, argument correctness, execution success, or end-to-end Agent success.

## Soft constraints

Prefer a small local computation that uses the fixed Python 3.11.15 shared environment and RTX 5060 Ti. Use the existing frozen cross-encoder and public BFCL/P084 bytes. Avoid paid APIs, new model generation, and broad engineering.

## Hard exclusions

- No TPPA, lexical-scope feature retuning, threshold retuning, or reuse of undocumented trajectory rewards.
- No fixture sanity as research or Delivery evidence.
- No non-Reviewer subagent.
- No access to the pinned Confirmation bytes before a successful Development capture and Main Codex Promotion Audit.
- No claim beyond the measured ranking result on the pinned datasets.

## Cost authorization

No paid API is authorized. The experiment may use only the shared local interpreter, local GPU, frozen model bytes, and deterministic CPU optimization.
