qrel/target-doc-derived oracle artifact。\n\n约 9.5% 的 instruction 直接含 target `name/api_name`：\n\n- Development：96/1,000\n- Confirmation：95/1,000\n\n其余 prompts 即使不逐字复制名称，也可能是 target descriptions `set(tokenize(query))`。instruction 中已经出现在 recipient query 的词不会再次增加 BM25 score；冻结 lexical support 却把 instruction 的所有词都计入，包括这些重复词。因此预注册 mechanism signature 不是实际 BM25 增量词机制。\n\n只计算 instruction-exclusive-to-query terms 后，aligned-minus-wrong lexical support 仍为正，但显著缩小：\n\n- Development：`0.10391`\n- Confirmation：`0.09767`\n\n同时，query 自身对 target docs 的 lexical support 高于 aligned instruction：\n\n- Development：aligned instruction `0.27336`，query `0.30366`\n- Confirmation：aligned instruction `0.27044`，query `0.31264`\n\n正的 exclusive delta 是支持性证据，但不能修复 control composition 与 oracle construction，因此不足以证明冻结机制 Claim。\n\n### 4.4 Confirmation 不是内容独立的复制，且研究路径存在 optional stopping\n\nDevelopment/Confirmation 没有精确重复 query 或 instruction，但 corpus 内容显著重叠：\n\n- 两 corpus 交集 4,978
