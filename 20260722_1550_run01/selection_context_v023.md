# Selection Context v023

v022 is closed after a real Confirmation failure. Its signed same-task-reference representation may not be retuned, and Terminal Wrench buckets 2 and 3 may never again serve as prospective Confirmation. They are now exposed Development material.

v023 selects a scientifically different, reference-free computation: Action–Observation Role Factorization (`AORF`). The current sparse mixed-text detector assigns one coefficient to the same n-gram whether it appears in a command or in terminal feedback. AORF uses one shared vocabulary but separate command and output coefficient blocks:

```text
x = mixed command/output trajectory
c = commands only
o = terminal outputs only
AORF = [x,c,o]
```

This is not a GRU, phase split, same-task residual, rule detector or prompt intervention. It is a controlled representation test. Three 90,000-dimensional controls—`[x,x,x]`, `[x,c,c]`, and `[x,o,o]`—separate role factorization from capacity and duplication.

Development combines the already exposed bucket-2 and bucket-3 datasets at the same Terminal Wrench commit. Bucket 0 (81 task IDs by tree-name hash only) is the sole prospective Confirmation and no bucket-0 metadata or trajectory byte has been acquired. Bucket 1 remains unused.
