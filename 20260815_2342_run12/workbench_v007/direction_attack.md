# v007 方向先行攻击：依赖路径核验布置

## 初始构想

在有限核验预算下，把工具轨迹表示为从不可靠工具效果到不可逆动作汇点的有向依赖图；选择最小成本的一组独立状态见证，使每条不可靠源到关键汇点的路径至少被一个见证覆盖，未找到可行覆盖时阻断提交。

## 已确认的直接邻居

1. **Sherlock（arXiv:2511.00330）**已经把代理工作流表示为图，在 15,000 余条执行轨迹上做反事实故障注入，估计节点对最终输出的脆弱性；运行时在预算内按终点、起点和汇入度选择核验节点，并学习任务条件下成本最优的核验器。它已经占据“一般工作流图＋全局预算＋选择性节点核验＋成本—正确性权衡”。
2. **Delayed Verification / Optimal Corrector Placement（arXiv:2606.27409）**已经在多智能体图上研究有限纠错器预算的最优布置，并给出超模目标与贪心近似保证；其作者也明确把这一步定位为经典网络控制中领导节点选择的移植。它不处理严格有向工具管线、外部状态效果或动作提交门。
3. **MAP-Graph（arXiv:2608.10509）**沿共享记忆祖先图计算路径信任，并在动作前用固定规则和风险阈值返回允许、阻断、重核验、删改或询问用户。其正文没有全局核验预算或最小割优化，但已占据“祖先依赖图＋动作时门控”。
4. **GRADE（arXiv:2606.22741）**区分观测、声明、推断三类依赖边，证明弱推断层会退化为运行长度，并把“在观测到的依赖失效前检查”列为开放问题。它提供图表征，不提供核验选择器。
5. **AgentTether（arXiv:2607.06273）**用关键转移图定位失败子轨迹，并在失败后的重执行中对工具返回与文本响应做局部检查—决策—注入；它不是首次执行前的全路径状态见证布置。
6. **GLOVE（arXiv:2601.19249）**在记忆与新观察冲突时主动重复同一状态—动作，并给出单对局部样本预算；它不在一条任务依赖图上分配全局核验预算。

## 经典归约攻击

- 2014 年 SACMAT 论文 *Monitor Placement for Large-Scale Systems* 已把有向数据流图中所有违规源—汇路径上的最小成本中介器布置定义为有向多割，并用各单割解的并集求解。普通“所有路径至少过一个核验点”在结构上就是这一旧问题。
- 2016 年 INFOCOM 工作 *Robust monitor placement for network tomography in dynamic networks* 已在多个可能拓扑下求最少监视器，归约为广义击中集，并讨论不可预测拓扑变化及布置成本—适配成本权衡。普通“对观测/声明/推断边做鲁棒割”也不是新算法问题。
- 网络监视、攻击图防御、传感器布置和主动感知都已有预算、拓扑不确定性与逐步探测；把最小割改名为“核验割”不能形成方法新颖性。

## 普通版本的判定

**淘汰**：不得把固定依赖图上的最小节点割、风险加权割、鲁棒多拓扑割、一般监视器布置或一般主动感知写成新贡献。

## 仅存的窄差分

保留的候选不是核验语言模型节点输出，而是核验**外部工具效果**：

- 图节点显式区分响应通道、效果状态、派生前提与不可逆提交；边来自工具契约和运行时资源读写，而不是自然语言相似度。
- 候选核验动作必须是与被核验写操作独立的效果见证，返回外部状态谓词；一个见证只覆盖其可观察的谓词，不能因为位于拓扑下游就自动覆盖隐藏前提。
- 选择目标是最低成本地覆盖所有“未见证效果前提→不可逆提交”路径；预算不足或不存在覆盖时，提交门必须阻断，而不是选择风险最高的若干节点后继续。
- 这与 Sherlock 的差分是**证据语义和安全约束**：Sherlock 优化期望最终准确率并核验工作流节点输出；本候选要求真实效果见证形成提交前覆盖证书。

## 退化与杀死条件

1. 若存在一个廉价、完备、独立的最终状态核验器，则最优解总是汇点单检，本候选退化为 ToolGate/Verified Tool Calls 的最终后置条件检查。
2. 若实际任务中候选见证不能机械声明可观察谓词，选择器只能依赖大语言模型猜测覆盖关系，则安全证书失效。
3. 若与 Sherlock 在相同成本和相同核验器集合下没有稳定安全优势，或优势只来自把正确答案写入契约，则淘汰。
4. 若所有路径覆盖的安全优势只在按构造必胜的合成图上出现，不能在至少两个有状态工具域和两个本地模型的真实动作选择中复现，则淘汰。
5. 若经典中介器布置可在不增加任何代理特有语义的情况下逐项映射全部变量、约束、输出和评价，则只剩工程移植，不交付。

## 下一步

登记 `h-009` 后先做两级杀手试验：

1. **退化扫描**：在终点完备可见、终点部分可见、仅上游可见三种可观测性下，比较最小见证覆盖与终点单检；若多数可执行任务都落入完备终点格，停止。
2. **预算等价试验**：构造多分支有状态工具任务，让本地 qwen3:4b/8b 在同一调用预算下分别接受无门控、Sherlock 式拓扑优先、风险前若干、随机、全量核验和效果见证覆盖策略。机械评分危险提交率、真实成功率、核验成本、阻断率和覆盖证书有效率。
