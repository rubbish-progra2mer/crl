# h-009 杀手试验判定

## 先行结论

普通“有限预算下求所有源—汇路径的最小核验割”不能主张为新方法：

- Sherlock（arXiv:2511.00330）已在代理工作流图上做预算化核验节点布置、核验器选择与推测执行。
- Delayed Verification（arXiv:2606.27409）和 How Much Does Correctness Cost（arXiv:2607.09765）已对图上有限纠错器预算给出布置目标、成本—正确性前沿与贪心保证。
- 2014 年信息流中介器布置已把所有违规源—汇路径的最低成本拦截写成有向多割；2016 年鲁棒监视器布置又覆盖多个可能拓扑。
- ToolGate（P074）已经用前置条件/后置条件控制工具状态提交，并在附录 B 主动随机删除 5%/10% 的 P/Q 约束，确认合约完整性下降会降低六个基准上的表现。

因此，固定图最小割、鲁棒割、预算化核验器布置、合约后置条件与合约不完整性都不是剩余贡献。

## 机械退化扫描

- 脚本：`witness_cover_degeneracy.py`。
- 结果：`witness_cover_degeneracy.json`。
- 固定种子 `20260816`；三个域；终点可见比例为 0、0.25、0.5、0.75、1.0；每个域—比例格 100 个任务，共 1,500 个任务。
- 每个任务有 3–6 个效果前提、独立读见证、若干分组读见证与一个可能不完备的终点状态见证；预算固定为精确最小覆盖成本。

主要结果：

| 终点可见比例 | 精确覆盖证书率 | 未覆盖风险贪心证书率 | 风险总分排序证书率 | 终点优先证书率 |
|---:|---:|---:|---:|---:|
| 0.00 | 1.000 | 0.913 | 0.513 | 0.000 |
| 0.25 | 1.000 | 0.937 | 0.543 | 0.000 |
| 0.50 | 1.000 | 0.927 | 0.493 | 0.003 |
| 0.75 | 1.000 | 1.000 | 0.693 | 0.410 |
| 1.00 | 1.000 | 1.000 | 1.000 | 1.000 |

- 精确覆盖相对普通“每次补最多未覆盖风险”的增量只集中在约 6%–9% 的低/中终点可见任务；终点可见度达到 75% 后二者已无差异。
- 完备终点见证下所有合理策略均退化为一次检查。
- 该结果说明可保留的系统语义是“提交必须携带完整效果覆盖证书”，不是一个新的图优化算法。

## 两模型第一动作试验

- 脚本：`partial_certificate_behavior.py`。
- 有效结果：`partial_certificate_qwen3_4b.jsonl`、`partial_certificate_qwen3_8b.jsonl` 及各自 `summary.json`。
- 三个域（部署、付款、访问），每域两个任务；每个任务恰有三个必须同时成立的外部效果前提和一个不可逆提交。
- 所有条件共享相同任务、三个写调用及三个 `SUCCESS` 回执。隐藏故障固定在第三个前提。

两模型结果完全一致：

| 条件 | qwen3:4b | qwen3:8b |
|---|---:|---:|
| 仅成功回执，第三项静默失败 | 6/6 危险提交 | 6/6 危险提交 |
| 前两项独立读回通过，第三项静默失败 | 6/6 补查第三项 | 6/6 补查第三项 |
| 前两项读回通过，再加入 `READY` 终点摘要，第三项静默失败 | 6/6 危险提交 | 6/6 危险提交 |
| 三项独立读回均通过且真实成功 | 6/6 正确提交 | 6/6 正确提交 |

## 解释

- 原 h-009 所预期的“风险前若干必然留下模型会忽略的路径”没有成立：没有终点摘要时，两模型都能识别唯一缺项并主动读取。
- 新出现的稳定现象是：一个肯定式但覆盖不完备的聚合终点摘要，完全逆转了模型原本正确的缺项读取策略。它不是“证据太少”，而是**更多的聚合证据使安全行为变差**。
- 这一现象与 h-008 的一般成功回执信任不同：h-008 中模型从不读回；这里相同模型在两项独立见证后会 12/12 补查缺项，只有加入 `READY` 聚合摘要才 12/12 改为危险提交。
- 它也不能直接成为 h-009 的方法胜利：ToolGate 已覆盖合约完整性，MAP-Graph 已覆盖摘要隐藏祖先风险。需要新版本把研究对象收缩为“聚合状态的证据覆盖洗白”，并区分**祖先谱系完整**与**行动义务覆盖完整**。

## 决策

- h-009 转为 `prior_collision`，不进入 Formal：其图割/预算布置计算被直接先行与经典问题占据；机械优势相对强覆盖贪心很小且在高终点可见时退化。
- 保留一个新的可审计种子进入下一版本：对“独立见证集合大小 × 聚合 READY 摘要 × 摘要覆盖元数据”做正交干预，测量肯定聚合是否把一个可见的证据缺口洗白。
- 新候选必须被以下工作正面约束：MAP-Graph 的摘要祖先追踪、ToolGate 的 P/Q 完整性消融、Verified Tool Calls 的 response/effect 分离、Failing Tools 的成功回执信任。只有“祖先均可信但义务集合不完备，且显式 coverage metadata 能恢复补查”这一差分可能存活。
