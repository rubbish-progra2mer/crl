## 主研究者终局裁决

本 Run 在“文本与工具型大语言模型智能体”的 Charter 内，经过四个科学版本的真实回溯与正交扩张后，未得到一颗在当前可访问文献、知识库、本地模型与计算资源下仍具有可辩护 CCF-B 论文潜力、且值得进入扩大验证的研究种子。因此，本 Run 以资源有界的 `CONCLUDED_NO_DELIVERY` 结束。

这不是对整个智能体领域、未来新数据或未来新机制的否定，也不主张已穷尽所有可能方向。结论只约束 Run `20260815_2342_run12` 的 Charter、截至 2026-08-16 可访问的证据与本次实际计算边界。

## 实际搜索与转向覆盖

本 Run 从工具执行可信性出发，随后依次跨越五类结构不同的问题与贡献载体：工具回执/状态更新稳健性、来源相关的虚假佐证、黑盒工具行为探查与路由、计划缓存的结构反事实评价、不可逆动作的信息就绪性调度。它们分别涉及现象、评价、路由方法与执行调度，并非在单一候选附近改提示词或调参数。

Run-local 终局诊断记录了 4 个科学版本、6 次结构化检索、6 个候选；检索指纹无重复。候选状态分布为 4 个 `prior_collision`、2 个 `falsified`，当前版本没有活动候选。完整诊断是只陈述事实的非权威材料，终局判断由主研究者在阅读各候选、先行审计和实验结果后作出。

## 正式反证的决定性证据

`formal-cache-003` 是本 Run 唯一进入正式支持级验证的候选实验。运行器成功完成 128 次本地模型调用，覆盖 `qwen3:4b` 与 `qwen3:8b`，输出、指标和独立机械评分契约均有效，无超时或实验错误。

预注册主张要求总体缓存诱发失败率至少为 0.10、两个模型分层都大于 0，并要求安全命中缓存正确率不低于反事实缓存正确率。实际结果为：

- 总体缓存诱发失败率 0.0417；
- `qwen3:4b` 为 0.0833，`qwen3:8b` 为 0；
- 安全命中缓存正确率 0.875，低于反事实缓存正确率 0.9583；
- 反事实任务中从头规划正确率 0.50，缓存适配正确率 0.9583。

因此不能把探索性小样本中的个别动作删除或顺序翻转失败缩窄包装为论文级稳定现象，也不能据此主张新的缓存安全评价必要性。

## 为什么此处是 Run 级 No-Go

在 h-005 被正式反证后，本 Run 没有停留在缓存方向，而是推进到 v004，转向执行调度与不可逆提交这一不同的干预位置。对 h-006 的组件级最近先行攻击表明：任何当前可运行的合成实验，即使得到正结果，也只会再次证明已知依赖顺序或写前验证的价值；最强的静态读前写基线或经典数据流调度足以成为杀死性替代解释。此时继续做本地小实验不能产生能够区分新计算的高信息量证据。

其余已死亡方向也没有留下当前资源内可执行、且失败会大幅改变论文级剩余差分的杀手实验：h-001、h-002、h-004 是直接或构造性先行碰撞；h-003 的目标因果差分在两模型成对试验中为 0；h-005 已由有效正式实验反证。继续推进只能依赖尚未取得的真实生产工具血缘与故障遥测、真实计划缓存系统及自然任务分布，或一个尚未形成的新计算机制。它们是未来重开条件，不是当前可辩护的活动路线。

## 评审与审计边界

没有启动固定三审。CRL 只在准备交付研究种子时要求三个全新独立 Reviewer；Run-level No-Go 不要求 Seed、实验或 Review。本 Run 没有可提交 Seed，伪造评审或为了满足形式而送审已死亡候选都不成立。

终局诊断的全文检索组成状态为 `READY`，未发现跨 Run 污染；语义召回未启用并以 `DEGRADED` 记录，不被用作终局依据。诊断对四份早期先行评估给出碰撞标记格式警告，但所有六份 Prior Audit 均已分类且核心判断由各自原文与候选级审计支持。机器诊断不能验证 Codex 原生委派历史，因此委派数量不作为本裁决的证据。
