## 额外盆地回溯

恢复后没有停留在“成功回执/核验”盆地。以下结构不同方向在立项前或候选死亡后接受了直接近邻攻击：

- 历史压缩、撤销与失效记忆：STALE、MemoryAgentBench、MemConflict、Governance Decay（arXiv:2606.22528）和 TRACE（arXiv:2608.06503）已经覆盖失效事实识别、选择性遗忘、压缩后约束/状态丢失及闭环续跑评价。
- 并行共享状态与多智能体协作：ToolSandbox、TPS-Bench 和 CoAgent（arXiv:2606.15376）已覆盖竞态、调度与共享状态可串行化协议。
- 人工批准与授权漂移：Intent-Governed Tool Authorization、OpenPort、CAVA（arXiv:2607.13716）和 Temporary Authority, Permanent Effects（arXiv:2607.10487）已覆盖意图—动作绑定、批准绑定、状态见证与提交时授权。
- 动态工具模式：MCPEvol-Bench（arXiv:2607.14642）已用 11 类模式变异、123 个模型上下文协议服务器和 12 个模型评价工具模式演化；自演化工具工作又覆盖版本化工具与漂移。
- 运行框架依赖：Harness-Bench（arXiv:2605.27922）已在 5,194 条轨迹上测配置级框架效应；Rethinking Harness Evolution（arXiv:2607.12227）与 HarnessOpt-Bench（arXiv:2608.06301）覆盖匹配预算、留出泛化和框架优化。
- 结构化输出与工具调用耦合：Constraint Tax（arXiv:2606.25605）已定位 JSON 模式约束下的工具抑制和语法词元掩码原因，并验证透明两阶段执行；XGrammar 2（arXiv:2601.04426）覆盖动态与条件语法生成。
- 单位与数值语义类型：MeNTi（NAACL 2025，arXiv:2410.13610）已经把参数单位不匹配检测、嵌套调用换算工具和回填计算器参数作为核心机制；CCTU（arXiv:2603.15309）又用可执行步骤级校验覆盖复杂工具约束。因此再做小模型单位换算测验即使测出失败，也只能得到既有机制的跨域实例。

这些方向有的由直接先行杀死，有的由经典类型系统、并发控制、最小割/击中集或完整前置/后置条件构造性吸收。它们不是因为“没有做实验”而被宣称不存在；相反，只有当一个新干预不能在当前资源内被公平地与这些强基线区分时，才不进入昂贵实验。

## 为什么没有剩余高信息量动作

当前没有一个可执行实验同时满足以下两点：其正结果会留下无法由最近先行直接配置出的论文级 changed computation；其负结果会继续大幅压缩一个仍存的贡献差分。

- 对已判伪的 h-007、h-010、h-011、h-012 扩大样本，只是在不存在预注册核心签名的情况下追逐更弱效应。
- 对 h-008、h-009 或语义单位继续实验，即使复现失败，也只会验证成功信任、后置条件核验、预算化验证布置、单位换算等已有问题。
- 把这些组件重新组合为“图＋风险分数＋自适应核验”“类型＋验证门”或“摘要＋覆盖元数据”，不会产生未被 Sherlock、GLOVE、ToolGate、Verified Tool Calls、MeNTi 和经典算法覆盖的新计算。
- 剩余需要真实生产血缘、跨供应商原生协议、长期故障遥测或新型环境能力的设想，当前既没有数据也没有可验证机制；它们是未来重开资源，不是可以靠本地合成正例支撑的活动种子。

因此，本次终局不是从开放世界推出“智能体领域没有研究问题”，而是在本 Run 的既有探索轨迹和当前现实资源下，判断没有值得继续投入方向发现的可辩护高价值 frontier。
