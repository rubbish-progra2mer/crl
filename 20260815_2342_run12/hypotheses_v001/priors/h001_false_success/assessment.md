# 最近先行科研解释

> 本文件属于主研究者解释，可在阅读候选、PDF、Evidence 和实验后继续修订；它不进入机器事实快照哈希。

- 审计标识：`h001_false_success`
- 碰撞类型：`DIRECT_EXACT`（现象）+ `DIRECT_EXACT`（后置条件方法）+ `CONSTRUCTIVE_COMPOSITE`（确定性验证与修复）

## 真正的 nearest prior

- `prior-327b167d0b97e8b6`，arXiv:2606.09863v1，*From Confident Closing to Silent Failure: Characterizing False Success in LLM Agents*：直接把“环境状态未完成但智能体声称完成”定义为 false success，并在 tau2-bench 与 AppWorld 大规模测量；这占据 h-001 的核心现象命名、存在性与表面完成线索主张。
- `prior-dce3e31a9bb1049c`，arXiv:2608.02645v1，*Verified Tool Calls Improve LLM Agent Reliability Under Non-Atomic Failures*：直接提出带后置条件验证、重试前验证和幂等键的工具包装器，并在注入非原子故障的多任务模板中评估；这占据 h-001 的核心计算变化。
- `prior-8bf08846cd612e04`，arXiv:2608.02464v1，*Real-Time Detection and Repair of LLM Agent Failures*：以确定性核验检查工具结果和必需调用，并用回滚重跑闭环修复；构成检测—修复组合强基线。
- `prior-45e6a141af3ea19b`，arXiv:2607.07405v2，*Reason Less, Verify More*：虽为执行前政策门而非执行后后置条件，但直接覆盖“静默错误状态 + 确定性状态检查优于继续推理”的邻近机制。

## 实质组件重合

- 问题重合：工具智能体在表面成功时未以外部状态为准。
- 现象重合：false success、肯定式结束语言、状态与自我报告不一致。
- 计算重合：后置条件验证、verify-before-retry、幂等键、确定性核验、回滚重跑。
- 评价重合：合成/真实代理基准、文本无关真值、故障注入、任务成功与重复动作。

## 仍存贡献增量

- h-001 原主张下没有足以支撑 CCF-B 研究种子的论文级剩余差分。
- 可能剩余的“肯定式回执措辞是否因表面形式而因果改变同一潜在状态下的下一动作”没有被以上摘要直接测量，但它已经是不同的失败现象与评价坐标，应作为新候选而不是缩窄 h-001。

## 最危险替代解释

- 任意收益可能完全由多一次读调用、幂等键或回滚能力解释，而非任务特定后置条件。
- false-success 现象已经在更大规模、更多模型和两个成熟基准上被直接报告，本地小规模重复不新增经验贡献。
- 非原子故障下的重复动作正是 arXiv:2608.02645 的目标，换故障措辞或换本地模型不足以分离。

## 最小区分实验

- 不再为 h-001 执行本地方法实验；最近先行已直接同时杀死现象存在性与方法计算差分。
- 后继候选的区分实验必须固定潜在工具状态与任务，只改变语义保持的观测表面形式，并比较下一动作与最终结果的成对不一致；这样才不复刻 false-success/后置条件验证。

## 方法死亡后仍存现象

- 一般 false-success 现象本身存活，但已被 arXiv:2606.09863 直接占据，不能作为本 Run 的主要贡献。
- “语义等价工具观测导致策略不稳定”是否成立仍未知，转入独立候选。
