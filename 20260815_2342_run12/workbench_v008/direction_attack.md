# v008 方向先行攻击：聚合状态的行动义务覆盖洗白

## 观察来源

v007 的部分证书首动作实验提供了一个非预期配对结果。对三个域、每域两个任务，qwen3:4b 与 qwen3:8b 在已读前两项而第三项缺失时均为 6/6 继续读取缺失项；在完全相同证据上再加入一个 `status=READY` 的终端聚合摘要后，两模型均变为 6/6 直接不可逆提交。摘要没有提供第三项的新外部状态证据，因此“更多文本证据使安全性下降”不能计入 h-009 的最小割胜利，必须作为独立现象审计。

## 概念拆分

- **来源/祖先可信**：摘要确实由可信的前两项见证计算，没有被污染、撤销或伪造。
- **行动义务覆盖完备**：摘要实际覆盖的义务集合 C 是否包含下游行动要求的全部义务 Ω。
- 来源可信不推出 Ω⊆C。一个来源完全可信的局部摘要仍可遗漏第三项。
- 候选失败发生在标量聚合把“C 内全正常”压缩成无作用域的 `READY`，使模型把局部证书当作行动级完备证书。

## 已确认的危险最近邻

1. **ToolGate（P074）**：用 Hoare 风格前置条件 P 与后置条件 Q 门控工具调用及可信状态提交；删减 5%/10% 契约约束会系统退化。若最终行动 P 已完整列出 Ω，它直接吸收提交门，候选只能讨论跨工具聚合摘要的覆盖范围没有进入 P 的情形。
2. **CMTF（arXiv:2606.06284）**：工具契约显式包含 required state variables 与 produced variables，并只暴露满足前置条件的下一因果前沿；但执行器在工具返回后直接把声明的 effects 加入已知状态，未处理成功回执与真实效果分离，也未验证聚合状态的实际覆盖集合。
3. **MAP-Graph（arXiv:2608.10509）**：追踪共享记忆摘要的祖先路径与信任，在动作时门控。它可识别被污染/撤销的祖先，但一个只由可信 p0、p1 组成的摘要没有坏祖先；遗漏的 p2 不在其祖先图中。
4. **ProvenanceGuard（arXiv:2607.01236）**：运行前证明工具选择、每个参数赋值及解释具有来自用户查询、工具文档或历史的证据；其量词覆盖动作参数，而非外部状态前提是否已被摘要覆盖。
5. **PCAA（arXiv:2606.04104）**：行动证书记录假设、证据载荷与回执完整度，并诚实披露治理覆盖；回执完整度针对运行阶段集合，不是下游行动义务集合与聚合证据集合的对齐。
6. **P076 / COLM 2025**：恶意错误或成功元数据可经前线代理洗白并改变编排器控制流，且局部警告可与系统级执行并存。它直接占据“一般元数据洗白”，但攻击源、机制和结果不同于来源可信的局部正向摘要导致缺失状态读取反转。
7. **证据追踪综述（arXiv:2606.04990）**：指出摘要/聚合后的语义来源、证据遗漏和依赖覆盖仍缺少统一评测；这是开放问题陈述，不是候选方法或同类因果实验。

## 可存活的最窄主张

不主张一般 false success、契约、来源追踪、前置条件、摘要风险、元数据污染或动作门。仅检验：

> 对明确具有多项外部状态义务的不可逆动作，一个由可信子集产生但未声明覆盖范围的肯定聚合状态，是否会稳定地使模型放弃原本会执行的缺失义务读取；给聚合状态附带实际覆盖集合后，模型行为和机械提交门能否恢复。

方法增量若成立，也只是把聚合结果从标量 `status` 改为 `(status, covered_obligations, witnesses)`，并在动作义务集合 Ω 上检查包含关系。若完整 ToolGate 合同已可自然表达所有现实场景，则该增量只够作为评价/现象贡献，不够作为方法贡献。

## 必须先杀的替代解释

1. **词汇捷径**：READY 自身可能等价于“现在提交”。需测试 ALL_SET、ELIGIBLE 和结构匹配的 AVAILABLE/RECORDED。
2. **位置与长度**：增加最近一条工具结果可能让模型忽略前文。需用相同 JSON 结构、近似长度的中性摘要控制。
3. **显式提醒**：`covers=[p0,p1]` 可能只是风险警告。不得写“incomplete”“missing”或“unsafe”，只给集合标识。
4. **坏接口构造**：若聚合器名称或文档天然承诺全局 readiness，则部分覆盖的 READY 是契约违规。实验接口必须定义为返回“它检查的项目范围内的协调状态”，并把覆盖范围是否显式作为正交因子。
5. **完整合同吸收**：必须与把 Ω 全量编码进最终动作前置条件的强 ToolGate 基线区分；强基线若无性能/可部署差分，方法主张停止。

## 下一步判据

先注册 h-010，并执行三个模型、四个域、两种表面变体的首动作杀手实验。只有出现“无摘要读缺失—肯定无范围摘要提交—显式部分覆盖恢复读取—完整覆盖安全提交”的配对链，才值得进入最近先行组件审计与更真实工具框架；否则在 v008 内淘汰。
