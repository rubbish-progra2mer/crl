# v008 主研究者诊断解释与重新扩张决定

## 事实基础

`post_h010_reexpansion` 诊断为 `ADVISORY_NON_AUTHORITATIVE`，FTS Recall 为 READY、无污染或陈旧源。Run-wide 共有 10 个假设：4 个 falsified、6 个 prior_collision；只有 v003 有一次 Formal/Review-support attempt。v005-v008 的 Scratch 级检查依次覆盖分页闭合、肯定回执—效果分离、预算化见证布置和聚合状态覆盖。

## 杀伤范围解释

这些负结果足以杀死当前 Run 中以下局部干预谱系：

- 把一般 false success、响应/效果分离或后置条件验证当作新问题/新方法；
- 把依赖图、最小核验割、鲁棒监视器布置或来源祖先门控当作新计算；
- 把标量聚合状态改成覆盖字段，再用完整行动前置条件做集合门控；
- 在本地模型上主张分页游标导致特有提前闭合或工具别名数导致独立证据错觉。

它们不构成整个 TEXT_AND_TOOL_LLM_AGENT 边界的开放世界 No-Go，也不杀死由 h-010 杀手实验直接暴露的行为评价问题：模型为何在明确知道尚有第三项义务未读时，因为最近出现一个与最终 action_id 绑定的非否定协调摘要而集体提交。

## 新评价对象

下一科学版本转向**工具协议阶段边界线索的义务覆盖效应**，贡献形态优先为稳定现象与因果评价，而不是方法：

- 固定任务义务、写回执、逐项读证据和隐藏状态；
- 正交改变最近工具的语义身份（协调摘要/审计记录/普通读取）、是否绑定当前动作、返回字段及消息角色；
- 测量模型是否把一个协议级“阶段已经发生”线索错误提升为“全部义务已经完成”；
- 与 P076 的恶意多智能体元数据洗白、false success、ToolGate 契约遗漏和一般提示顺序偏差做组件级区分。

如果任意无关最近消息都产生相同反转，则只剩普通位置/截断效应，路线立即淘汰；如果只有与当前动作语义绑定的阶段摘要稳定反转，且无状态或不相关动作摘要不反转，则形成可进一步审计的因果现象。

## 版本决定

该转向改变了贡献形态（方法→评价/现象）、干预对象（覆盖字段→协议控制流线索）和核心自变量，适合从 v008 推进到 v009。历史 h-010 及全部输出保持原位，不修改机器。
