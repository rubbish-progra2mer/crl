# v102 选择上下文

v102 从方法/基准贡献切换到系统贡献，扫描最新 `cs.DC` 代理推理工作，并读取就绪调度、缓存虚拟化、沙箱预热、异构服务和恢复契约的原始摘要。该方向结构上确实不同于 v101，但公开工作已经覆盖所有主要状态变量。

当前机器可以安全执行小型调度仿真，却不能用它对真实 GPU 就绪批次、键值缓存吞吐或沙箱尾延迟做有说服力的系统结论；仿真正反结果也不会改变直接先行工作碰撞。把执行正确性加入调度又退回当前 Run 已关闭的陈旧、未来、取消和事务语义。

因此本版不实验。关闭范围仅限工具等待/恢复调度、键值缓存存活、沙箱预热和恢复恰好一次；Run 保持 `ACTIVE`。
