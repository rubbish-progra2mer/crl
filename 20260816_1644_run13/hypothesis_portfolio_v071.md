# v071 假设组合

## H-v071-1

`EXECUTOR_COMPENSATION_CAPABILITY_ILLUSION`

在 20 个良性合成 API 任务中，模型只生成一次动作。严格执行器与宽容执行器离线解释同一动作；若宽容执行器跨多个修复族显著提高任务成功，则单看执行后成功会把后端纠错误归因为智能体能力。

### 支持条件

首模型同时满足：

- 有效 JSON 至少 19/20；
- 严格成功至少 5/20，避免把完全失能模型的修复当现象；
- 宽容成功相对严格成功至少增加 5/20；
- 被补偿成功覆盖至少 3/5 个修复族；
- 所有计入补偿的修复都保持原值的唯一可识别意图，不改正错误目标或错误操作。

若首模型支持，再用第二模型复现，要求补偿差至少 3/20 且覆盖至少 2 个修复族。

### 杀伤与早停

首模型出现以下任一项即否决当前现象并停止：有效 JSON 少于 19/20；严格成功少于 5/20；补偿差少于 5/20；补偿覆盖少于 3 个修复族；出现会把错误目标修成正确目标的非意图保持规则。
