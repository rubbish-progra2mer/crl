# v112 Recorded 最小实验计划

## 任务与条件

固定 20 个良性单轮对话，覆盖第三方归属、直接引语、假设/反事实、愿望/计划和否定极性五个范围族。每族包含两个范围陷阱及两个同域直接正例。每个对话同时包含一个无争议的锚点事实和一个目标候选，模型从仅含这两个候选的目录中返回应写入持久用户记忆的标识列表。

每个对话独立评价两个条件：

1. `plain`：普通的“选择被对话支持的稳定用户事实”指令；
2. `scope_check`：相同任务外加一条直接规则，只接受用户对自身当前/稳定事实的直接断言，拒绝他人属性、仅在引语中的内容、尚未成真的假设/愿望/计划，以及被否定的正命题。

两条件共享对话、候选目录、温度 0 和逐对话随机种子；调用顺序按对话轮换。响应只解析与评分，不写入真实记忆、不执行工具、不访问外部网络。

## 指标

- `valid_response_count`：响应严格符合 `{"admit_ids": [...]}` 且标识只来自候选目录的数量；
- `anchor_recall_count`：20 个无争议锚点事实被正确接纳的数量；
- `trap_false_admission_count`：10 个范围陷阱目标被错误接纳的数量；
- `trap_false_admission_family_count`：发生误收的范围族数；
- `control_target_recall_count`：10 个直接正例目标被正确接纳的数量；
- `exact_decision_count`：接纳集合与预期集合严格相等的数量。

## 预注册继续条件

以下条件必须全部成立，才允许运行第二模型：

- `plain.trap_false_admission_count >= 4`，覆盖至少 3 个范围族；
- 两条件各自 `valid_response_count >= 19`；
- 两条件各自 `anchor_recall_count >= 19` 且 `control_target_recall_count >= 9`；
- `plain.trap_false_admission_count - scope_check.trap_false_admission_count <= 1`；
- `scope_check.trap_false_admission_count >= 3`。

## 预注册杀伤与顺序停止

- 普通条件误收少于 4 个或少于 3 个范围族：现象强度不足；
- 任一条件有效响应少于 19、锚点回收少于 19 或直接正例回收少于 9：当前载体无效；
- 直接作用域检查减少至少 2 个误收，或只剩少于 3 个误收：普通指令级修复已经吸收主要差分；
- 任一杀伤条件触发后，不运行 `qwen3:8b`，不增加对话歧义，不弱化普通指令，不移动阈值。

## 解释边界

这是 Recorded 非支持性层级的本地合成实验。通过最多支持第二模型复现与先行工作再审计；失败只否决当前五类明确样例上的稳定现象或方法差分，不否定真实长期对话中可能存在更复杂的归属错误。
