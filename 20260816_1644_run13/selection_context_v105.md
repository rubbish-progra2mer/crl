# v105 选择上下文

v105 不是从新论文标题派生候选，而是对 Run 内全部记录实验作横向复核后提出跨实验残余。这个残余的事实基础有限：v063 显示正确描述性状态不足、显式推荐有效；v066 显示效果标签无效；v082 显示结构物化局部有效但不统一。它值得审计，却不能自动升级为新假设。

直接先验将可执行路径分成三类：测量每条文本是否影响行为、优化工具元数据的表面表达、在模型看到动作前确定性过滤不可执行项。候选没有留下第四种改变计算的机制。将“跨多个语义切片”本身当作方法贡献，只会把复现基准误写成方法论文。

因此本版归档该综合残余，不修改既有实验解释，不追加事后提示变体；Run 保持 `ACTIVE`，下一版本转向结构不同的前沿。
