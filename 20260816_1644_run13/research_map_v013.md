# v013 研究图谱

- QuoteBench（arXiv:2608.13547）以固定回复交叉生成契约与执行传输，证明额外解析器造成 55.4–73.2 个百分点损失；正确边界转义和临时脚本完全消除该传输损失。其结构化操作试验仍有 11/36 失败，主要是字面量字段复制错误。
- CXI（arXiv:2607.06000）已将可写上下文区分为目的地限定的类型化释放与不透明数据槽；不透明数据句柄保存数据而不赋予权限，外壳命令使用可信渲染的参数、环境和目录，精确效果承诺绑定文件字节与状态快照。
- PACT（arXiv:2605.11039）已在参数级追踪来源和语义角色；NeuroTaint（arXiv:2604.23374）覆盖跨步骤语义信息流。
- SQL 参数化、预备语句与经典代码/数据分离是更早的直接系统谱系。

结论：不透明句柄、目的地限定类型和可信边界物化已被 CXI 直接实现；以正确率而非安全性为评测目标不产生新的 changed computation。
