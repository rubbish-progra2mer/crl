# v140 Recorded 最小实验计划

## 研究问题

目标论文 Lemma 11 声称：在世界模型均值是实际分数的单调失真、噪声独立有界且条件零均值、真实分数有限分层且各层持续获得锚点时，正文等距回归校准后的逐轨迹系统误差收缩到零。实验检验这些已写条件是否足以支持该结论。

## 预注册分布

实际分数 `r` 取 `1/4` 与 `3/4`，概率各为 `1/2`。定义

`phi(r) = 1/10 + 4r/5`，

噪声 `xi` 独立地取 `-1/5` 与 `+1/5`，概率各为 `1/2`，世界模型分数为 `hat_r=phi(r)+xi`。

四个等概率原子为：

- `(r,hat_r)=(1/4,1/10)`；
- `(r,hat_r)=(1/4,1/2)`；
- `(r,hat_r)=(3/4,1/2)`；
- `(r,hat_r)=(3/4,9/10)`。

该分布有两个真实分数层、每层覆盖率 `q=1/2`；`phi` 严格单调，条件均值层间隔为 `2/5`；原始偏差幅度 `B=1/20`；噪声跨轨迹独立、有界于 `1/5` 且条件均值为零；全部真实和预测分数均在 `[0,1]`。

## 计算

程序将用 Python 标准库有理数精确完成：

1. 按正文目标聚合相同 `hat_r`，用池相邻违反者算法求人口平方损失等距回归；
2. 计算两个真实分数层上的 `E[f(hat_r)|r]-r`；
3. 用任意正整数倍复制四个原子的权重，确认人口最优解与残差不随样本权重规模变化；
4. 令一维策略分数函数在低分层为 `-1`、高分层为 `+1`，计算真实奖励、原始世界模型奖励和校准奖励对应的期望策略梯度。该分数函数零均值且范数有界，可由二项策略的对数几率参数化缩放得到。

## 预注册判据

缺口成立必须同时满足：

- 分布逐项满足上述有界性、单调性、层间隔、覆盖率、独立性和条件零均值条件；
- 人口等距回归在 `hat_r={1/10,1/2,9/10}` 上的值依次为 `{1/4,1/2,3/4}`；
- 两个真实层的条件残差分别为 `+1/8` 与 `-1/8`，绝对值均严格大于零；
- 把四个原子的权重共同复制 `1、10、1000、1000000` 倍时，拟合值和条件残差完全不变；
- 真实期望策略梯度为 `1/4`，原始世界模型梯度为 `1/5`，校准后梯度为 `1/8`，所以直接等距回归不仅未消除梯度偏差，而且在该构造中把绝对偏差从 `1/20` 增至 `1/8`。

任一判据失败则关闭 H1。全部通过只证明 Lemma 11 的已写假设不足以推出其逐轨迹消偏结论；不评价真实任务数据，不声称论文整体训练收益无效，也不自动产生方法 Seed。
