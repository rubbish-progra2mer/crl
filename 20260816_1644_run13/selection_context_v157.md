# v157 选择上下文

本版有意离开 v156 的散落记录检索，转向接口执行语义。VAKRA 的优势是控制了本地数据库后端并提供三种接口分解、跨源多跳和自然语言政策，因而它比单一工具调用基准更适合检查“能力相同而接口形状不同”的现象。模型排名反转以及端点式接口相对组合式接口约 20 个百分点的优势，支持接口抽象确实是模型—运行框架联合系统的一部分。

但这个观察还没有给出新的选择算子。查询特定端点把多步计算移入工具实现；按任务选择端点是工具路由；从轨迹学习接口是工具制造和文档优化；把政策变成允许工具集是访问控制；把跨源字段显式连接是依赖图与模式对齐。这些路线都已有直接实现与当前 Run 负记忆。

本地合成实验若让一个模型比较“九个通用工具”和“一个宏端点”，正结果只会重现 VAKRA 已在 62 个领域观察到的接口效应；加入动态路由后，又只能评测已有工具选择器。负结果则无法推翻 VAKRA 的跨域证据。由于任何结果都不能恢复独立方法核，本版不消耗实验预算。

政策部分只做防御性、非操作性的能力边界分析，不研究过滤绕过，也不执行真实外部工具。v029 的宿主安全边界保持原样，且不是本版关闭原因。
