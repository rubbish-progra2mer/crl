# v129 研究图谱

## 证据解释与决策聚合

- [Split the Labor: Separating Evidence Interpretation from Decision Aggregation](https://arxiv.org/html/2608.14509) 把每个来源的解释压缩成命题、可靠性桶、理由和出处，并指出固定票数阈值会随来源总数增加而改变隐含后验阈值。
- 论文已经给出按可靠性桶校准的对数似然比聚合、三结果混淆矩阵扩展和块依赖折扣；同时明确依赖折扣只是启发式，可靠性桶通常并非辅助变量，实验没有改变聚合器，机制本身也不是新发明。
- “区分缺失、无关、沉默和反证”的自然扩展会落入非随机缺失、多类别标注者模型或带覆盖率的选择性预测；本地合成投票实验只能重现论文已推导的计数尺度漂移，不能建立新计算。

## 测试时数字孪生

- [Twin: Playing an Unknown Game with a Test-Time Digital Twin](https://arxiv.org/html/2608.14490) 让智能体编写可执行环境模型；模型必须重放全部已观测转移，失败反例触发修复，之后才用于规划和动作验证。
- 论文报告首见转移与重复转移的预测差异、计划动作与探测动作占比、数字孪生与真实环境失配率及整体框架消融，但整体消融同时删除世界模型、回放验证、探索、规划和执行器，不能单独归因各组件。
- 主动选择最有信息量的探测、从观测等价状态提升隐状态以及逐组件消融分别回到主动探索、部分可观测状态建模和评价设计；它们与反例引导世界模型的组合没有留下可识别的新原子计算，并与本 Run 的世界模型、状态别名和反例修复版本重合。

## 自适应评测停止

- [Knowing When to Stop: Bayesian Optimal Stopping for LLM Evaluations](https://arxiv.org/html/2608.14425) 用项目级和组级后验可信区间宽度决定停止；组级模型在固定先验下支持跳过尚未评测的项目。
- 这种跳过要求已观测前缀能代表未观测项目。论文明确要求随机顺序或可交换性，也承认中等异质性下名义可信区间的经验覆盖不足；若题目按难度或主题排序，前缀精度不能推出完整基准的精度。
- 预先随机化、按主题/难度分层并对各层设最低覆盖量，是经典抽样设计而非新的智能体计算。v055 已关闭自适应搜索中的序贯验证方法移植，v097 已关闭通用评测预算共享；再做有序前缀模拟只会复现已知抽样偏差。

## 电子表格层级关系图

- [SheetCompass: Hierarchical Relation Graphs for Agentic Spreadsheet Reasoning](https://arxiv.org/html/2608.14452) 为每个原子子任务构造相关子图 $G_i$，随后在正文中定义全局共享子图 $G_{shared}=\bigcap_i G_i$，程序员再以该共享子图为结构上下文，并被要求只锚定在已验证节点集合内。
- 该规范存在直接反例：若某一步需要节点 $x\in G_i\setminus G_{shared}$，严格锚定的程序员就无法引用 $x$；两个独立子任务的相关节点集合互不相交时，共享上下文甚至为空。正确保留所有步骤所需节点至少要使用逐步子图，或使用并集并把交集仅当公共核心。
- 这是论文规范层的集合运算矛盾，但修复只是改用逐步子图/并集，不构成论文级新方法。论文给出的匿名代码入口被宿主安全策略拒绝访问；本版本不改换入口规避，因此不能断言发布实现真的执行了交集。

## 结论

四条路线分别被论文自身的显式边界、成熟统计/世界模型先例、本 Run 历史覆盖或过于局部的规范修正关闭。v129 不注册活动假设，也不运行不能改变判定的低信息量实验。
