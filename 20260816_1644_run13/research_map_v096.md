# v096 研究图谱

## 行动诱导观察

- 执行溯源综述把检索、工具、记忆、环境观察、外部状态变化、主张与动作纳入同一类型图，并明确区分 `Generate`、`Use`、`Support`、`Depend-on`、`Update` 和 `Invalidate` 等关系。
  - https://arxiv.org/abs/2606.04990
- 因而，一个被当前动作生成的环境状态可以在执行图中被识别为该动作的后代；它可以验证动作的后置条件，却不能充当该动作前置理由的独立来源。
- 更一般地，Performative Prediction 已形式化决策会改变其后观测分布的情形，并给出执行稳定性而非把诱导结果当作固定外生数据。
  - https://proceedings.mlr.press/v119/perdomo20a.html
- 当前 Run 的 v009 已处理证据根循环重复，v085 与 v089 已处理执行/主张来源，v092 已处理自生成推断写回后自我强化。把外部状态写入加入来源图不产生新的计算原语。

## 假设诱导采样

- POPPER 以可测蕴含为目标设计并执行序贯证伪实验，在主动收集多样观察时控制第一类错误。
  - https://proceedings.mlr.press/v267/huang25n.html
- Fisher-R1 的 P-Bench 已直接测量统计方法选择、有效 p 值计算和结论，指出智能体即使正确执行分析也会因细微推断错误得出错误结论；其训练使用可验证统计奖励。
  - https://arxiv.org/abs/2608.07437
- Evidence-Informed LLM Beliefs 将先前假设证据写入非平稳信念，过滤虚假惊奇并增加多样性，避免搜索把重复发现当成新证据。
  - https://arxiv.org/abs/2606.29182
- 当前 Run 的 v023 已覆盖候选—证据—可信度更新，v055 已覆盖自适应科学搜索的事后选择偏差与序贯检验，v084 已覆盖自动科研流程评价。

## 结论

“行动诱导观察”可由执行溯源的生成关系和经典决策依赖分布表示；“假设诱导采样”已有序贯证伪、错误控制、非平稳信念与统计推断训练。二者均没有留下可由一个新提示、标签或局部图规则承载的论文级计算差分。
