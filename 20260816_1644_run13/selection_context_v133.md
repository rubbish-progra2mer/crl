# v133 选择上下文

v133 刻意跨越记忆、事务、判分、强化学习比较、科研搜索和证据传输，避免连续版本只在一种轨迹载体内改写问题。结果仍然没有方法候选，但原因不是关键词搜索局部化：各对象分别被当前 Run 的精确历史或目标论文的完整方法关闭。

RubricForge 暴露的轨迹渲染承重假设一度是最清晰的残差。若两个环境结果在判分器可见轨迹上观察等价，无环境判分不可识别；但这正是 v021 已保存的协议级观察碰撞判据，而不是新的评分量表学习。AI 科研偏好模型的“有余量时有用、验证已近最优时无增益”也成立，但自然计算是多保真选择与信息价值，不是新的科研智能体原语。

跨上下文传输论文则提供了真正不同的全局计算，不过论文自身已把它从定理推进到可运行分解、弃答门、统计检验和数据收集动作。为避免把直接工作重新命名，本版不做缩小复现。

Run 保持宽 Charter 下的 `ACTIVE`。下一版不继续围绕近期评测、选择器、事务和冲突门控横向扩展。
