# v083 选择上下文

v083 关闭的是“动作标签偏置可独立升级为本 Run 方法候选”，不是否认该偏置存在。公开证据已经显示：一般分类标签会产生稳定偏好，工具描述编辑会显著改变工具使用，调用/不调用存在可定位的内在偏移，工具选择失败也可能发生在决策读出而不是注意阶段。

把工具动作改写成 `A/B/C`、随机排列或使用运行时映射，最多是这些已知偏置的控制与校准。它没有引入新的可观测状态，也没有改变动作选择之外的计算。v035 的枚举字段名实验又未复现相近的名称诱导效应。基于 v082 的具体错例继续调标签会降低可证伪性。

因此本版不实验、不修改 v082 解释，下一前沿必须避开标签校准、工具描述编辑、调用阈值偏移、注意力/读出干预和输出格式重排。
