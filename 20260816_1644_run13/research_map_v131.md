# v131 研究地图

## 路径等价与执行传输

- [SpecPath](https://arxiv.org/abs/2608.09799) 固定代码库、最终契约、核验器、系统与预算，仅改变等价修订历史；其公开摘要报告聚合准确率近似时，100 个完整区块中仍有 35 个在直接规范成功、却在至少一条等价历史上失败。该现象有效，但把历史编译成当前有效契约或结构化控制状态，会回到 v060 的状态化交接和 v124 的历史状态抽象；继续要求对所有等价历史保持行为，又属于变形测试/规范鲁棒性。
- [QuoteBench](https://arxiv.org/abs/2608.13547) 分离生成契约与执行传输，并显示额外解析器可造成 55.4--73.2 个百分点损失。当前 Run 的 v013 已以 CXI 的不透明数据槽、类型化释放和可信物化关闭该修复，v058 又关闭命令解释链归因；本版不重复。

## 核验、弃答与表示干预

- [AI Evaluation Should Measure Verification Cost, Not Correctness Alone](https://arxiv.org/abs/2608.08709) 提出核验成本等概念性评价对象，但公开摘要说明它仍是概念性工具而非完整部署方法；依赖图核验点选择、级联截断和用户核验负担已分别受 v072/v054 约束。
- [You Only Pass Once](https://arxiv.org/abs/2608.14465) 在一次冻结模型前向中同时回答与弃答，并直接处理条件引导写入残差后、零样本充分性读出受干扰的问题；它用小网络重建干预前残差。该论文已经给出目标现象、干预位置和修复计算，不能把“先读后写”重新包装为工具智能体方法。
- [Never the Number](https://arxiv.org/abs/2608.13926) 把数值计算放入可信确定性内核，让生成外壳选择问题而不生成事实值；v114 已以结构性弃答与确定性边界关闭同类架构。

## 消息、技能、异步思考与恢复

- [Wrong but Useful](https://arxiv.org/abs/2608.14375) 用固定消息池和可见/隐藏重放区分消息答案正确性与上下文轨迹价值；论文自己给出同题删除机会，并把未见问题价值预测定义为下一目标。v106 已核对反事实信用分配、离线价值学习和在线选择的直接方法族。
- [Demystifying Agent Skills](https://arxiv.org/abs/2608.14036) 发现技能主要充当程序锚点，正确调用既非成功的充分条件也非必要条件；v106 已以技能逻辑测试、适用条件和可执行门控关闭自然扩展。
- [Second Thought](https://arxiv.org/abs/2608.13667) 在动作—观察等待窗口并行生成辅助思考，再在观察到达时合并；v106 已以异步投机执行和命中提交语义关闭观察守卫扩展。
- [AgentRewind](https://arxiv.org/abs/2608.14380) 记录模型上下文与受控环境的对齐检查点并恢复；v125 已审计外部效果边界与等预算评价。

## 版本回归、成本与工具表面

- [No Universal Signal Predicts Sample-Level LLM Regression under Version Updates](https://arxiv.org/abs/2608.13607) 已统一比较置信度、似然漂移、词元级散度与表示漂移，并用选择性回退把高风险样例路由回旧模型；剩余任务条件信号选择是该论文直接结论，不是新的智能体计算。
- [Not All Tokens Are Equal](https://arxiv.org/abs/2608.13571) 已把重试造成的真实工作流成本膨胀纳入模型路由，并发现把失败推理链转交强模型可显著伤害准确率；其新鲜升级策略已是直接修复。选择性保留失败链中的可核验步骤会回到过程核验、负轨迹利用和 v106 的上下文轨迹价值选择。
- [Does a Language Server Save Tokens for Coding Agents?](https://arxiv.org/abs/2608.13568) 直接比较词法检索与语言服务器协议检索的成功成本，并把任务类、模型能力与词法噪声作为自适应路由条件；该路由已由论文明确给出。

## 结论

筛查到的现象多为真实且跨模型稳定，但每个自然干预要么由论文自身完成，要么与当前 Run 的精确负记忆同构。v131 不注册实验；合成复现不能恢复已经消失的方法差分。
