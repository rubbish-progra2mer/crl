# v123 当前记忆

- 云端—本地系统的隐私声明必须枚举所有外部接收端，不能只根据在线推理路由推断训练、评估、监督或遥测控制面也受保护。
- “最终监督者只看聚合统计”不等于“精炼循环不看原始样例”；应逐调用检查参考者、评估者和监督者各自的输入。
- 基准使用公开或合成个人身份信息样例时，只能证明架构/指标范围错位，不能据此声称真实用户数据已经泄漏。
- 评测分母遗漏可以形成重要审计意见，但若修复只是补全外部接收端，通常不足以构成新的方法计算。
- 私有适配的直接基线必须包括差分隐私提示生成、私有教师聚合、本地提示优化和联邦参数/提示聚合。
- 下一前沿需避开个人身份信息检测、去标识、出口审计和私有提示适配这组已拥挤路线。
