# v146 选择上下文

差分故障注入工作提供了高质量、应用特定且可重复的异常路径验证，不能因其使用大语言模型改写代码而低估其工程价值。但方法的承重部分是共享驱动注入、逐对旧/新执行与确定性结果分类；智能体没有决定故障模型，也没有学习一个新验证策略。

如果把它迁移到工具智能体，最小实验只能构造若干状态扰动，对旧/新提示或技能运行同一用例。这正是当前 Run 已执行过的变异/协议补全路线，且语言模型生成变异输给固定程序化基线。重新运行会降低证据强度，不能恢复论文级差分。

ISO 非功能需求研究又提供了必要的表示强基线：相同语义的结构化 JSON 与丰富自然语言几乎等效。后续不得把文件格式、字段化或更长规范本身记作 changed computation。

因此 v146 不注册实验、Seed、Reviewer、Formal 或 Review-support，转向下一结构前沿。
