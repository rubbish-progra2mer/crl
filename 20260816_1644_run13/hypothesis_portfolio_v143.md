# v143 假设组合

| 草案 | 判定 | 决定性原因 |
|---|---|---|
| 固定难度偏移的前沿环境选择 | `MECHANISM_NOT_IDENTIFIED` | 固定偏移不是材料化后难度的经验估计，金标准验证只认证内部一致性 |
| 同候选池关闭求解器的选择器归因 | `VALUABLE_EVALUATION_ONLY` | 论文明确缺少该组件对照；补做对照会收紧现有系统主张，不能独自产生方法核 |
| 动作条件的经验难度/学习增益模型 | `AUTOMATIC_CURRICULUM_AND_UED_COLLISION` | 自动目标生成、基于遗憾的环境设计、学习进展与优先级关卡回放已直接覆盖 |
| 材料化后策略复测门 | `DIRECT_FRONTIER_MEASUREMENT_BASELINE` | 这是识别既有机制所需的公平基线，不是新的智能体计算 |
| 验证状态的依赖失效 | `EXACT_RUN_DUPLICATE_V012_V124` | 版本化读集、依赖图失效和任务相对充分状态已关闭 |
| 决策图选择性重算 | `EXACT_DEPENDENCY_AND_PROVENANCE_COLLISION` | 影响闭包、未受影响节点保留和来源治理已有直接计算 |

v143 没有正式实验假设。公开仓库工件不足只降低复核性，不被当作效应反证或先行工作碰撞。
