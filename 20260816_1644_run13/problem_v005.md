# v005 问题定义

## 候选问题

并行工具调用在语义上没有先后依赖，但真实完成时间不确定。若运行时按完成顺序追加工具结果，同一批调用与同一组结果可能仅因消息排列不同而产生不同的后续动作。

## 拟议干预

运行时以原始计划中的调用索引归并并行结果，等待批次完成后按稳定索引向模型提交；失败也占据原槽位，不让墙钟完成顺序泄漏到语言模型上下文。

## 最小可证伪主张

在固定任务、固定并行调用、固定结果内容、固定模型与固定解码种子的条件下，只置换三个工具结果消息。若后续决策几乎完全不变，或稳定计划顺序不比任意顺序可靠，则候选死亡。

## 关键混杂控制

- 工具调用列表顺序固定，只改变对应工具结果消息的到达顺序；
- 正确证据源在计划位置 1、2、3 间平衡，不把“第一或最后最好”写入设计；
- 同时包含权威源裁决、显式拒绝、法定人数、集合交、求和与约束优化；
- 使用温度 0 和相同种子；所有排列使用完全相同的结果文本。
