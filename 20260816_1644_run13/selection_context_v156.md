# v156 选择上下文

本版先排除了与既有版本直接重合的近期工作：跨会话上下文状态交接已由 `v124` 关闭，未知博弈规则推断已由 `v116/v129` 覆盖，PACE-Bench 的机制重设计已在 `v119` 处理。SPIEval 被保留为主候选，因为它以 10 个应用、精确参数判分和大规模调用日志揭示了一个稳定的跨模型现象：失败智能体并非主要选错工具，而是检索不足并提交了错误参数值。

然而，该现象不能单凭“79% 参数值错误”识别唯一因果机制。错误可能发生在查询生成、召回、候选消歧、跨记录整合或最终复制中的任一环节。去掉分页几乎无效、直接提供相关记录大幅有效，能排除分页预算作为主因，却仍不能把上述阶段分开。

若构造本地合成任务并加入逐参数充分性检查，正结果只会复现 S2G-RAG、证据覆盖停止或论元溯源的已知收益；负结果则可能来自合成任务和 SPIEval 分布不匹配。两种结果都不能恢复新的方法差分，因此不注册实验。这里的“不实验”来自决策价值不足，不是机器资源不足、安全控制或 Run 停止。

v029 的宿主安全边界保持原样。本版只处理虚构个人记录上的防御性信息定位与证据支撑，不涉及真实个人数据，也不涉及安全过滤绕过。
