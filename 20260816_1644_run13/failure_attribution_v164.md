# v164 失败归因

## 类型

`LEARNED_TOOL_DEFERENCE_CLOSED_BY_TOOL_CALIBRATION_DISAGREEMENT_TRIGGERED_RECRUITMENT_AND_INFORMATION_VALUE_PRIORS`

## 直接原因

- 目标论文已证明 Qwen 工具型智能体在图神经网络输出后几乎不再探测，并给出正的逐节点神谕差距；
- 仅用标准置信、纯度、度和邻居分歧训练路由器，目标论文自己的留出分析已显示可恢复空间很低；
- 校准工具条件有效性已有 ProbeCal 和工具型智能体置信校准强化学习；
- 由分歧选择能解决争议的专用工具已有 DART；
- 以预计信息增益和成本选择继续探测属于现成的信息价值预算控制。

## 非原因

- 不是把 Qwen 的 97.6%–99.2% 一致率外推给所有模型家族；
- 不是忽略 0.5B 低一致率来自不会调用工具而非怀疑；
- 不是把单种子门控表面增益当成稳定结果；
- 不是安全控制、恶意工具研究、Prior collision 或 Run 终局。

## 决定

不注册实验或 Seed。保存“工具调用率、工具一致率和工具仲裁增益必须分别报告”的评价边界；Run 保持 `ACTIVE`，下一版离开工具信任校准与选择性调用方法族。
