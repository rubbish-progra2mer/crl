The Definition of the 'S' -- Summary Bracket -- Variable: A summary bracket variable summarizes the bracket information embedded in a set of individual bracket variables. Each bracket question, if asked, yields a single-digit response (1=more than, 5=less than, 8=do not know, 9=refused), which we name v1 through v4 for four bracket questions, v1 - v5 for five brackets, etc. Whatever the actual sequence of bracket questions, v1 refers to the lowest amount and v4 (0r v5) refers to the largest. The summary bracket variable is calculated simply as v1 + 10*v2 + 100*v3 + 1000*v4 +10000*v5... Missing values on any individual bracket variables are converted to zero (0) before the operation. In addition, there are three special codes reserved for an 'S' variable: '-2' indicating that the missing value on the 'X' variable was legitimate (no imputation was necessary)"; '-1' indicating that the original value of the 'X' variable was not missing"; and '0' indicating that the 'X' variable was imputed without any bracket information.
