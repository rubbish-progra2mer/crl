# v155 假设组合

## H1：共享策略世界排演会形成自证轨迹

- 机制：行动与假想响应共享参数和成功奖励，排演角色可能偏向生成使当前动作显得有效的响应，行动角色再对该偏置分布过拟合。
- 可证伪现象：在动作固定时，训练后排演响应相对真实模拟器面板的行为覆盖下降，同时训练内奖励上升、未见模拟器成功率下降。
- 判定：现象和诊断链已被《一个冻结模拟器并不够》直接覆盖；EnvACE 的同一模型双角色还是该论文框架明确实现的在线自博弈情形。

## H2：多样化私有排演可恢复环境覆盖

- 机制：要求单模型显式输出多模态回应分布，再从中采样多个排演分支。
- 判定：与“言语化采样”逐轮扩宽模拟器分布同构；EnvACE 自己也已有多条私有排演，只是没有跨模拟器覆盖保证。缺少新计算。

## H3：排演者群体或历史检查点池可避免共同漂移

- 机制：行动策略不只面对当前共享排演者，而从异构模型或历史排演者检查点中采样，并以保持有信息变化的奖励更新。
- 判定：异构轮换、双模型协同训练、历史检查点池与群体自博弈均已由 SCOPE 框架和实验直接覆盖；将它移植到 EnvACE 只改变应用标签。

## H4：真实环境锚点校准假想响应

- 机制：抽样调用真实工具，以观察排演—真实响应差异并校准世界模型。
- 判定：退回本 Run `v140` 的少量真实执行锚点世界模型校准，以及一般模型式强化学习的模型误差／利用问题。它还放弃 EnvACE“训练展开不接触外部环境”的核心接口。

## 决定

四个假设均不注册为 Seed。没有满足“结构差异、先行未覆盖、可由当前资源产生决策性证据”三项条件的候选。
