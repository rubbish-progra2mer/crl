# v147 选择上下文

本版本刻意从连续的软件测试前沿转向责任边界，并优先检查是否存在真实用户行为或可执行协作状态。AppLooper 提供了清楚的角色权限、证据边界和候选版本生命周期，但公开论文没有比较评价；它不能回答闭环是否优于普通开发—测试循环，也不能识别虚拟用户、所有者意图复测或候选绑定的边际贡献。

把该系统缩小为本地合成实验会得到一个确定性账本加若干角色提示。通过率只能证明我们实现了自己的协议，不能证明用户更能发现缺陷、信任更校准或发布更负责。使用另一个语言模型扮演所有者又会重复 `v088` 已关闭的模拟用户外部效度错误。

真实被动感知研究显示行为可控性与社会依赖是重要边界，但当前环境不能用合成人类行为复现该外部因素；将其写成“可控性字段”仍只是人类确认或风险分层。因此本版本在实验前关闭，不生成 Seed、Reviewer、Formal 或 Review-support。
