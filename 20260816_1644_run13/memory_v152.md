# v152 当前记忆

- 随时有效停止解决反复查看与选择性停止，不自动降低结果方差；控制变量降低方差，也不自动提供可停止证书。
- `AV-AIVAT` 的有效接口要求：动作前启用、已知条件动作核、只用过去数据的价值函数、固定目标流，以及精确证书所需的独立结构界。
- 方差比不能直接替代停止时间比；有界置信序列的赌注上限和声明范围会形成确定性宽度下限。
- 在公开扑克语料中，渐近置信序列停止比中位数约 74.17 倍，而描述性经验伯恩斯坦停止比约 1.365 倍；后者的校正流没有解析上界，不能称精确证书。
- 通用语言模型工具轨迹缺少完整可验证的动作核，未知环境节点又是主要随机来源，因此不能直接继承 AIVAT 的条件零均值。
- 普通结果预测残差不是自动无偏的方差校正；若校正器看见当前轨迹或事后选择节点，会污染显著性。
- v015/v055 已覆盖语言模型智能体随时有效评价和自适应序贯验证，v069/v138 已覆盖重复执行方差与可靠性。
- 不再从置信序列、电子过程、重复运行或扑克动作核控制变量派生候选。
- 下一 frontier 必须改变通用智能体可观察状态或干预计算，而不是继续扩展评价统计外壳。
