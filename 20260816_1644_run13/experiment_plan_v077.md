# v077 Recorded 最小实验计划

## 任务与条件

固定 20 个良性单步工具任务，覆盖订单配送、成员角色、报告排程、账单货币和备份配置五个任务族，每族 4 个任务。每个任务有三个演示；演示的关键参数重复同一实例值，而当前请求明确给出不同值。所有工具参数都在当前请求中逐项显式出现。

每个任务独立评价三个条件：

1. `concrete`：普通具体演示；
2. `warning`：相同具体演示，并加一条通用“不要复制演示实例值”警告；
3. `scoped`：原始演示值完整保留在逐演示局部绑定表，演示工具调用体改用逐演示 α 改名占位符。

三个条件使用相同工具模式、当前请求、温度 0 和逐任务随机种子；调用顺序按任务轮换。模型输出只被解析和评分，不执行任何工具。

## 指标

- `valid_call_count`：可解析、工具名正确且参数对象存在的调用数；
- `exact_count`：工具名及全部参数严格等于当前请求的任务数；
- `leakage_count`：指定关键参数恰好等于重复演示值、且不同于当前目标值的任务数；
- `leakage_families`：发生串值的任务族数；
- `other_error_count`：有效调用中既非严格正确也非指定串值的任务数。

## 预注册成功条件

以下条件必须全部成立：

- `concrete.leakage_count >= 6` 且覆盖至少 3 个任务族；
- 三个条件各自 `valid_call_count >= 19`；
- `concrete.leakage_count - warning.leakage_count <= 1`，即通用警告没有吸收主要现象；
- `concrete.leakage_count - scoped.leakage_count >= 4`；
- `scoped.exact_count - concrete.exact_count >= 4`；
- `scoped.exact_count - warning.exact_count >= 3`。

## 预注册杀伤与顺序停止

- 若 `concrete.leakage_count < 6` 或串值少于 3 个任务族，现象不可行；
- 若任一条件 `valid_call_count < 19`，当前载体无效；
- 若通用警告减少至少 2 个串值，方法差分不足；
- 若作用域表示减少串值少于 4、相对具体演示严格正确率增益少于 4，或相对警告严格正确率增益少于 3，干预失败；
- 任一杀伤条件触发后，不运行 `qwen3:8b`，也不调整提示、任务或阈值。

## 解释边界

这是 Recorded 非支持性层级的本地合成实验。成功最多支持进一步复现与先验审计；失败只否决当前现象强度和表示干预，不否定一般上下文复制。
