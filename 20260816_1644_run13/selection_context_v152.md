# v152 选择上下文

`AV-AIVAT` 不是简单把两个现成统计工具并排使用。它明确规定在线价值函数的时间可预测性、动作前启用、条件动作核、结构界与停止声明发布协议，并实证说明相同方差收益在渐近区间和精确有界区间中可能对应 74 倍与 1.365 倍的完全不同停止收益。这一负面设计规律值得保留。

但论文级迁移必须保留条件零均值校正。常规文本/工具智能体评价既不知道完整动作核，也不知道环境响应核；工具轨迹还具有任务异质性、运行聚类和模型/环境漂移。删除这些条件后只剩一般控制变量或结果预测残差，不能继承无偏性与随时有效保证。

本 Run 已有直接智能体置信序列、电子过程、自适应验证和方差分解先验。人工伯努利流或小型扑克树不能缩小剩余的不确定性，因此本版在实验前关闭。
