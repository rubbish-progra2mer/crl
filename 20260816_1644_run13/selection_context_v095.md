# v095 选择上下文

v094 的 facts-only 主动诊断不替代科研判断，但促使本版本从方法命名转向跨模型稳定失效现象。筛查得到的三类现象均有直接证据，不过贡献差分已经塌缩：Over-Searching 覆盖不可回答问题、负证据、成本指标与缓解；MisKnow-Agent 覆盖核验可识别但流程仍采纳的错知及前后置防御；DeepFact 覆盖证据争议驱动的真值修订和版本化评分。

本地合成防御实验在安全边界内原则上可以设计，但它无法形成新的论文级计算：不可回答查询实验复现 Over-Searching；合成误导文档实验复现 MisKnow-Agent，且没有必要接近任何可操作的规避研究；标签迭代实验复现 DeepFact。实验失败或成功都不会显著改变剩余贡献差分。

因此不执行这些实验。下一前沿必须离开通用过度搜索缓解、误导文档核验传递和版本化真值审计，寻找结构不同且能改变在线计算的稳定现象。
