# v143 失败归因

## 类型

`FRONTIER_SYNTHESIS_AND_STRUCTURED_STATE_CLOSED_BY_UNIDENTIFIED_MECHANISM_AND_DIRECT_PRIORS`

## 直接原因

- Envs-FORGE 用原种子通过率加固定偏移预测材料化后难度，后生成验证只认证内部一致性，没有认证新环境位于学习前沿；
- 下游比较缺少相同候选池的无求解器/动作置乱/动作边际匹配对照，并同时改变技能子图、制品编辑掩码和提示；
- 动作条件经验校准、材料化后策略探针、学习进展和遗憾选择被自动目标生成、无监督环境设计、演化课程和优先级回放直接覆盖；
- StructAgent、BoardroomAI 和本体项目记忆的自然扩展分别与当前 Run 的陈旧依赖失效、选择性重算、来源治理和集合完备性负记忆重合；
- 能力层积论文自身在真实仓库压力测试中保留了无显著优势的负结果，没有可继续包装的正向方法主张。

## 非原因

- 不是 Envs-FORGE 的公开增益不存在；其跨模型与跨基准方向稳定；
- 不是本地实验失败：本版没有注册或运行科研实验；
- 不是把公开代码链接的复核不足当作科学反证；
- 不是 v029 宿主安全边界，本版没有操作安全过滤器或研究绕过；
- 不是事实诊断自动淘汰候选；最终解释和选择由主研究者完成；
- 不是 Run 终局。

## 决定

关闭 v143 的固定前沿偏移、材料化后难度校准和结构化状态执行线；Run 保持 `ACTIVE / AUTONOMOUS`。
