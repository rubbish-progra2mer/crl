# v149 当前记忆

- 消费外部给定的漂移起点不等于检测漂移；必须把起点发现与后续分类分开评价。
- 小模型在固定节点模式上经强化学习提高格式和裁判分数，只识别窄任务训练效果；没有无图同预算基线时不能归因图分解。
- 只读漂移后的消息历史回滚与环境写入后的状态修复是不同问题，不能用前者的完成率支持后者。
- 不再从“分类—抽取—查文档—判风险—决定”的状态机派生恢复候选；故障归因与角色化图表示已有直接工作。
- 环境回放奖励、逆接口文档核验、逆操作执行、复测与人工升级分别属于执行验证、工具契约、事务补偿和责任门控。
- 不运行或扩展安全攻击/过滤绕过载体；良性恢复研究也必须先越过 MARS、AgentRewind、ACRFence、Cordon 与当前 Run 的事务负记忆。
- 下一 frontier 离开故障归因、漂移检测、回滚、检查点和补偿。
