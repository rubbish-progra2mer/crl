# v150 选择上下文

HERMES 与前几版不同：它不是玩具协议，而是已经生产公开科学数据库并经专家全面校订的真实系统。其实体/属性精度和 55 卷规模应当保留为有效工程证据。

但论文级方法判断必须分开“系统有效”与“多智能体编排造成有效”。系统同时改变光学字符识别、版面/表格解析、72B 领域模型、另一实体模型、检索、领域规则、来源追踪和人工复核；没有可识别编排或共享状态的基线。跨域又修改模式与规则，且宽表属性召回明显塌缩。

更强的直接方法证据来自 SudokuFill：它在同一科学文档抽取问题上显式实现全局状态、跨字段复用与多轮约束，并报告固定骨干消融。DocETL/MOAR 又覆盖流水线改写与成本—准确率搜索。任何本地小 PDF 实验都只会降低任务真实性并重复这些计算。因此不生成 Seed、Reviewer、Formal 或 Review-support。
