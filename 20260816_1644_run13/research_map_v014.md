# v014 研究图谱

- Agent Behavioral Contracts II（arXiv:2608.12895）把联合分布的 $2^m$ 个单元作为变量，以带邦费罗尼校正的克洛珀—皮尔逊矩区间约束线性规划；作者明确说明该证书不声称扩展到大 $m$。
- 同文“未来工作”直接提出两条路线：对子组合分别认证后再组合，以及在 $2^m$ 单元上做列生成；后者被作者描述为对结构化矩族保持尖锐性的路线，但未实现。
- Byun 与 Song（2020，DOI:10.1061/(ASCE)EM.1943-7889.0001717）已经针对完全相同的系统可靠性极值问题提出延迟列生成：在只给边缘与联合失效概率、且不假设联合分布形式时计算最窄可靠性界，并把指数规模的单元线性规划改写为重复求解较小的二元整数定价问题。
- Boole—Hailperin 概率界、系统可靠性线性规划与后续概率界优化构成更早的直接计算谱系；局部边缘多面体或图宽松弛则会牺牲尖锐性，属于经典图模型松弛而非新的智能体计算。

结论：把现有智能体证书换成延迟列生成，是经典可靠性求解器在新对象上的直接应用，而且已被源论文明确指出；不足以形成 CCF-B 方法论文的 changed computation。
