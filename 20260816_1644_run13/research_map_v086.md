# v086 研究图谱

## 搜索时污染

- 《深度研究智能体中的搜索时污染》已经把外部检索绕过预期推理并抬高成绩定义为搜索时污染，区分基准元数据泄漏、题目—上下文泄漏和显式答案泄漏，给出检测算法，并在六个公开基准上发现成绩最高可被抬高 4%。
  - https://arxiv.org/abs/2606.05241
- 更早的《搜索时数据污染》在 HLE、SimpleQA 和 GPQA 上发现约 3% 的问题可让搜索智能体直接找到带真值标签的数据集；屏蔽 Hugging Face 后，污染子集准确率下降约 15%。该工作还公开完整日志并提出受控访问、轨迹透明和基准设计建议。
  - https://arxiv.org/abs/2508.13180

## 训练时污染与抗污染评价

- Data Contamination Quiz 通过原始实例与词级扰动版本的多选识别，黑盒估计模型是否记住特定数据集实例。
  - https://aclanthology.org/2025.tacl-1.37/
- AntiLeak-Bench 自动使用更新的现实知识构造可持续更新基准，直接针对静态测试集进入后续模型训练的问题。
  - https://aclanthology.org/2025.acl-long.901/
- 《当基准泄漏：大语言模型的推理时去污染》已把推理时去污染作为独立方法问题，而不是只删除可疑测试条目。
  - https://aclanthology.org/2026.acl-long.2071/
