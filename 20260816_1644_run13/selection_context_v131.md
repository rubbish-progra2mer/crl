# v131 选择上下文

v131 遵守 v130 主动诊断的“现象先于方法”约束，优先核查平均准确率可能隐藏的路径敏感、干预干扰和逐样例回归。结果不是现象不足，而是当前 Run 已经在 v013、v054、v060、v072、v106、v114、v124 和 v125 保存了精确负记忆；最新论文又直接完成了消息轨迹价值、等待期并行思考、残差重建、版本回退与成本路由。

SpecPath 是本版唯一新增且清晰的现象边界：最终契约等价不保证智能体对修订历史不敏感。但其自然修复没有留下超出有效契约编译、状态化交接、历史抽象或变形测试的计算。为避免再次以“新问题”替代“新方法”，本版不做低信息量复现。

v029 的外部执行边界保持不变。本版没有研究真实网关、过滤规则或任何绕过技术；一次被宿主拒绝的 arXiv 导出接口 URL 没有被重试或规避。
