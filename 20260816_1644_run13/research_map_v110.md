# v110 研究地图

## 成功轨迹中的无效动作

- 候选计算：对最终成功轨迹逐步删除、替换或从中间状态重放，区分任务必要动作、可恢复错误、纯冗余动作和补偿动作；只对必要/有效步骤给予正监督。
- [ET-Agent](https://aclanthology.org/2026.acl-long.333/) 已明确指出只看答案正确会忽略冗余和不足的工具调用，并以自演化数据飞轮与两阶段行为校准训练把错误行为逐步校准为更优行为。
- [InT: Self-Proposed Interventions Enable Credit Assignment in LLM Reasoning](https://arxiv.org/abs/2601.14209) 已直接指出结果奖励会在成功轨迹中强化伪步骤，并用定位首个错误和单步干预形成细粒度信用。
- Run v071 已用同一模型动作在严格/宽容执行器下的配对差证明后端补偿会造成能力归因幻觉；v072/v093 又关闭动作替换、补丁重放与因果根因归因。
- 因而把轨迹删减用于训练样本清理，是现有行为校准、干预信用和 Run 内补偿归因的组合。

## 环境观测作为训练监督

- [SOAR](https://aclanthology.org/2026.acl-long.1624/) 已指出仅奖励成功动作会使策略不理解环境响应，并按前序动作的负熵给观测令牌分配正优势，使更新学习工具后果。
- “只奖励经工具观测证实的动作”因此不是空白；再接入 Run v006 的结果反事实敏感度也只形成已有监督信号组合。

## 能力缺口定向数据

- [TRACE](https://arxiv.org/abs/2604.05336) 已对比成功与失败轨迹，自动识别缺失能力，为每项能力合成训练环境、以能力是否被执行为奖励，并训练/路由能力适配器。
- FAMA 已按常见失败激活最小专门智能体集合；Fission-GRPO 已把当前策略的执行错误裂变成带诊断反馈的在线纠正样本。
- 因而从失败族生成定向课程或恢复样本也没有剩余方法核。

## 逐步信用与轨迹遗忘

- [STAPO](https://aclanthology.org/2026.acl-long.1308/) 已用相对状态平均行为的归一化熵定位轨迹遗忘步骤，并以轨迹奖励和独立惩罚联合优化。
- Error-Localized Policy Optimization 已用二分回放树定位首个不可恢复错误并进行层级优势归因；工具调用的熵下降监督与过程奖励也已有直接工作。
- 删除动作、测量成功翻转后重分配信用不会越过这组干预式逐步归因。

## 结论

“成功不等于每一步都值得学习”是真实且重要的问题，但问题层、监督对象和优化机制均已有直接方法。v110 不运行本地合成删减实验，不注册 Seed。下一版本进一步收缩到更新评价：当自演化系统拒绝一个有害更新时，评价是否能把该决定识别为有效进步，而不是只统计已接受更新后的性能变化。
