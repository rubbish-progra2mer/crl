# v159 失败归因

## 类型

`OBSERVATION_ENCODING_SELECTED_COLLECTIVE_DYNAMICS_CLOSED_BY_SEMANTIC_INVARIANCE_METAMORPHIC_AND_CONSISTENCY_PRIORS`

## 直接原因

- 相同内生状态重放、跨块噪声底和三模型复现已充分建立编码改变动作算子的现象；
- GPT 与 Claude 的同步方向反转排除固定通用最佳编码，却只导向模型条件化接口选择；
- 等价编码测试属于现成的智能体语义不变性与变形测试；
- 多编码集成属于提示集成／自一致性；
- 动作分布对齐属于提示扰动一致性学习和不变策略优化；
- 类型化规范器若承担决策则转为经典接口编译或控制器，若仍输出文本则没有不变性保证。

## 非原因

- 不是否认目标论文的闭环编码效应或跨模型复现；
- 不是把同信息控制误说成只改变长度、位置或任一单因素；
- 不是因本机模型或预算不足而跳过可改变新颖性判断的实验；
- 不是安全控制或 Run 终局。

## 决定

不注册实验或 Seed。保留“观察映射属于有效策略，且方向不可跨模型类推”的强证据；Run 保持 `ACTIVE`，下一版离开序列化、提示不变性、变形测试与表示对齐方法族。
