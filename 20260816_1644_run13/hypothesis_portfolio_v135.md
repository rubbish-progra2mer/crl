# v135 假设组合

## H1：原始跨任务 BCM 会奖励任务不变而非任务响应

- 状态：`SUPPORTED_AS_CONSTRUCT_COUNTEREXAMPLE_ONLY`
- 可证伪陈述：在成功率匹配的两任务合成载体上，固定策略的原始全局 BCM 高于任务响应策略，而同任务 BCM 无法区分两者。
- 机制：跨任务直接比较原始贡献方向，把任务需求引起的合法行为变化计作不一致。
- 反证条件：原始全局 BCM 不发生所述排序，或同任务控制能区分两个系统。

## H2：任务需求坐标运输可恢复预期排序

- 状态：`KILLED_BY_TRANSFORM_ORACLE_AND_DIRECT_PRIOR`
- 可证伪陈述：用已知任务变换将搜索/编辑需求运输到统一“所需操作”坐标后，任务响应策略的 BCM 高于固定策略，并在小扰动下稳定。
- 机制：只比较需求等价后的行为方向，不把正确适配误作漂移。
- 反证条件：运输后排序不反转，或反转依赖无扰动的精确单位向量。
- 边界：任务运输算子在本实验中由真值给定；如何从真实软件任务可靠估计它尚未解决。

## 组合决定

H1 的预注册反例成立，但它只界定原始 BCM 的解释边界。H2 没有存活为方法：受控工具/标签置换提供运输算子时，候选退化为变形测试与本 Run v083 已关闭的工具表面置换；从任务数据学习运输算子时，则归入成熟的任务条件表示、任务相似性和跨任务策略对齐。没有注册方法内核或 Seed。
