# v061 假设组合

| 草案 | 判定 |
|---|---|
| 不确定时选择低承诺动作 | 被工具参数不确定性、澄清和信息增益方法直接覆盖 |
| 把情境性纠正与稳定偏好分层 | 被偏好泛化基准、情节/语义记忆和抑制过度泛化方法吸收 |
| 通过保留可达方案集延迟不可逆动作 | 被可逆性理论、不确定规划和未来模拟吸收 |
| 按证明依赖解锁量调度下一义务 | 被蓝图依赖图、叶到根调度和成本路由直接覆盖 |
| 随机智能体评测的自适应取样 | 被 AgentAssay 与 Cer-Eval 直接覆盖 |
| 反例引导的开放策略类协议补全 | 保留到下一版本做最小可行性与差分检查 |

本版本不注册实验。
