# v154 研究图谱

## 等待窗并行思考

- [Second Thought: Reasoning in Parallel as LLM Agents Act and Observe](https://arxiv.org/abs/2608.13667) 在每轮主思考结束后并行启动检查、回忆、预演和备选四个分支；工具观察到达时中断分支，把已经闭合的原子想法接到观察之后供下一轮使用。
- 三个基准、三个推理模型的九个组合中，平均轮数全部下降；七个组合的一次通过率没有显著变化，两个 Terminal-Bench 2.1 组合分别显著提高 12.4 和 10.2 个百分点。配对重放报告任务中位延迟降低 10.9%。
- 四分支的每任务接口成本相对基线提高 66.4%--181.5%；只有 28.7% 的轮次产生非空收获，但这些轮次覆盖 86.7% 的等待时间。论文明确把按领域动态选择分支作为后续方向。
- 本 Run v106 已精确审计“真实观察到达后只释放相符预想”，判定为异步投机执行的命中提交语义；v131 又明确禁止重开 Second Thought 观察守卫。因此本版发现的“观察后陈旧推测倒置”不能注册为新候选。

## 分层信用分配

- [Teach the Magnitude, Not the Direction: Verifier-Bounded Credit Assignment for Multi-Turn Multi-step LLM Agents](https://arxiv.org/abs/2608.13179) 提出 CrEST：先按每轮独立可验证奖励计算组相对优势，再用带方向门和熵门的特权自教师信号放大每个词元的优势系数。
- 词元系数为 `A_turn × φ_t`，默认参数下 `φ_t` 位于 `[1, 1.084]`；方向门只在自教师与该轮优势符号一致时启用，熵门优先放大高惊讶度词元。
- Qwen3-4B 在 BFCL V3 平均准确率为 52.00%，强 RL 基线 MT-GRPO 为 49.25%；Qwen3-8B 分别为 50.00% 和 46.00%。WildToolBench 会话准确率分别达到 7.03% 和 9.38%。
- 训练使用单节点 8 张 H200，组大小 16，每步 512 条 rollout，最长生成 10,000 词元；每种方法只有一个训练种子，三次近贪心解码只测解码一致性，不能估计训练方差。
- 论文主文多次称该设计保留“由核验器限定的性能上限”，但附录准确限定了形式性质：正的 `φ_t` 只保留逐词元标量系数符号；重新加权仍会改变词元梯度在参数空间中的抵消，因此不保证聚合梯度方向、驻点或全局性能上限。附录也明确说绝对扰动界不是相对聚合梯度界。
- 构造接近抵消的词元梯度即可让不超过 8.4% 的正权重放大反转聚合方向；但这一事实已经由目标论文附录明示。用梯度投影、夹角约束或信赖域恢复聚合对齐，属于成熟的梯度手术／安全更新；用反事实重放分配跨轮延迟信用又回到 CausalFlow、Causal Agent Replay 和一般回报传播。

## 跨指令表面的遵从评价

- [Harness-IF: Evaluating Instruction Following Across Instruction Surfaces in Coding Agents](https://arxiv.org/abs/2608.11727) 把规则放在系统提示、工具描述、技能描述、项目文件和用户指令五个可配置表面，针对 60 个多轮编码任务、12 个前沿模型和三轮重复得到 2,160 次智能体运行及 40,104 条规则判定。
- 反先验准确率只统计被零注入探针或人工整理标为违背默认行为的规则。十二个模型的普通准确率为 72.1%--85.9%，反先验准确率为 66.1%--78.6%；每个模型都下降 3.6--7.4 个百分点，平均 5.81。
- 该指标是行为分层，不是目标模型的逐规则因果效应。九个零注入探针模型与十二个被评模型存在部分重叠；最终 282 条反先验标签中有 36 条来源未知，12 条与可恢复共识不同但没有保留覆盖理由。
- 86.8% 的规则行涉及语言模型裁判；200 条分层样本中只有 116 条形成干净的裁判交换配对，其一致率 62.1%、Cohen `κ=0.163`。论文据此只强调跨模型模式，不主张相邻排名。
- 对同一目标模型、同一任务和同一规则运行有／无注入配对，能直接估计规则带来的行为变化，避免把规则固有难度当作遵从性；但这只是标准的处理—对照消融。把配对效应再用于选择指令表面则退化为模型特定提示放置优化，不产生新的智能体状态或学习算子。

## 结论

三项都提供了有效的新证据，但没有留下可由当前资源验证、且能改变论文级方法归属的候选。Second Thought 是当前 Run 精确重复；CrEST 的聚合方向限制已由论文自陈，修复属于经典梯度对齐；Harness-IF 的目标模型配对扩展属于标准因果消融。`v154` 不注册实验。
