# v056 假设组合

本版本没有注册正式假设，也没有 Seed。

| 草案 | 预期计算差分 | 决定 |
|---|---|---|
| 批量部分成功分解 | 逐项效果状态与安全重试 | 被 `v001` 和非原子故障核验工作直接吸收 |
| 不可达任务证书 | 由可用工具证明任务是否可完成 | 被 FeasiGen、Agent Planning Benchmark 与 HyperAgent 直接覆盖 |
| 请求值—实际应用值绑定 | 下游只绑定实际应用值而非原请求 | 被成功响应核验、数值一致性和 Run 内既有版本吸收 |

由于每一项都在最低成本去重阶段满足杀死条件，禁止为了制造实验结果而注册缩窄版假设。
