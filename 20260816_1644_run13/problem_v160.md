# v160 问题定义

《完全记忆，代价几何？智能体记忆系统服务成本基准》（arXiv:2608.11879）把 Mem0、Hindsight 与 Mastra 观察式记忆同滚动窗口和完整对话历史放在统一服务成本账本下，覆盖最长 400 轮对话、两个推理骨干和 665 个 LoCoMo 问题。结果显示，记忆的检索、回答与写入成本强烈依赖具体后端和模型，不能仅由轮数或消息长度可靠预测；不同配置的成本—准确率前沿也没有单一赢家。

本版考察一个部署决策问题：在未来对话长度和查询需求未知时，智能体能否根据已发生的交互、记忆写入成本和预期答案质量，在完整历史、滚动窗口与外部记忆后端之间在线切换，并形成区别于阈值核算、经典在线切换和已有查询感知预算路由的新计算。
