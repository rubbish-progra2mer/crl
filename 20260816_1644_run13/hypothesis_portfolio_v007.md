# v007 假设组合

## H1：名义成功掩盖潜伏约束错误

- 状态：`SUPPORTED_LOCAL_PRIOR_COLLISION`
- 假设：模型编译出的工具提交策略中，存在通过一个高覆盖名义允许状态、但在完整状态空间上错误的策略。
- 致命条件：两个本地模型生成的编译有效策略几乎都语义正确，或名义通过的潜伏错误不足 8 个。
- 实验一：96 个候选全部编译有效，92 个通过名义状态，其中 28 个在完整状态空间错误；H1 存活。

## H2：逐约束激活剖面

- 状态：`ACTIVE_TEST`
- changed computation：对每个工具状态字段，在参考策略中搜索只翻转该字段就改变动作的最小成对世界；用全部成对世界评估候选策略。
- 最强轻量基线：使用完全相同数量、固定种子的随机状态世界。
- 致命条件：潜伏错误召回率优势低于 0.10，且候选选择后的完整状态准确率优势低于 0.05。
- 实验一：激活召回 1.0、单种子随机召回 0.8214，召回优势 0.1786。
- 实验二：相对一千次随机与候选分歧强基线，激活相对最强平均召回优势 0.3363；局部机制成立。
- 新颖性结论：AgentEval 已直接覆盖黑盒状态边界挖掘、路径重放和边界扰动，P098 覆盖逐约束双向激活；H2 方法候选被组合吸收。

## H3：激活剖面驱动的候选选择

- 状态：`UNSUPPORTED`
- 计算：从同一模型为同一政策生成的四个候选中，按激活剖面准确率选择，再在未用于选择的完整状态空间评估。
- 风险：若所有候选都相同或随机状态已足够，选择机制没有独立价值。
- 实验一：激活选择相对随机选择的完整状态准确率只高 0.0013，当前不支持独立选择价值。
- 实验二：相对最强基线选择优势为 0；H3 不成立。
