# v158 失败归因

## 类型

`FULL_GRAPH_EDGE_MARGINAL_INVALIDATED_AS_BUDGET_SELECTOR_BUT_CLOSED_BY_SUBGRAPH_OPTIMIZATION_AND_COALITION_PRIORS`

## 直接原因

- 预注册反例证明，完整图单边删减效应即使面对单调次模覆盖，也可在预算选择中取得趋近零的近似比；
- 缺口来自冗余与预算改变造成的条件分布变化，一次完整图排序不能替代集合级选择；
- 条件边际前向选择属于经典最大覆盖算法；
- 直接子图优化、结构感知合作博弈、多片段联盟解释和渐进通信剪枝已覆盖全部自然修复；
- 将这些先行移植到 E2 的监督标签不产生新的状态、更新规则或验证边界。

## 非原因

- 不是声称 E2-Explainer 的真实基准结果错误；
- 不是把合成覆盖反例外推为真实语言模型通信分布；
- 不是实验失败、资源不足或安全控制；
- 不是 Run 终局。

## 决定

记录严格方法边界，但不注册 Seed。Run 保持 `ACTIVE`，下一版离开通信拓扑归因、合作博弈和预算剪枝方法族。
