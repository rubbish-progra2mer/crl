# v127 当前记忆

- 连续通道容量大，不等于对齐后的前缀保留了发送方额外信息，更不等于接收方使用了这些信息。
- 当映射同时看到隐藏状态和对应词元嵌入时，评价必须固定词元身份再替换隐藏状态；否则消息替换效应混合了离散词元与连续残差。
- 对每条短消息分别白化两组高维点云会产生有限秩退化：在 (d\gg K) 和小正则下，白化行几何趋向由中心化约束决定，而不是由原始语义几何决定。
- 正交映射保持“白化后的几何”不能自动证明保留“白化前的上下文差异”；反白化、范数校准和词汇锚定还会继续改变最终前缀。
- 随机噪声前缀不是充分对照。至少需要纯词元嵌入、同词元异隐藏状态、其他样例、自生成和无消息对照，并分别测发送编码、接收敏感性和任务价值。
- 小模型四例机会水平探针只能作为诊断，不能写成总体反证；端到端结论需要论文模型、原基准、成对重复和等效性检验。
- 下一前沿避开潜通信、隐藏状态投影、表示对齐和多智能体消息因果审计。
