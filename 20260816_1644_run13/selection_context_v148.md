# v148 选择上下文

本版本从治理与人类发布门控转向可执行记忆对象。“编译专用智能体”表面上比文本检索更接近改变计算，但实现展开后仍是：从历史抽取规则、生成技能、质量筛选、按适用性路由，再用独立模型调用执行。当前 Run 已分别覆盖这些步骤。

目标论文最关键的缺失不是工程细节，而是公平基线。若把同一抽取出的偏好、任务蓝图和质量筛选结果作为检索内容交给相同模型，在相同总调用与词元预算下比较，才能识别独立执行上下文或多步蓝图的边际作用。当前无记忆基线把“有没有使用历史”和“如何使用历史”混为一体。

本地复现实验需要目标模型家族、嵌入服务、合成用户和同家族裁判，且即使完成也只重复原比较。制作一个规则化玩具专用智能体与文本提示对照，又只会测提示遵从，并落入 `v106/v130`。因此不下载或执行公开流水线，不生成 Seed、Reviewer、Formal 或 Review-support。
