# v084 选择上下文

v084 的四条路线均重要且仍未完全解决，但“存在能力缺口”不等于“存在方法空白”。行为纠缠已经有黑盒统计量和去纠缠集合加权；假成功已经有文本无关状态真值、轻量检测和终止门；科研有效性已有假设检验、过程对齐和论文复现任务；工具置信已有提示/轨迹校准、工具类型条件校准和奖励信噪比下限。

当前 Run 也已经覆盖共享证据、无独立性可靠性证书、交付承诺、执行差分、自适应验证污染、不可靠科研前提和不确定性传播。把这些组件重新组合成“独立评审 + 状态核验 + 置信门”会形成模块堆叠，而不是新的 changed computation。

下一前沿不得依赖模型家族作为独立性代理、最终陈述检测、一般统计检查表、论文复现量表、置信校准或信息效用路由。
