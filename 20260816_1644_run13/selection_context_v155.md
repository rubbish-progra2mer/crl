# v155 选择上下文

本版从 2026-08-14 的新公开工作中筛出 EnvACE，因为它把工具环境响应的生成直接并入策略参数，确实不同于本 Run 最近反复出现的等待窗口、信用权重和指令表面问题。最初可分离的问题是：同一参数同时选择动作、生成假想环境响应并接受同一成功奖励，是否会产生“自己提出动作、自己证明动作正确”的世界模型偏置。

精读后，这个问题不能安全地注册为新候选。《一个冻结模拟器并不够》已经从状态访问分布和策略梯度层面形式化单模拟器主导模式如何诱导策略利用，并公开覆盖同一模型双角色自博弈、推理期回应分布扩宽、异构模拟器轮换、双模型协同训练及历史检查点群体。它还在与 EnvACE 重叠的 `tau2-Bench` 上验证未见模拟器和真人迁移。因此，本版能提出的“多排演分支”“多个排演者”“历史排演者池”不是尚待发明的机制。

EnvACE 没有报告排演响应相对真实环境的校准与覆盖，仍留下一个评价缺口；但本地合成实验若发现自证偏置，只会复现模拟器坍缩。若未发现，则只能说明某个小规模提示配置暂未触发，不能推翻长时域训练风险。两种结果都不会改变候选的方法归属，所以不消耗本地实验预算。

下载两篇论文源码时出现一次公开服务 `HTTP 429`，随后通过官方网页正文完成核对。该现象仅作为外部访问速率边界，不计入科学证据，也未进行规避性重试。v029 的宿主安全边界保持原样，与本版判断无关。
