# v113 失败归因

## 类型

`FRONTIER_SIEVE_KILLED_BY_DIRECT_PRIOR_CLASSIC_COMPUTATION_AND_CARRIER_INVALIDITY`

## 直接原因

- 查询相对实体计数被 DocSage 的问题特定可连接模式、EA-Agent 的实体对齐与 GRIT 的关系路径覆盖，剩余计算是经典分组；
- 澄清问题可能构造偏好的主张需要真人行为或经真人校准的模拟，当前双模型对话无法识别该因果效应；
- 跨工具统计粒度被多表模式连接、问题相关列选择、分组/聚合与表预处理直接覆盖；
- 三条路线的本地合成实验都只能复现已知表推理或模型选项偏差，不能改变方法归属。

## 非归因与范围

- 不是实验反证：v113 没有注册或运行模型实验；
- 不是 v029 外部安全边界：本版本只检索公开学术资料；
- 不是 Run 终局：只关闭三个当前入口及其直接重命名组合，Run 保持 `ACTIVE`。
