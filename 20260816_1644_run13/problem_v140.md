# v140 问题

v140 从最新公开研究中筛到 *Scaling Automatic Research Agents via World Models* 的在线去偏理论。该工作用少量真实执行锚点拟合单调等距回归映射 `f(世界模型分数) -> 真实分数`，并声称在单调分数失真、独立有界零均值噪声、有限真实分数层和各层持续覆盖下，校准后的逐轨迹系统误差以 `O(1/sqrt(t))` 收缩到零。

核心问题是估计对象是否一致。论文实现的平方损失等距回归在无限样本下估计的是 `E[真实分数 | 带噪预测分数]`；证明则先按真实分数层估计 `E[带噪预测分数 | 真实分数]`，再把该结构映射求逆，并在最后一步把 `f(E[预测分数])` 当作 `E[f(预测分数)]`。当相邻真实分数层的预测分布重叠时，这两个对象通常不同。

本版只检验一个完全满足论文分数尺度假设的二层离散分布，判断实现中的人口等距回归是否仍保留非零逐轨迹系统误差，并给出一个一维策略梯度见证。实验为纯本地、有理数、有限支撑计算；不调用模型、智能体、外部环境或安全过滤器。v029 的宿主安全控制仍作为外部执行边界保留。
