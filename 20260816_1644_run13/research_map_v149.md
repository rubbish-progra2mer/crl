# v149 研究图谱

## 图结构漂移诊断

- [面向自主大语言模型智能体结构化漂移诊断与恢复的图强化学习框架](https://arxiv.org/pdf/2608.14109) 用同一个小语言模型承担五个角色节点：逐步对齐分类、已执行操作抽取、应用文档定位、可逆风险评价和最终回滚/升级决定。
- 节点共享“推理块加 JSON 答案块”模式，按节点标签采用不同键集合。路由器从外部提供的可疑漂移起点向前回看，连续 `K` 个对齐判断后停止；发现写操作时读取文档并分类可逆性。
- 小模型以组相对策略优化训练，奖励由八个格式/长度检查和一个冻结 14B 模型语义裁判组成。两个基础模型是 Granite 3.3 2B 与 Qwen 2.5 1.5B；内在评价只有 100 个节点提示，每项采样四次。
- AppWorld 端到端评价只有 40 个任务。第一类瞬时只读漂移上，训练后的 Granite 恢复模块得到 27.5% 任务目标完成率，无漂移上限为 35.3%，同图中的 GPT-4o 恢复模块为 32.5%。第二类持续只读漂移上，结果强烈依赖重新执行任务的主智能体：较弱主智能体下为 7.5%，较强主智能体下为 35.0%。

## 实际执行边界

- 第一节点不自主检测漂移起点，只细化外部检测器给出的信号。因此系统没有解决何时启动恢复。
- 端到端实验只覆盖消息历史回滚足够的第一类和回滚加警告的第二类。涉及环境写入的第三类不执行逆操作：只要发现写入就升级给人类；可逆性分类只由语言模型裁判评价，没有环境核验。
- 论文先指出真实漂移可能在错位与重新对齐之间交错，随后在工作范围中假设起点以后漂移单调；回看连续对齐段的停止规则因此没有在其声明的非单调模式上得到验证。
- 训练基线是同一图与同一节点提示下未经训练的小模型。没有单提示诊断、无图的同等训练、多独立分类器或直接规则抽取基线，故结果识别了窄任务训练效应，不能识别图分解本身的贡献。
- 格式奖励主导部分增益；风险节点的语义裁判只从 0.72 提高到 0.78，作者明确承认通用裁判可能漏掉虚构的逆接口。代码与数据只声明可向作者索取，不是当前公开可执行工件。

## 直接恢复与归因先行工作

- [MARS：用蒙特卡洛树搜索自主修复多智能体系统](https://arxiv.org/abs/2607.29055) 已把故障归因后的修复定义为搜索过程，用诊断指导扩展、故障分类增强评价和部分回放降低成本，并在 1,310 条可重放失败轨迹上报告 3.0%—12.1% 绝对提升及组件消融。
- [ASCon](https://arxiv.org/abs/2608.10646) 已用有向智能体—步骤图注意力统一故障智能体、错误步骤和失败模式归因，直接覆盖节点化轨迹诊断表示。
- `v116/v125` 已审计 AgentRewind 的上下文—受控环境对齐检查点和外部效果边界；ACRFence、Cordon 与当前 Run `v008/v034/v075/v108` 已覆盖效果账本、重放/分叉、语义事务、延迟提交和可逆补偿。
- `v061` 已记录幂等、可逆、可补偿与不可逆动作分类；`v103/v122` 已覆盖漂移起点、责任主体、首错步骤和因果归因。

## 自然扩展的归约

- 用模拟器回放最终决定并以是否恢复状态为奖励，是环境验证与基于执行的修复评价；MARS 已在可重放失败环境中搜索修复。
- 查文档确认逆接口，是工具契约核验；实际执行逆操作并复测，是 Saga/事务补偿和后置条件验证。
- 训练起点检测器，是逐步故障归因/变点检测；处理错位—对齐交错，则是一般序列分段或隐状态推断。
- 因而论文未来工作的每个可执行分支都有直接最近计算，组合为闭环不能形成独立方法核。

## 判定

目标工作证明小模型可被训练为固定诊断状态机中的多个角色，并在狭窄只读漂移上恢复部分完成率；它没有执行环境修复，也没有识别图分解的因果贡献。剩余闭环由直接故障修复搜索、检查点、事务与补偿工作覆盖，`v149` 不注册本地实验。
