# v095 研究图谱

## 现象一：不可回答问题上的过度搜索

- Over-Searching 系统考察查询、模型、检索与多轮交互，发现搜索对可回答问题通常有益，却会损害不可回答问题上的弃答；该效应在复杂推理、深度研究、噪声检索和多轮累积时更明显。
  - https://aclanthology.org/2026.eacl-long.361/
- 该工作已引入 OverSearchQA、每正确答案令牌数指标，并研究查询级与检索级缓解；负证据可以改善弃答。
- 当前 Run 的 v008 已研究查询的预期信息价值与停止，v010 已处理负证据覆盖，v019 已处理知识边界与弃答，v040 已处理证据不足，v081 已把继续检索绑定到显式充分性条件。

## 现象二：核验能识别、流程仍采纳误导知识

- MisKnow-Agent 在受控的任务特定错误文档上评估多种深度研究流程；论文报告，加入一篇误导文档会显著提高错误结论采纳率，而聚焦的跨模型核验能够识别保留样本的误导性，但整条流程仍可能采用它们。
  - https://arxiv.org/abs/2607.20891
- 其检索前和检索后防御只能降低而不能消除风险，作者据此主张在中间状态和最终综合阶段持续核验。
- 当前 Run 的 v006 已处理工具依赖与结果忽略，v021 已处理证据传输，v057 已处理行动前证据闭合，v092 已处理长期记忆写入准入。把聚焦核验结果再传给长流程，落在这些既有计算边界内。

## 现象三：专家真值需要迭代修订

- DeepFact 在隐藏已知答案主张上发现，无辅助博士级专家的准确率只有 60.8%。其 Audit-then-Score 允许核验器提交证据、审计员裁决争议并在评分前修订标签和理由；三轮后专家准确率升至 90.9%。
  - https://aclanthology.org/2026.acl-long.1586/
- 该工作已经给出版本化深度研究事实性基准、可审计理由和主张级核验器。
- 当前 Run 的 v030 已处理评价语义不匹配，v062 已处理协议可识别性，v080 已处理时间证据，v087 已处理模拟器与评价伪影。让真值随证据审计而更新属于上述评价路线的直接实例。

## 结论

三类现象都是真实且重要的，但都已有直接问题定义、基准或方法；当前 Run 也已有吸收其剩余组合的计算边界。对第一类做本地不可回答问答、对第二类放置合成误导文档、或对第三类模拟标签修订，都只会低规模复现现有工作，因此 v095 不注册实验。
