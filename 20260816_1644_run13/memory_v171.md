# v171 当前记忆

## 新增正向证据

- 持久代理规则会出现灾难性记忆：规则仍在，但允许安全删除的因果理由消失，导致理性维护器趋向只增不减。
- 年龄越大删除概率越低、多人维护放大该趋势，以及整文件重写后立即再增长，能把理由遗失与规则陈旧区分开。
- 新增持久规则时应同步保存“为什么加入”，并与执行提示隔离；只保留规则文本不足以支持后续维护。

## 新增负记忆

- 不把提示评论替换成可执行见证后宣称新方法；这是目标论文机制的工程强化。
- 不把留一规则评测、联盟边际归因或集合覆盖包装为新的提示垃圾回收算法；技能压缩与测试最小化已覆盖。
- 不把规则—测试追踪关系本身当作智能体方法贡献，除非出现新的在线因果识别或分布外安全删除保证。

## 安全与 Run 状态

v171 只研究良性项目规则维护，没有执行外部代码、模型或安全敏感任务。v029 继续仅作为外部执行边界保存。Run 保持 `ACTIVE / AUTONOMOUS`，无实验、Seed 或终局。
