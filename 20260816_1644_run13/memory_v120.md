# v120 当前记忆

- 工具枚举缺少 `None` 与包含 `None` 后仍发生概率边界移动，是两个不同问题；前者是不可达，后者是条件分布失真。
- 首行停止与词元枚举可以方向相反，必须以三条件设计拆分，不能把总差统一归因于语法掩码。
- “先自由思考、后结构化输出”已有草稿条件约束解码与透明两遍执行，今后不得再作为新方法种子。
- 扩大可接受表面形式会引入等价表述数量偏置；若需要按语义类聚合，必须先对照表面形式竞争、结构条件最小贝叶斯风险和全局约束采样。
- PA-Tool 已直接实现“让工具模式适应模型而非训练模型适应模式”。工具名改写或别名扩充不足以形成新方法。
- 下一前沿避开约束解码、工具路由、不调用与结构化渲染，转向信息获取或推理预算分配中的结构性计算差分。
