# v128 当前记忆

- “没有唯一文本答案”与“没有唯一最优行动”是两层不同的不确定性；后一层必须由用户效用、错误损失、交互成本和可逆性价值定义。
- 多维大语言模型评审可以描述冲突处理行为，但不能在缺失效用函数时识别普遍最优政策；维度总分也不应被越界解释为部署效用。
- 若只保留所有可能最优的行动，可得到集合值可采纳前沿；没有受约束的损失函数族时，该集合通常过宽，不能独立产生可验证的行动策略。
- 一旦补入潜在用户状态信念、行动效用与提问成本，澄清/提交选择就是信息价值计算；工具参数上的结构化不确定性与完美信息期望价值已有直接实现。
- 论文主动声明结果是描述性的、策略只是正向基线时，审计必须尊重主张边界，不能把缺少更强目标写成反证。
- 不用无法复现原评审器的本地替代模型实验来制造“评分偏差”证据；先判断该偏差是否会改变论文的实际主张和候选方法差分。
- 下一前沿避开个人记忆冲突、澄清、弃答/延后、信息价值、可逆行动选择和风险条件化提交。
