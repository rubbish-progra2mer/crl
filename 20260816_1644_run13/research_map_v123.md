# v123 研究图谱

- [P2Skill](https://arxiv.org/abs/2608.14094) 的在线推理管线在本地分解、路由和去标识，并让每个在线云端请求通过确定性标识符匹配器。论文据此把传输泄漏定义为 87 个已标注标识符是否出现在记录的在线云端请求中。
- 同一论文的技能精炼循环却明确执行两次不同的云端调用：云端参考者直接回答原始提示 `x`，云端评估者又对三元组 `(x, y_s, y_r)` 评分。其后云端监督者才仅接收聚合失败统计。因此，“监督改写不看失败样例”不能推出整个精炼控制面不看原始样例。
- 该精炼集来自公开或合成式基准组合，论文没有证明实际用户私有样例已因此泄漏；可成立的结论是架构威胁模型与泄漏指标没有明确覆盖参考者、评估者这两个控制面接收端，而不是声称发生了真实用户数据事件。
- [DP-OPT](https://arxiv.org/abs/2312.03724) 已直接把“向提供商发送私有训练数据会加剧隐私问题”作为出发点，在客户端生成离散提示，并用差分隐私的上下文学习集成限制提示对私有示例的泄漏。
- [Flocks of Stochastic Parrots / PromptPATE](https://arxiv.org/abs/2305.15594) 已指出直接与由私有提示形成的教师群交互会泄漏信息，转而通过带噪多数聚合把知识转移到可公开部署的学生提示；它给出了受限黑盒接口下的显式差分隐私核算。
- [CBP-Tuning](https://aclanthology.org/2025.emnlp-main.991/) 已把服务端任务无关提示生成器与用户端无梯度定制分开，目标就是不上传私有数据，只传每任务的定制向量。
- [Fed-BBPT](https://arxiv.org/abs/2310.03123) 与 [FedPrompt](https://arxiv.org/abs/2208.12268) 已把私有数据留在客户端、通过聚合提示或提示生成器完成协同适配；这直接覆盖“统计或参数出端、原始样例不出端”的自然修复方向。
- [From Conventional Web Privacy to Agentic Disclosure](https://aclanthology.org/2026.privatenlp-main.1/) 已主张运行时外部调用是智能体隐私分析的关键单元，并要求从仅看最终输出扩展到逐调用参数分析。把所有云端角色列为接收端因而是必要的审计修正，但不是新的改变计算。

P2Skill 的控制面范围遗漏是文本上可直接复核的评测缺口；然而“枚举全部外部接收端”属于既有信息流审计原则，而“只上传带隐私保证的聚合量或适配产物”又被差分隐私和联邦提示学习直接覆盖。候选不能仅凭修正一个系统的泄漏分母形成独立方法核。
