# v011 研究记忆

## 已排除复用

- 不再把“对每个模型重复调用并用正确率软标签训练路由器”当作新颖点；Switchcraft 已直接实现。
- 不再把“恢复状态、跨模型分叉、同模型对照”当作新颖点；Replay Gap 已直接实现并公开工具链。
- 不再把“执行完整后缀得到逐步路由标签并训练路由器”当作新颖点；TwinRouterBench 已实现相近监督链。
- 不再把“潜在结果 + 成本敏感遗憾最小化”当作新颖点；Causal LLM Routing 已覆盖。
- 不以公开 Replay Gap 数据直接训练终局处理效应路由器：目前只有 5 个双模型成功差异，证据量不足。

## 可迁移事实

- 智能体路由的静态未来不可信，任何逐步路由主张都应优先做动态闭环评测。
- 同模型控制能测服务栈噪声，但动作差异稠密不等于终局效用差异稠密。
- 新候选若依赖终局二元奖励，应先审计可用标签密度，再投入路由训练。
