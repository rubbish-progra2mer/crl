# v169 失败归因

## 类型

`CANDIDATE_CONDITIONAL_PILOT_FIDELITY_CLOSED_BY_INPUT_DEPENDENT_AND_ROBUST_MULTI_FIDELITY_OPTIMIZATION_PRIORS`

## 直接原因

- 训练集大小、训练预算和部分学习曲线早已作为成本不同的保真度变量被联合建模；
- 低保真代理可能失真或有害，已有稳健多保真方法专门处理；
- 同一代理在不同候选区域具有不同保真度，已有输入依赖保真度模型直接覆盖；
- 主动选择单位成本信息量最大的候选—代理查询也是既有获取函数，而非智能体特有计算。

## 非原因

- 不是研究偏好模型无效；论文报告了端到端分数和预算效率增益；
- 不是小试验没有异质失真；原论文的代理策略分析明确显示不同简化操作效果不同；
- 不是资源、安全控制或环境导致无法实验；
- 不是 Run 终局或用户终止。

## 决定

不注册实验或 Seed。v170 转向 PACE-Bench 暴露的机制重设计瓶颈，Run 保持 `ACTIVE`。
