# v146 研究图谱

## 差分故障注入

- [Validating LLM-Modernized Scientific Software Through Differential Fault Injection](https://arxiv.org/html/2608.14527v1) 在 GAMESS 共享自洽场驱动的十二个位置对旧实现与大语言模型现代化实现注入相同、确定性的瞬态、持续、并行和降精度故障。
- 共享驱动保持不变，被转换的积分内核是唯一变化单元；主验收标准是逐对比较结果分类、迭代数、注入数与最终能量，而非只比较边际分布。
- 2,200 多次运行揭示收敛阶段相关吸收、并行副本死锁、降精度假收敛与跨模块微小传播；200 对主比较全部一致，测量引出的单行同步修复又在 40 对运行中一致。
- 人类开发者定义故障模型和验收准则，智能体只接收有界修复任务并提出代码修改。系统的科学计算由应用特定注入点、确定性回放、旧/新成对差分和外部验收器承担。
- 论文明确限制结论只覆盖测试过的位置、幅度、阶段与配置，不声称所有故障上的程序等价。

## 与智能体方法的边界

- 把同一异常场景施加到旧技能/旧智能体与新技能/新智能体，再比较结果，是变形/变异/差分测试；智能体是否生成修改不改变测试算子的归属。
- 当前 Run `v062` 已审计 AgentAssay 的固定变异算子、变形关系、三值统计判定和预算分配，也已实验证明语言模型生成的碰撞变异没有超过程序化固定变异。
- `v131` 已记录 SpecPath 的契约等价历史敏感性，并把要求所有等价历史行为一致归入变形测试/规范稳健性。
- 因而“自动从修改差分生成异常注入点”若靠语言模型猜测，只是变异生成；若靠程序切片、数据流或接口差分，则属于成熟软件分析。没有留下新的文本/工具智能体状态或更新算子。

## 结构化需求强基线

- [ISO-Grounded NFR Specification](https://arxiv.org/abs/2608.13742) 在固定模型快照、四类非功能需求、每条件十个提示变体和配对非参数分析中，比较一行自然语言、ISO 丰富自然语言与相同 ISO 内容的结构化 JSON。
- ISO 语义扩充改善部分静态质量代理与措辞稳健性，但没有可靠提高功能正确性；错误处理的扩展测试通过率反而下降。
- 固定 ISO 内容后，丰富自然语言与 JSON 的正确率差异绝对值不超过 `0.023`。语义内容而非序列化格式承担主要效果。
- 这与本 Run `v001` 的负结论一致：显式分面契约没有超过通用策略提示；把相同语义换成结构化载体不构成新计算。

## 系统级覆盖

- [Engineering Reliable Coding Agents](https://arxiv.org/abs/2608.13867) 的公开摘要已把任务构造、执行环境、检索、状态、权限、核验、可观察性与资源作为依赖链，并汇总 206 条可靠性记录。它是系统方法综述，不提供一个可从当前候选中分离的新局部算子，但进一步说明单层改进不能自动归因到模型。
