# v057 选择上下文

`v057` 从工具返回解释转向执行前的工具选择。实验完全本地，只让模型生成模拟函数调用，不连接任何外部服务或执行动作。

选择该候选的原因是它保留一个可测差分：工具的动作能力相同，但最终效果的可观察性不同。实验同时设置强通用提示，防止把普通提醒包装成方法；闭包卡由同一工具说明中的字段关系机械生成，不增加隐藏真值。

在实验完成前，不把该候选称为 Seed，也不主张新颖性。

## 实验后决定

原始说明在两个模型上均达到 12/12，强提示和闭包卡没有增益。当前合成功能等价工具对没有暴露“忽略未来证据可达性”的失败现象。把说明改得更隐蔽只会转成文档诱饵或能力幻象，与 Tool Preferences/Canary Tools 重合，因此不扩大实验并关闭候选。
