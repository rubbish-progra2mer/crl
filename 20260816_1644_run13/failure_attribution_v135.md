# v135 失败归因

## 类型

`CONSTRUCT_COUNTEREXAMPLE_SURVIVES_METHOD_KILLED_BY_TRANSFORM_ORACLE_AND_DIRECT_PRIOR`

## 成立部分

- 成功率匹配时，原始全局 BCM 可系统性奖励固定行为并惩罚任务需求引起的正确变化；
- 目标论文的同任务控制在该确定性反例中不能区分两种系统；
- 现象对 101 个小扰动种子稳定。

## 方法死亡原因

- 若任务运输算子由受控工具/动作置换给出，方法退化为变形测试，且与 v083 的工具标签置换负记忆和 v131 的等价关系测试精确相邻；
- 若运输算子从真实任务数据学习，则归入已有任务条件表示、任务相似性和跨任务策略对齐；
- 单纯在余弦前交换或残差化坐标只是评价后处理，没有新的智能体在线计算，也没有解决真实任务需求算子的可识别性。

## 非原因

- 不是实验反证；预注册反例实际成立；
- 不是目标论文结果被证明错误；本实验没有真实模型轨迹；
- 不是 v029 宿主安全边界；本版没有安全过滤或绕过研究；
- 不是 Run 终局。

## 决定

保留测量构念负结果，拒绝方法升级；Run 继续 `ACTIVE / AUTONOMOUS`，下一版本转向不依赖任务变换或标签置换的结构对象。
