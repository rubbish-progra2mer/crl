# v116 问题

v116 在 v115 的结构候选被公平基线否决后，使用 facts-only 主动诊断判断下一前沿是否仍被“分解、闭合、门控”搜索盆地支配。诊断确认 Run 无索引污染或陈旧来源，但 115 个科学版本只有 15 次 Recorded 和 3 次 Formal / Review-support 尝试；主研究者据此筛查时间动态、恢复、主动探索、意图推断和证据聚合等结构不同对象。

候选包括：执行失败后的对齐回退、从轨迹学习策略自动机、未知环境中的主动探索、不可消解个人记忆冲突、证据数量改变决策阈值、未知游戏中的目标推断，以及从图形界面动作前缀主动推断用户意图。目标不是把这些新论文标题直接变成方法，而是检查其最小残差是否已被直接方法覆盖。
