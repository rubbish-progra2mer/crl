# v090 研究图谱

## 当前 Run 精确先行

- v009 已定义同一一手证据被多个智能体转述后形成虚假多数的问题。
- v009 的候选计算为证据根继承与唯一根计数，保证复制、重排或多跳转述不增加支持质量。
- v009 的最小实验已表明构造规则有效，但随后核到传统社会学习和分散式信息融合中的数据乱伦消除、重复计数消除与依赖感知融合，因而归档为先验碰撞。
- v009 已把“没有可信根标识时，从轨迹和语言消息中在线推断依赖”列为可重开条件；v090 没有新的可校准依赖估计器、监督信号或大语言模型特有计算。

## 与 v089 的区别

v089 关注一个主张沿引用链来自哪里；v090 关注多个表面来源是否统计独立。两者问题不同，但 v090 的核心计算与 v009 完全相同。

## 结论

网页复制簇、共同原始稿件和多智能体转述都可归约为同一观测被重复融合。当前候选没有满足 v009 的重开条件，因此不进行外部检索或重复实验。
