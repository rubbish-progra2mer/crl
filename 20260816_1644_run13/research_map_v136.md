# v136 研究地图

## 路线 A：策略相对优势的交互残差

- [ARC: Fair Relative Advantage Comparison in Open-Ended Real-World Interaction](https://arxiv.org/abs/2608.13622) 用同策略中心化降低开放式交互中策略差异造成的不公平比较。v136 考虑的残差是：全局策略主效应可能是风格偏置，但任务条件下策略效果的交互项可能是自主策略选择所必需的信号。
- 候选计算原型是两因素分解：删除提示/任务无关的策略主效应，保留任务与策略的交互优势。它比再次做同策略分组更窄，但并不构成新的方法差分。
- [Information-Theoretic Reward Decomposition for Generalizable RLHF](https://arxiv.org/abs/2504.06020) 已把奖励显式分为提示无关的响应项和提示相关的提示—响应交互项；DARM 也用条件互信息保留提示敏感信号并抑制响应侧捷径；[Robust Reward Modeling for LLMs via Causal Decomposition](https://arxiv.org/abs/2604.13833) 进一步直接表达了抑制风格伪相关同时保留提示意图的目标。
- 个性化群组归一化和异质处理效应估计又覆盖了“不要用总体中心化抹平条件异质性”的统计结构。若没有新的可识别状态、干预或在线决策，候选只是固定效应/奖励分解在 ARC 场景中的应用。
- 当前 Run v133 已处理 ARC 的同策略分组；v136 的交互残差虽不与其完全相同，但被上述直接分解先验关闭。

## 路线 B：自演化外壳的共享核心与局部残差

- [HELIX: Model–Harness Co-evolution for Recursive Self-Improvement](https://arxiv.org/abs/2608.13951) 把外壳表示为有来源轨迹的类型化端口、原子和配方，并报告一次代码修复演化轮次及可验证训练记录；论文自己也承认尚未训练更新后的模型、缺少多轮递归和通用能力回归控制，而且多个组件与选择预算同时变化。
- [One Recipe, Many Harnesses: What Self-Evolution Encodes Across Languages and Models](https://arxiv.org/abs/2608.10178) 固定 TRIAGE 配方，在 8 种语言与 3 个模型上使用类型化失败路由和可证伪编辑契约。它已经直接测量抽象纪律的共享核心与 20%–40% 的生态专属实现，并通过外壳移植、通用外壳蒸馏和目标生态原生再演化三条路径检验可移植性。
- 该工作报告移植在 20 个有向语言对中的 18 个有益，但 14 个仍低于原生再演化；在 Java、C++ 与 TypeScript 上，通用蒸馏只恢复原生增益的 48%–68%。这正面占据了“共享核心＋局部残差”的现象、测量与决策语义。
- 论文的长时程、多目标任务局限是真实边界，但仅把任务换成长时程不会产生新机制；它还明确报告外壳循环未能发现植入的新环境操作事实，以及预装能力工具在其预算下反而为负。若要继续，必须找到与迁移/蒸馏/再演化不同的状态变量或因果可识别性。

## 当前 Run 精确去重

最新研究流中的 ICL 状态交接、消息轨迹价值、技能演化、主动探索、轨迹回放、数字孪生、活体基准、遗留环境和灾难性记忆等方向，分别与 v107/v124、v106、v106/v131、v116、v125/v131、v129、v119/v130、v108 和 v058/v098 重复。本版不据标题差异复活这些计算族。

## 结论

ARC 路线死于直接奖励分解先验；外壳路线死于同问题、同计算和同决策语义的直接自演化先验。两者均未达到本地实验前所需的最小新差分。
