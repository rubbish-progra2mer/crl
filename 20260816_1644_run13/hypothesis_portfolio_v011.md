# v011 假设组合

## H1：对照底线校准的状态分叉路由

- 状态：`PRIOR_COLLISION`
- changed computation：在同一恢复状态上配对执行小/大模型续跑，并用同模型重跑的效用方差决定跨模型效用差是否足以签发训练标签；不确定状态弃权或路由到强模型。
- 最强组合基线：Replay Gap 的状态分叉与同模型对照 + TwinRouterBench 的执行验证逐步路由监督 + Switchcraft 的重复调用软标签 + Causal LLM Routing 的成本敏感遗憾最小化 + 通用选择性分类。
- 最小可行性审计：在 Replay Gap 公开轻量索引中，按运行、实例和分叉步配对小/大模型终局结果。
- 审计结果：358 个完整状态对中只有 5 个终局成功差异，全部为大模型单独成功；353 个为两者均失败。有效处理标签率为 1.40%，95% 威尔逊区间为 0.60%–3.23%；随机 20% 留出集期望只有 1 个有效标签；同模型对照成功翻转为 0。
- 终止理由：方法计算是最新直接工作的组合，剩余“按噪声底线弃权”属于标准统计筛选；公开分叉数据又不足以训练并可信评测该组合。引入稠密过程奖励或主动分叉采样会产生新的未验证方法问题，不能作为本假设的无成本修补。
