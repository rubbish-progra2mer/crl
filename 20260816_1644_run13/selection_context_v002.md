# v002 选择上下文

1. v001 的状态分面契约被强提示基线吸收，因此选择正交的工具发现阶段问题。
2. 共享论文库先支持了一个真实张力：文档扩展能改善检索，但语义相关工具增多、描述编辑和候选表过宽都会损害最终选择稳定性。
3. 原拟议方法是近邻感知的相对边界扩展，并要求等事实源、等文本预算、顺序抵消和检索—选择双层评测。
4. 最新原始论文核查发现 ToolExpNet 对“相似工具关系、细微差异探索、区分易混工具的描述重写”构成直接方法级碰撞；ToolObserver 的比较式描述又形成独立复现线。
5. 因此不把一个已知提示模板包装成新方法，也不启动缺乏方法差分的实验。候选在先行工作门终止。
