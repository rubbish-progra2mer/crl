# v135 选择上下文

## 选择理由

facts-only 诊断显示此前版本明显偏向文献级闭合，v135 因而优先选择可在本地确定性复现、且当前实验记录较少的行为测量构念。目标论文的公式、同任务控制、作者限制与官方实现均可公开核对，适合在不调用模型和外部工具的条件下进行高信息量否证。

## 实验前承诺

- 成功率、任务数量、指纹维度、原始 BCM、同任务 BCM、需求对齐 BCM 与 101 个扰动种子均在执行前固定；
- 只要任一预注册排序失败，就关闭构念缺口；
- 即使反例成立，也必须另过运输算子可实现性、最近公平基线、Run 内精确记忆和直接先行工作审计；
- 不把仓库实现不完整性当作方法新颖性。

## 实验后决定

构念缺口成立，但方法差分未通过先行工作与 Run 记忆审计。v135 保留一条测量负结果，不注册 Seed，不请求 Reviewer，不进入 Formal/Review-support 实验。
