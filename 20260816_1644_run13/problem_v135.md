# v135 问题

连续四个版本主要由文献碰撞关闭后，v135 使用 facts-only 活跃诊断重新选择“先找可复现现象，再问方法”的路径。诊断只提供机械事实：截至 v135 前共有 134 个科学版本，而 Recorded 尝试集中在结果语义、证据闭合、状态路由、观察消费、执行补偿、论证泄漏、流式结果、话语记忆、角色闭合与轨迹归因等少数结构；它不作科学结论。

本版从最新公开研究流筛出跨任务行为一致性度量，询问：不同任务本来要求不同策略时，直接平均跨任务轨迹指纹的余弦相似度，是否会把正确适配算作不一致、把固定行为算作一致；目标论文的同任务重复控制是否足以消除该问题。

边界是度量构念与良性本地合成实验，不涉及 v029 的网络安全边界、安全过滤器或绕过内容。
