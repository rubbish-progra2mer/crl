# v126 当前记忆

- 双向错误率不等于机制识别：错误阻断显著高于错误放行，只能说明当前数据上的决策方向，不能单独解释模型为何阻断。
- 镜像比较要同时固定标签、文本难度、非目标风险标志和证据复杂度；只翻转验证状态但不匹配这些量，不能把差距唯一归因于历史事故记忆。
- “风险触发存在”与“风险当前未解除”必须分开；但这种分解已经由 SteerBench-Work 明示，不能作为本 Run 的方法新颖性。
- 签名证明来源，不自动证明时效、范围、目标绑定或当前资格；完整提交授权至少还需验证这些边界条件。
- 描述式单轮门控不能替代真实工具提交评价，也不能测阻断后的恢复、升级或继续行为。
- 下一前沿避开安全门控、权限执行、签名授权、提交时见证与拒绝校准。
