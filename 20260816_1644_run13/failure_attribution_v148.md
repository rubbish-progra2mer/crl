# v148 失败归因

## 类型

`COMPILED_PERSONALIZATION_CLOSED_BY_AGENT_SKILL_PROCEDURAL_MEMORY_PRIORS_AND_MISSING_EQUIVALENT_RETRIEVAL_BASELINE`

## 直接原因

- 专用智能体由历史规则抽取、技能生成、适用性路由、独立模型调用和质量门控组成，均有直接计算先行工作与 Run 内负记忆；
- 目标实验没有检索式记忆基线，无法支持“编译优于检索”的核心比较主张；
- 主要胜率条件化于已经触发的子集，正式组件消融、成本比较、真人评价和跨模型验证均缺失；
- 最新记忆后端匹配研究也明确暴露组件捆绑、非成本匹配和置信区间重叠，不能为结构因果优势补证。

## 非原因

- 不是本地实验失败；
- 不是公开代码不可用；
- 不是宿主安全边界；
- 不是 Run 终局。

## 决定

归档编译式个性化、专用智能体群和两阶段技能触发路线。Run 保持 `ACTIVE`，下一前沿离开长期记忆、技能编译、个性化路由和合成用户评价。
