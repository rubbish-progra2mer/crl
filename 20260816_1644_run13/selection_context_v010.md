# v010 选择上下文

1. v009 因传统分散式信息融合的重复计数消除而终止；v010 刻意转向单智能体工具查询完备性。
2. 固定知识库支持错误成功、工具契约不完整和检索非穷尽等失效，但没有提供足以建立新 changed computation 的直接差分。
3. 公开最近邻检索发现 DADL 已把分页策略放入声明式工具运行时，并支持透明抓取全部页面；其 `max_pages` 边界还明确暴露了“自动分页未必等于绝对完整”的工程条件。
4. 数据库研究从 1996 年起已直接研究不完整数据库上的查询答案完备性；部分闭世界、完备性陈述和否定推理均有成熟形式化。
5. 因此不执行低信息量的合成分页实验，H1 不进入 Seed。
