# v156 失败归因

## 类型

`SCATTERED_PERSONAL_INFORMATION_LOCALIZATION_CLOSED_BY_STRUCTURED_SUFFICIENCY_QUERY_PLANNING_AND_ARGUMENT_PROVENANCE_PRIORS`

## 直接原因

- SPIEval 的失败标签是结果层证据，不能唯一定位查询、召回、消歧、整合或复制中的因果节点；
- 缺口驱动的继续检索已由结构化充分性判断和 Run 内检索停止工作覆盖；
- 逐参数证据绑定与执行前支持检查已有直接相邻工作；
- 搜索算子切换和竞争候选验证仍属于通用查询规划、检索优化与接口工程；
- 可做的本地合成实验无论正负都不会改变上述新颖性判断。

## 非原因

- 不是 SPIEval 的经验现象不真实或评测无效；
- 不是把“参数值错误”强行解释成某一种未经测量的原因；
- 不是宿主安全控制、公开服务访问限制或本机资源造成的科学失败；
- 不是 Run 终局。

## 决定

不注册实验或 Seed。保留 SPIEval 作为“散落个人信息任务主要败于定位和参数支撑，而非分页或工具选择”的问题证据；Run 保持 `ACTIVE`，下一版离开检索充分性与参数溯源方法族。
