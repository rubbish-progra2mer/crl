# v169 当前记忆

## 新增正向证据

- 自主研究代理的关键资源问题是候选生成速度远高于全规模实验执行速度；执行前排序能实质改善最终结果和预算效率。
- 廉价试验不是统一缩放：子采样、少折数、少轮数和删组件可能保留不同的候选属性，也可能改变排序。
- 研究偏好评估应同时报告最终分数、预算、低／高保真排序保持率和由代理引起的赢家翻转率。

## 新增负记忆

- 不再把候选特定的小试验可靠性包装为智能体新机制；输入依赖多保真优化已直接覆盖。
- 不再把不可靠低保真源的熔断、回退或加权包装为新方法；稳健多保真优化已有理论与算法。
- 不把“用代码语义挑选降配方式”单独视为贡献，除非它产生超出既有保真度建模的新计算和可证伪差分。
