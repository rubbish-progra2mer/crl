# v112 研究图谱

## 问题单元

待检验单元不是一种记忆架构，而是一个准入决定：给定对话和两个规范化候选命题，哪些命题有充分话语依据被保存为关于用户的持久事实。关键错误是把嵌入在他人陈述、直接引语、假设/反事实、愿望/计划或否定范围中的正命题误收为用户事实。

## 最接近的直接工作

- [Very Long-Term Conversation Memory for LLM Agents](https://aclanthology.org/2024.acl-long.747/) 建立长时对话记忆评价，并把说话者归属错误列入错误分析；它没有把说话者、引语、模态与否定联合成记忆准入任务。
- [GroupMemBench](https://arxiv.org/abs/2605.14498) 直接评价多人对话中的说话者落地信念跟踪，是当前问题在“谁持有该事实”维度上的最近工作；其核心不是单用户长期记忆对嵌入话语范围的联合准入。
- [Hindsight](https://arxiv.org/abs/2512.12818) 区分事实、信念与经验并提供长期记忆组织，但现有材料没有给出上述五类范围的成对准入探针。
- [A Bag of Tricks for Dialogue Summarization](https://arxiv.org/abs/2109.08232) 分别讨论多说话者与否定处理，载体是对话摘要而非持久用户事实准入。
- [PAED: Zero-shot Persona Attribute Extraction in Dialogues](https://aclanthology.org/2023.acl-long.544/) 直接研究人格属性抽取，但没有形成上述联合话语范围的长期记忆准入基准。

## 精确差分

前置检索没有找到同时满足以下三点的直接先行工作：

1. 输出是关于用户的持久记忆准入，而非一般摘要、事实性判断或多人信念问答；
2. 在同一评价中用成对正反例覆盖说话者、引语、假设/反事实、愿望/计划和否定极性；
3. 把普通明确指令作为吸收基线，只有该基线仍保留稳定误收时才允许继续方法研究。

因此 v112 只登记现象探针。若普通指令没有稳定误收，或一条直接作用域检查指令已经显著修复，则停止该路径；不以现有组件重新包装成方法。
