# v121 选择上下文

v120 关闭约束输出后，v121 转到接口之外的资源分配：工具是否值得暴露、异质成本下应该暴露多少，以及是否应在看到输出后改变后续获取。该问题不涉及任何安全过滤机制或规避行为。

候选差分很快被目标论文自己的边界和直接前作夹住。固定前缀确实会在部分收益与极端成本异质性下付出代价，但论文已用非前缀得分/成本规则展示这一点，并在理论上给出价值/成本的集合选择条件。进一步改成观察自适应，则直接进入在线上下文潘多拉盒、成本感知探索和迭代检索停止。

v121 因直接方法碰撞在实验前关闭，不是成本感知工具获取无效，也不是 Run 终局。下一前沿离开路由、工具集选择、检索深度、停止策略和测试时预算分配，优先检查多智能体或长上下文系统中“信息被谁改变、何时失去可追责性”的计算边界，同时先排除来源追踪与事实—信念分离的既有路线。
