# v020 研究图谱

- Heuresis（arXiv:2606.25198）在 3,222 个已评分运行上发现现有贪心、质量—多样性、开放式和好奇心策略都没有扩展质量—新颖性前沿，并把缺失能力定义为判断低初始分构想究竟是机制差，还是首次实现尚未优化；其 Curiosity 只测预期误差惊异，不测精炼上行空间。
- 本地非支持性诊断使用 Heuresis 的 BBOB 函数、实例、种子、函数评估预算和计分公式，对两个本地模型、八个固定构想各生成三次独立实现，共 48 条记录。均匀随机控制三次完全一致；38 条得到有限分数，10 条无穷或未形成汇总。
- 14 个非控制模型—构想组中，6 个首次不及均匀随机控制 `1.439247`，但后两次至少一次反超，比例为 42.9%，Wilson 95% 区间为 21.4%–67.4%；有至少两个有限实现的非控制组，其组内极差中位数为 `1.773802`。无效实现分别封顶为 3、4、6 时，单次实现组内相关系数均约为 0.09–0.11。
- 该诊断存在严格边界：只覆盖两个小模型和一个 CPU 黑箱优化任务；独立重实现不是同分支持续精炼；公开驱动的 POSIX `SIGALRM` 在 Windows 不可用，本地适配只保留任务、种子、函数评估预算和计分公式，以整套进程超时替代单例闹钟。
- One Run Is Not an Idea（arXiv:2607.26587）已经精确形式化“实现彩票”：冻结机制级构想卡，采样全新会话独立实现，用结果盲法标注忠实度，单独重跑保存工件，并报告构想组内相关系数与留一实现胜者翻转。其 312 次任务结果显示实现方差超过同工件重跑方差五到十倍，胜者翻转为 25.6% 与 43.6%。
- 该论文还明确区分平均实现构想质量与 Best-of-N 工件效用，并建议在候选接近或实现方差高时追加实现。因此“重复构想再排名”和直接的方差触发路由均已被提出。
- 把追加实现预算做成自适应竞速并不留下独立原语：逐次减半（Jamieson 与 Talwalkar，AISTATS 2016）已按中间观测淘汰劣臂；Hyperband（JMLR 2018）已在固定资源下跨配置自适应分配与提前停止；自适应 Best-of-N 进一步把初始探索后的奖励分布用于推理预算分配。

结论：本地诊断独立复现了真实现象，但现象、测量仪器、直接实践建议与自适应分配算子均有精确或成熟先行工作，候选没有可辩护的剩余计算差分。
