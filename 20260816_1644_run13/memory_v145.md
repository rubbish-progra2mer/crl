# v145 当前记忆

- 多模态报告不等于多模态落地；必须检查核验器是否真实消费像素、表格单元与正文，而非只消费图注和来源摘要。
- Wyvern 的图像选择与主张落地是分离流水线；公开失败包括错放、过泛说明和裁剪图—图注不一致。
- 引用召回 `supported / final claims` 在允许删除主张时存在删除退化；以后任何修订收益必须同时报告受支持信息保留或等信息量对照。
- 不把图—注—文核验重新包装为文本/工具智能体方法；SciFigBench 已直接覆盖科学图表的缺失证据、误导图注、错误前提和谨慎推断。
- 不从一般报告有用性派生角色画像方法；读者中心信息满足与个性化摘要已经直接存在。
- 下一 frontier 离开报告修订、来源契约、引用指标和视觉模块集成。
