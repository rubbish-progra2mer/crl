# v151 当前记忆

- 开放多智能体中的成员加入/退出不自动等于语言模型编排新问题；必须比较效用结构、反馈可得性和可行约束是否同构。
- `SubMAPL` 的关键不是一般“动态分配”，而是分区多线性扩展、分类型策略一致性、全局集合函数给出的局部动作边际反馈，以及 Kullback–Leibler 镜像更新。
- 语言模型团队效用不能默认单调或次模：互补子任务使后加入成员的边际值上升，错误与上下文稀释又可使总效用下降。
- 若边际贡献需要语言模型裁判或完整轨迹重放，方法成本和识别问题会回到上下文反事实信用分配。
- 依赖有向无环图、共享工具配额、互斥写入、前置条件和取消语义不能由“每成员选择一个动作”的分区拟阵充分表示。
- `TIPEX` 已在语言模型多智能体中实证两层并行的非加性、非单调和成本冲突；它的初步自动路由器只降低延迟，未改善准确率或词元成本。
- 不再从次模覆盖、开放成员策略迁移或副本/结构并行参数选择派生候选。
- 下一 frontier 必须改变可观察信号或语言模型特有计算，而不是再迁移经典分配数学载体。
