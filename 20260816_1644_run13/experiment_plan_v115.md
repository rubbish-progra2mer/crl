# v115 Recorded 最小实验计划

## 数据、盲法与样本

- 数据固定为 OADD-Bench 提交 `cb60f8951075980ff8c76d3e95f201d11de6030d`，先运行其 `verify_artifact.py`，并从随仓库发布的 HRS 代码本快照离线重建元数据。
- 以 `sha256("v115-oadd-pilot-001:" + record_id)` 升序选取前 32 个问题。该选择不读取问题内容、解释或标签；样本目标列数最小 3、中位数 19.5、均值 30.21875、最大 136。
- 实验前由独立准备入口把公开 CSV 投影成仅含 `record_id`、科研问题、允许年份和官方允许用于预算的目标集合大小 `R` 的盲清单；生成阶段只读取该清单。来源论文、解释、出处、目标列和证据账本只在三个条件的预测文件全部写完后加载评分。

## 模型与共享生成

- 首模型固定为本地 `qwen2.5:7b`，温度 0；每题种子由记录标识确定。
- 每题只调用模型一次，要求输出 1–4 个焦点测量角色、每角色 1–6 个可观察组件，总组件数上限 12；每个组件给出一个面向 HRS 代码本的英文查询。
- 模型输出经固定 JSON 模式与确定性规范化处理。有效计划必须至少包含一个非空角色和一个非空组件查询；无效计划的两个增强条件均回退到原问题排名，并计入载体失败。

## 三个条件

1. `direct_bm25`：仅用原科研问题检索。
2. `flat_rrf`：仅用全部组件查询的 BM25 排名，并对它们做倒数排名融合。
3. `role_closure`：使用与 `flat_rrf` 完全相同的逐组件 BM25 排名；在角色之间轮转，每个角色内部再在组件之间轮转，每次取下一个未重复的字段族，形成层级闭合排名。

三条件使用相同字段族目录、允许年份、字段族到跨波次列的展开规则，以及 `R`、`2R`、`5R` 三个精确输出预算。增强条件的模型调用、查询集合与逐查询检索结果完全相同，唯一实验变量是排名融合方式。

## 指标

- 各预算下宏平均精确列召回；
- `5R` 下每题至少命中一个目标列的测量组件比例；
- `5R` 下每题完整命中所有目标列的测量组件比例；
- `5R` 下为每个测量组件至少命中一列的问题数；
- `role_closure` 相对 `flat_rrf` 的逐题召回胜/负/平数与确定性配对自助法 95% 区间；
- 有效计划数、平均角色数、平均组件数和各条件平均输出数。

## 预注册继续条件

以下条件必须全部成立，才允许运行 `qwen3:8b` 复现：

- 有效计划不少于 30/32；
- `role_closure` 的宏平均 Recall@5R 至少比 `flat_rrf` 高 0.025；
- `role_closure` 的问题级全组件至少一列覆盖率至少比 `flat_rrf` 高 0.10，即至少多覆盖 4/32 个问题；
- `role_closure` 的宏平均组件完整命中率至少比 `flat_rrf` 高 0.025；
- `role_closure` 的 Recall@5R 不低于 `direct_bm25`。

## 预注册杀伤与顺序停止

- 任一继续条件未满足，当前“角色闭合排序”方法核即被最公平扁平基线或无效载体杀伤；不运行第二模型，不改样本，不读取标签后补写组件，不调整查询数量或阈值。
- 即使通过，首实验也只支持第二模型复现和更严格最近工作审计，不足以声称超过论文中的专有 OADD 智能体，因为公开仓库未发布该智能体实现或预测。
- 该实验不执行数据库写入、外部动作或网络请求；仅调用本机 Ollama 和本地公开代码本快照。
