# v151 假设组合

| 草案 | 判定 |
|---|---|
| 用分区多线性扩展分配动态加入/退出的语言模型子智能体 | `INVALID_MECHANISM_TRANSFER`：团队效用未证明单调次模，可行域也不只是分区拟阵 |
| 用局部边际增益训练分散的子智能体策略 | `COUNTERFACTUAL_FEEDBACK_NOT_OBSERVABLE_AT_REASONABLE_COST`；需要逐成员逐动作反事实评价 |
| 成员恢复时迁移其旧策略以避免重新学习 | 目标论文直接机制；语言模型成员通常共享基础模型，恢复角色提示或记忆不构成新的策略学习计算 |
| 用开放系统遗憾界保证动态语言模型编排 | `ASSUMPTION_MISMATCH`：到达/离开独立、逐阶段次模和策略无关时间展开地面集均未满足 |
| 依据任务结构自适应选择副本数与结构并行度 | `DIRECT_TIPEX_FRONTIER`；其自动路由已评价且当前仅改善延迟 |
| 用玩具覆盖或人工互补函数做本地验证 | `LOW_INFORMATION_EXPERIMENT`：分别只复现定理或预设反例，不能识别真实语言模型效用 |

无草案达到最小可验证 Claim 或本地实验门槛。
