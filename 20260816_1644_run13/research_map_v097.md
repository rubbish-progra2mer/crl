# v097 研究图谱

## 等待而不感知

- Let it Cook 将“等待”形式化为放弃若干时间步的感知与决策，在不损害任务表现或总完成时间的前提下最小化感知/决策频率，并以词典序强化学习训练等待时点与时长。
  - https://arxiv.org/abs/2608.11511
- 当前 Run 的 v052 已覆盖异步工具完成、未来值和事件状态机，v058 已覆盖长期主动监测与结构化事件流，v065 已覆盖超时、取消和截止时间。迁移到文本/工具智能体只剩事件驱动调度与成本权衡。

## 轨迹级不确定性

- Beyond Single-Turn Confidence 在五个模型、四个多轮工具数据集上比较动作词元概率、轨迹重采样一致性和模型自评；结果显示聚合器敏感，轨迹等价与动作集合一致性通常是较强变体。
  - https://arxiv.org/abs/2608.11552
- 当前 Run 的 v016 已处理行动/观测不确定性与轨迹方差，v043 已处理逐步不确定性传播与跨工具校准，v069 已处理重复运行和方差分解。

## 多轮信用分配

- CrEST 把轨迹级可验证奖励分成轮次分段优势，并以熵门控的自教师调节轮内词元贡献，在不让教师决定更新方向的情况下提供稠密信用。
  - https://arxiv.org/abs/2608.13179
- 该工作已直接给出层级信用分配、训练目标和 BFCL/WildToolBench 实证；本 Run 没有剩余的训练级新信号，只能变体化分段或门控。

## 多策略共享反馈

- Tree-Coupled A/B Testing 用可预测树和最大耦合共享匹配策略的奖励，同时保持每个策略的独立有限时域轨迹分布；反馈查询数由树边失配的累计全变差决定。
  - https://arxiv.org/abs/2608.12831
- 当前 Run 的 v020 已处理多实现重复采样与预算竞速，v055 已处理自适应科学选择的序贯统计，v069 已处理随机智能体评价与采样预算。该方向属于评价统计而非新的执行策略。

## 结论

四个维度都有直接形式化和实验。等待策略在工具智能体中的迁移被事件驱动运行时吸收；轨迹不确定性与信用分配已有专门方法；反馈共享属于精确耦合评测设计。没有候选需要本地现象实验。
