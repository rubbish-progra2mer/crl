# v009 选择上下文

1. v008 的主动核验选择被“先验证再重试”与结构化信息价值选择组合覆盖，本版转向多智能体证据聚合。
2. 最新 ForesightSafety-TIDE 已提供直接失效事实与证据根传播测量；其最终决策仍按智能体多数，谱系用于分析而非聚合。
3. ProvenanceGuard 能判断主张是否由指定来源支撑，但不解决同一根经多个智能体转述后被重复计票。
4. 候选只改变聚合单位，不增加模型调用：认证根是运行时对象，转述只继承标识。
5. 最小实验必须同时包含全诚实与欺骗配对；只把错误多数变成全面弃权不足以建立方法价值。

最小实验数值门槛通过，但候选不进入 Seed：

1. 欺骗条件下，末轮多数真实/诱饵/不确定率为 0.25/0.25/0.50；证据持有者多数为 0.25/0.125/0.625；根归一化为 1.00/0/0。全诚实条件三者均为 1.00/0/0。
2. 根归一化直接读取生成器登记的根支撑标签；三个真实根对一个虚假根的多数是构造事实，未证明大语言模型能可靠抽取或维护证据根。
3. 提示向所有智能体公开了初始根证词，因此“私有证据”没有形成真正的信息隔离；该探针只能视为机制冒烟测试。
4. 更宽的最近邻检索发现，Hamdi 与 Krishnamurthy（arXiv:1309.6687）以及 Krishnamurthy 与 Hoiles（arXiv:1501.00994）已经把相同观测的多次复用定义为数据乱伦，并给出基于信息交换图的消除算法；Funk 等（arXiv:2307.10594）进一步按概率独立结构处理多智能体分散式融合中的谣言传播与重复计数。

因此 H1 以 `PRIOR_COLLISION` 终止。正结果保留为负面记忆，不再投入更大实验预算。
