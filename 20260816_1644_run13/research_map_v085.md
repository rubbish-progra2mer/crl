# v085 研究图谱

## 直接治理与来源完整性

- 《正确不等于受治理：智能体工作流中的来源完整性》已经把受治理执行定义为：决策、完成和对变化的响应都由可检查来源支持。其 Matrix 层记录权限与事实依赖、核验完成证据并选择性失效受影响工作；治理路径与直接路径常有相同终态，但只有前者保存治理证据、拒绝无支持闭合并限制恢复范围。
  - https://arxiv.org/abs/2608.12761
- 《受治理的持久记忆》给出双时间状态转换、来源绑定接纳、冲突隔离、撤回/删除后不复活和基于最新已核验头部的失败关闭释放，并在预注册冻结的 3,600 个案例及独立服务评价上执行。
  - https://arxiv.org/abs/2608.12476
- 《一次协调、随时写作》维护带时间戳和信任层级的证据卡、权威指标账本与主张图，并按知识截止时间生成无前视报告；它已直接覆盖时间截面、信任层和反驳传播。
  - https://arxiv.org/abs/2608.12984
- 《工作流卡》把机器可读执行来源压缩为人和语言模型均可读的结构化摘要，并报告相对直接查询来源数据库近两倍的回答质量。
  - https://arxiv.org/abs/2608.11022

## 证据契约与交接

- GAVEL 要求多智能体辩论者把原子子主张绑定到精确证据单元，再由中立审查者确定性核验标识符和引文跨度；证据契约与机制化审查均有消融支持。
  - https://aclanthology.org/2026.findings-acl.1789/
- AgentAsk 已把跨智能体交接错误分为数据缺口、信号腐化、指称漂移和能力缺口，并在关键边上用最小澄清干预，在五个基准上最高提高 4.69%，额外时延与成本低于 10%。
  - https://aclanthology.org/2026.acl-long.1294/
- 《从智能体轨迹到信任》系统综述已经把检索证据、工具输出、记忆、观察、中间主张、动作和最终回答统一为执行来源关系，并把统一轨迹模式、主张级来源和恢复评价列为明确方向。
  - https://arxiv.org/abs/2606.04990

## 过度阻断是否留下新计算

Matrix 的角色分离迁移确实失败：在创作上下文外生成的合成包被确定性完整性契约严重过度阻断。但当前候选的修复只可能是三类已有计算：

1. 由生产方补齐或澄清缺失字段，落入 AgentAsk 的交接数据缺口与最小澄清；
2. 用语义映射把不同字段/表述对齐到同一证据义务，落入模式匹配、来源模式统一和工作流卡；
3. 通过反例放宽过度约束的完整性规约，落入 v064 已记录的 VeriAct 反例—验证反馈规约修复。

当前 Run 的 v012 已处理事实变化后的依赖失效，v045 处理记忆使用的语境适配，v054 处理可独立核验残留物，v076 处理无支持的完成声明，v080 处理时间截面证据。新增“最小交接见证”没有独立状态或干预算子。

## 结论

受治理正确性及其核心计算已被直接工作覆盖；交接过度阻断是真实边界，但现有修复只剩澄清、模式对齐或规约修复。v085 不注册本地实验。
