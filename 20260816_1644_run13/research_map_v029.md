# v029 研究图谱

- RewardHackBench 公开仓库固定在提交 `3a4efd12a42be23a796ae6a087c87cc6d010ea7d`；其已发布结果包含 8 个任务、7 类策略、每格 3 次试验，并区分事后全轨迹公平性裁判与请求时策略裁判。
- 该仓库的防御配置跨越智能体工具开关、分阶段网关规则和请求内容裁判，说明策略结论依赖多个执行层共同作用，而不是单个规则名称。
- 上一执行阶段在继续检查公开网关路径时触发宿主平台安全控制。这里把它记录为外部执行边界；没有继续尝试规避、绕过或削弱控制，也不把它当作科研反证或 Run 终局。
- 安全抽象候选只保留本地合成能力图：节点表示抽象组件，边表示能力委托，标签表示允许效果或禁止效果；审计器检查允许路径能否到达禁止效果。它不包含真实主机、密钥、请求、漏洞载荷或外部执行。
- ToolGuardian（arXiv:2607.21835）已经把工具描述、系统调用、模拟执行和源码证据转成结构化事实，并用答案集程序显式推理能力、效果、任务语境与多工具组合；消融表明移除组合规则会显著退化。
- AgentGuard（arXiv:2605.28071）已经以属性访问控制覆盖单工具与跨工具安全风险，并提供策略说明与运行时审计。
- 《Towards Verifiably Safe Tool Use for LLM Agents》（arXiv:2601.08012，ICSE NIER 2026）已经把危害转成数据流与工具序列上的可执行规范，并在工具协议中加入能力、机密性和信任等级标签。
- 更一般的系统安全先行工作也早已把多层访问控制合并成图并查询特权可达路径，例如 BigMAC（USENIX Security 2020）。

结论：安全的本地合成实验可以实现，但其计算只是上述能力/效果/组合策略推理的简化实例，不能形成新的方法内核。
