# v155 失败归因

## 类型

`SELF_REHEARSED_TOOL_WORLD_MODELS_CLOSED_BY_SIMULATOR_COLLAPSE_POPULATION_COTRAINING_AND_RUN_MEMORY`

## 直接原因

- 单共享策略的行动—环境双角色满足模拟器坍缩的核心结构：模拟器决定状态访问分布，策略可利用其主导模式；
- 同一模型双角色自博弈已由相邻工作明确实现，不是 EnvACE 特有的未覆盖情形；
- 推理期多样采样、异构模拟器轮换、双模型协同训练和历史检查点群体已覆盖所有自然修复；
- `v016` 与 `v109` 已分别保存单模拟器坍缩和假想观察误用的负记忆；
- 可做的本地合成实验无论正负都不能恢复新的方法计算。

## 非原因

- 不是 EnvACE 的公开经验结果已被推翻；
- 不是把公开服务限速或 v029 宿主安全控制误当成科研反证；
- 不是因本机无法复现 16 张 H20 训练就宣称候选无效；
- 不是 Run 终局。

## 决定

不注册实验或 Seed。保留“共享参数提升任务分数不等于世界模型校准”的评价边界；Run 保持 `ACTIVE`，下一版离开内部世界排演与模拟器群体方法族。
