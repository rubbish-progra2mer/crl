# v167 研究图谱

## 直接经验与理论

- [两智能体接力中的状态压缩](https://arxiv.org/abs/2607.18265) 在 50 个闭世界旅行规划实例上比较无压缩、叙述摘要、结构化 JSON 和嵌入裁剪。结构化 JSON 的可行性准确率为 0.96，叙述摘要虽最短却降至 0.48，嵌入裁剪以 0.88 匹配无压缩控制。
- [跨会话交接理论](https://arxiv.org/abs/2608.14528) 区分“精确恢复旧材料”与“保持目标分布”，并在外生性条件下用预测等价刻画最粗确定性充分交接和固定位需求。
- 该工作显式分离内存约束、写入器和续接过程，并量化写入时尚不知道下游实现查询的代价。
- 它提出三段式记录：决策与约束精确保留；重复证据使用任务有理统计量；统计量不能保留影响的原始观察继续保存。高斯线性回归给出精确有限维交接与有限位扰动界，非参数回归给出内存—平方预测误差上下界。

## 自然扩展及边界

- 在交接后更换目标／查询以测试叙述摘要和 JSON 的稳健性，会直接验证未知下游查询代价；三段式记录已经是针对该问题的机制。
- 以最坏查询而非平均查询选择保留项，是经典充分统计／率失真／稳健压缩的目标变体；没有新的智能体计算。
- 为每个后续查询检索原始记录，是一般任务条件化检索；保存所有原始记录则退化为无压缩。
- 动态注意上下文作用域、主动上下文压缩和经验压缩光谱分别覆盖多智能体上下文隔离、自主压缩时机和跨压缩层级选择。

## 结论

“未知后续查询下的交接充分性”已同时有直接闭世界实验与正式理论。当前可做的实验只会测量三段式记录相对叙述／JSON 的适用范围，不会产生不可替代的新算子。
