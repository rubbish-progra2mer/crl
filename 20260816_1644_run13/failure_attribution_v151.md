# v151 失败归因

## 类型

`OPEN_LLM_AGENT_ALLOCATION_CLOSED_BY_SUBMODULAR_ORACLE_ASSUMPTION_AND_DIRECT_PARALLEL_SCHEDULING_PRIORS`

## 直接原因

- 目标方法要求团队效用归一化、单调、次模，语言模型子智能体存在互补依赖、负干扰和错误传播；
- 目标方法需要对每名成员的每个局部动作获得边际增益，真实语言模型任务中该反馈需昂贵反事实重放或裁判；
- 分区拟阵不表示依赖图、共享配额、互斥写入和前置条件等真实编排约束；
- 有限时域保证还要求策略无关的时间展开次模效用，不能直接覆盖路径依赖的工具执行；
- `TIPEX` 已直接评价语言模型多智能体副本/结构并行及准确率—延迟—词元成本权衡，v052/v091/v106/v121 又覆盖并行、动态成本、边际信用和序贯停止。

## 非原因

- 不是 `SubMAPL` 在覆盖任务中无效；
- 不是网络安全控制或 v029 的科研反证；
- 不是本地实验失败；
- 不是 Run 终局。

## 决定

归档把次模开放多智能体策略学习直接迁移为语言模型子智能体调度的路线。Run 保持 `ACTIVE`，下一 frontier 离开次模覆盖、成员动作边际反馈和副本/结构并行参数调度。
