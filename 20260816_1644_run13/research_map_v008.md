# v008 研究地图

## 共享知识库证据

- P074（ToolGate）：调用前检查前置条件、返回后检查后置条件，只有验证通过才把结果提交到可信状态；缺少响应结构时默认后置条件为真，暴露合同完整性边界。
- P072（结构化不确定性引导澄清）：枚举候选工具调用与未知参数，用成本惩罚的预期信息价值选择问题，并在信息足够时停止追问。
- P007（tau-bench）：以文本外部的数据库终态核验智能体是否真的完成任务。
- P040：智能体可在环境状态仍失败时自信宣告完成。

## 最新直接先行工作

- Verified Tool Calls Improve LLM Agent Reliability Under Non-Atomic Failures（arXiv:2608.02645）：显式形式化超时后派发、延迟可见和部分写入，提出后置条件核验、先验证再重试与幂等键。
- Atomix（arXiv:2602.14849）：记录读与副作用，按资源前沿决定事务提交；中止时抑制未释放作用并补偿可逆作用。
- Recoverability Has a Law（arXiv:2601.22352）：用预期恢复遗憾与效率分数刻画工具智能体的恢复代价。

## 组件级差分审计

候选的“作用状态集合—只读诊断—恢复动作”应用位置不同，但其关键计算被两部分组合覆盖：非原子副作用后的核验与恢复分支来自先验证再重试；按信息价值和成本选择查询并停止来自 P072。P074 又覆盖验证后才提交可信状态，Atomix 覆盖部分作用与补偿。当前没有新的查询目标估计器、可证明停止准则、恢复原语或可迁移学习机制。
