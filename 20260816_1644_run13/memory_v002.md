# v002 当前记忆

## 已验证张力

- 查询无关的文档扩展能提高检索指标，但部分字段会有负作用；
- 语义相关工具增多会降低最终函数调用准确率；
- 工具描述和排列顺序会强烈影响选择。

## 已杀方法

- 近邻感知、相对边界式工具描述重写；
- 困难负例驱动的相似工具重排；
- 仅靠自适应缩短候选表解决干扰。

## 杀伤边界

“检索指标改善是否掩盖最终选择退化”仍是可测经验问题，但现有计算不足以支撑独立方法贡献。

## 下一项最高信息增益动作

转向检索后、执行前仍未解决的评测语义：当多个工具对同一请求在操作上可替代时，单一工具标识标签是否把正确替代调用误判为错误，并诱导检索器学习不稳定的表面差异。先核查可替代工具、工具合并、集合值标签与执行等价先行工作。
