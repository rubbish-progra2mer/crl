# v137 失败归因

## 类型

`DEDUP_GRANULARITY_COUNTEREXAMPLE_SURVIVES_REPAIR_KILLED_BY_SIMPLE_BASELINE_AND_RETRIEVAL_PRIORS`

## 成立部分

- 当观察单位是局部轮窗口而抑制单位是整个会话时，同会话未观察证据可被确定性删除；
- 101 个随机布局种子全部复现该可达性损失；
- 观察区间去重能恢复第二证据并抑制完全覆盖窗口重复。

## 方法死亡原因

- 更简单的精确命中轮去重在预注册主指标上与观察区间去重完全相同，没有证据支持额外状态复杂度；
- 段落级证据检索、最大边际相关性和多答案覆盖已把相关性与新颖性放在细粒度单位上；
- AIR、MURRE 与 S2G-RAG 已按未覆盖信息或证据缺口继续迭代检索；
- 当前 Run v010 已关闭“局部结果不能提升为全局完备”及覆盖记账的直接迁移。

## 非原因

- 不是实验反证，构念反例和修复基线均通过；
- 不是实现失败，Recorded 首次尝试成功；
- 不是 v029 外部执行边界；实验完全本地且不涉及安全过滤；
- 不是 Run 终局。

## 决定

保留粒度不一致反例，拒绝观察区间去重升级为 Seed。Run 继续 `ACTIVE / AUTONOMOUS`，下一版本离开检索去重、分页覆盖和一般记忆检索。
