# v137 假设组合（实验前）

## H1：会话级去重会破坏同会话远距证据可达性

- 状态：`SUPPORTED_AS_CONSTRUCT_COUNTEREXAMPLE`
- 可证伪陈述：在每个合成档案中，目标会话含两个间距大于两倍窗口半径的唯一词面证据；第一次查询返回第一证据后，ReFind 语义的会话级去重在第二查询上的第二证据召回率为 0，而不去重、精确命中去重和观察区间去重的召回率均为 1。
- 机制：抑制粒度（整个会话）大于观察粒度（局部窗口），导致未观察区域被错误归入已观察状态。
- 反证条件：会话级去重仍能返回目标会话内第二证据，或任一细粒度基线无法返回它。

## H2：观察区间去重同时保留新证据并抑制原窗口重复

- 状态：`SUPPORTED_AS_REPAIR_BASELINE_BUT_KILLED_AS_METHOD`
- 可证伪陈述：观察区间去重在“第一查询—第二查询—重复第一查询”三轮协议中，第二证据召回率为 1，第三轮不会再次返回完全已覆盖的第一窗口；无去重基线会重复第一窗口。
- 机制：对每个会话维护已观察轮区间，只拒绝扩展窗口没有任何新增轮的候选，不把局部观察提升为父会话完备性。
- 反证条件：区间去重丢失第二证据、重复返回完全覆盖窗口，或无去重不发生预期重复。

## 方法边界

H1/H2 均按预注册成立，但只证明目标控制的构念边界和一个修复基线。精确命中轮去重在本实验中与观察区间去重同样达到第二证据召回 1.0 和完全覆盖窗口重复率 0.0，尚无证据支持区间状态的额外复杂度。区间状态、最大边际相关性、段落级检索与查询完备性又是强先验，因此不生成 Seed。
