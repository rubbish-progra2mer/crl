# v081 研究图谱

## 可恢复工具故障

- ToolBench-X 在确定性多步任务中注入规范漂移、调用错误、执行失败、输出漂移和跨来源冲突，并保证至少一条重试、回退、核验或交叉检查恢复路径。
  - https://arxiv.org/abs/2606.25819
- ToolFailBench 在 1,000 个任务、19 个模型上区分跳过工具、忽略结果、伪造输出和不必要调用，最佳模型的干净工具使用率仍只有 86.33%。
  - https://arxiv.org/abs/2607.04686
- AgentProp-Bench 包含 14,750 条执行轨迹，并直接测量参数错误传播、腐化输入拒绝、恢复与伪造工具执行；轻量运行时拦截器也是其已评价组件。
  - https://arxiv.org/abs/2604.16706
- 当前 Run 的 v008、v023、v063、v072 已分别覆盖作用状态诊断、根因证书、共同原因故障和验证放置。再做故障分类器或提示恢复会同时碰撞直接基准和 Run 内记忆。

## 用户交互

- AppWorld-UL 提供 516 个需澄清、确认或告知不可行的用户在环任务，覆盖 9 个有状态应用；Claude Opus 4.7 总成功率为 48.6%，组合子集为 35.7%。
  - https://arxiv.org/abs/2607.20536
- ClarifyMT-Bench 用五维歧义分类和六类用户角色构造 6,120 个多轮对话，并以感知、预测、跟踪和规划组成 ClarifyAgent。
  - https://arxiv.org/abs/2512.21120
- SAGE-Agent 已把工具参数域上的规范不确定性与模型不确定性分离，并用完美信息期望价值选择问题和停止澄清。
  - https://aclanthology.org/2026.findings-acl.2028/
- 当前 Run 的 v047 已用信息来源与副作用决策值规定何时工具检查、何时询问用户。候选没有独立计算差分。

## 科学论文层级组织

- TaxoBench 从 72 篇专家综述得到 3,815 篇论文和专家分类树；在直接给定专家论文集合的 Bottom-Up 模式中，70 次标准运行没有达到专家平均深度 4.86，强行匹配深度又会因树碎片化降低对齐。
  - https://arxiv.org/abs/2601.12369
- 多方面聚类已经让大语言模型按方法、数据集和评价等方面生成论文表示，再动态聚类成层级，并在 156 个专家分类树、约 11,600 篇论文上评价。
  - https://aclanthology.org/2025.emnlp-main.788/
- TaxoAlign 已给出三阶段主题指令法和结构对齐评价；SC-Taxo 已用自下而上抽象、自上而下约束及同层依赖做层级语义一致性精炼。
  - https://aclanthology.org/2025.emnlp-main.1536/
  - https://arxiv.org/abs/2605.00620
- 因而“先定方面再聚类”“限制无证据分裂”“双向检查父子语义”均为已实现方法族，不注册本地分类树实验。

## 执行框架与测量

- MASEval 把拓扑、编排、错误处理、执行框架和上下文工程作为系统级评价变量，并在 3 个基准、3 个模型、3 个框架上发现框架选择的影响与模型选择相当。
  - https://aclanthology.org/2026.acl-demo.34/
- Harness-Bench 在 106 个离线任务、5,194 条轨迹中直接评价模型—执行框架配置，并主张能力应归因于二者组合。
  - https://arxiv.org/abs/2605.27922
- *Measuring Harness-Induced Belief Divergence* 已在固定任务、环境和基础模型时分解执行框架造成的即时与长程信念差异。
  - https://arxiv.org/abs/2607.04528
- 当前 Run 的 v021 和 v071 已实测证据重塑及宽容执行器补偿。框架归因不再是空白。

## 检索停止与预算

- DeepControl 用边际信息效用控制是否继续检索及展开粒度。
  - https://arxiv.org/abs/2602.01672
- HALT 以预期跳步主张的累计证据覆盖决定停止，并在三个多跳问答基准上减少冗余搜索而大体保留精确匹配。
  - https://arxiv.org/abs/2608.02009
- 企业深度研究工作已用覆盖目标、依赖控制上下文和显式证据充分性减少过早停止。
  - https://aclanthology.org/2026.acl-industry.116/
- 当前 Run 的 v050 已审计依赖闭合检索停止，v076 已审计部分证据上的过度交付声明。再用覆盖表或一般信息增益停止没有差分。

## 结论

五条残余候选均有直接问题定义、基准或方法，并与当前 Run 机制记忆重合。本版不运行实验，Run 继续保持 `ACTIVE`。
