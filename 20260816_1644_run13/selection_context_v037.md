# v037 选择语境

主动诊断 `v037-frontier-reset-006` 是仅事实、非权威材料。它确认当前版本没有既有尝试，Run 已有 37 个科学版本，全文召回为 `READY`、无污染；语义召回未构建。主研究者据此离开近期工具字段、模式和补丁盆地，选择多轮报告修订这一文本智能体问题。

公开 Mr Dre 仓库只包含问题清单、评测与生成代码，没有论文中已生成的报告；完整复现还依赖多个商业接口。因此，本版本没有声称重放论文结果，而是用完全本地的合成报告做两个层次的判死实验。

原始压力评分器曾把“高于阈值 18”与“超过阈值 18”等语义等价表达判为不同。该错误没有被静默覆盖：原始结果保留，另写独立语义重评分文件，并且没有重新调用模型。重评分使人工闭包从表面失败恢复为 4/4，但仍未超过整篇强基线。
