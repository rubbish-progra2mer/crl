# v127 选择上下文

v126 后需要离开安全门控、授权和签名协议。v127 选择多智能体潜通信，因为它改变了分析对象：从语言或工具动作边界转向连续表示如何跨智能体成为可用信息。

StateBridge 的逐消息双边白化暴露了一个强可证伪点。合成实验确认在 (d\gg K)、满行秩和小正则下，对齐几乎只重建固定词元嵌入；真实 Qwen3-0.6B 激活则保留非零残差，迫使结论从“通道坍缩”收窄为“通道贡献未被词元条件控制识别”。这个收窄是科学版本的有效进展。

然而，通用的消息边界因果审计已经发表，包含其他样例替换、自生成对照、接收敏感性、任务价值和配对推断。把词元固定加入该框架很重要，却不足以构成新的 CCF-B 方法；残差学习修复也回到既有训练式投影。因此 v127 记录为有实验支持的负结果，不注册候选。下一前沿离开潜通信、表示对齐与多智能体消息审计。
