# v125 研究图谱

- [AgentRewind](https://arxiv.org/abs/2608.14380) 在每个模型决策边界记录模型上下文与受控环境状态的对齐检查点，恢复时回退两者并注入失败分支摘要。其官方 PDF 已保存并抽取到 `workbench_v125/agentrewind.pdf` 与 `workbench_v125/agentrewind.txt`。
- 论文精确定义恢复边界为工作区目录树：后缀中的网络请求、外部服务调用和外部运行时状态不会撤销，也不会因日志重放而再次触发；根目录版本库元数据、空目录和多数权限位也不完全进入快照。作者在正文、附录和结论中都明确披露“只恢复受控状态”，所以不能把这一点写成隐蔽实现错误。
- 论文不预设墙钟、步数或总令牌上限，并允许无限回退；但它没有只给终局成绩，还报告任务成功和清单进度随模型/工具事件数变化的曲线。该曲线不能等价控制令牌、墙钟和提供商成本，却已经直接处理“仅因更多轨迹事件获益”的主要混杂。
- [ACRFence](https://arxiv.org/abs/2603.20625) 已直接研究本地检查点回退而外部效果仍前进造成的语义回滚，记录不可逆工具效果并在恢复后执行重放或分叉语义。
- [DART](https://arxiv.org/abs/2605.23311) 已认证满足依赖与效果约束的语义可恢复边界，在下游已有承诺时选择可接受恢复点或阻断恢复。
- [Crab](https://arxiv.org/abs/2604.28138) 已把聊天级恢复遗漏操作系统副作用定义为智能体—操作系统语义缺口，通过操作系统可见效果检查、轮次对齐检查点和完整沙箱恢复提高正确性。
- [Cordon](https://arxiv.org/abs/2606.17573) 已用任务级语义事务绑定工具意图、结果谱系、可逆本地状态、暂存的外部效果、委派权限与审计元数据，在验证后才提交或释放外部效果。
- 当前 Run 的 v008、v075 和 v102 已分别覆盖不确定副作用、遗留义务/补偿和崩溃恢复；新增“效果边界清单”会再次落入同一恢复原语。

因此，AgentRewind 的恢复边界是真实部署限制，但相应方法差分已被效果账本、语义恢复点、完整沙箱检查点和事务暂存直接覆盖。进一步做一个外部计数器不随文件系统回退的玩具实验只会复现已知机制。
