# v100 问题

v100 在科学版本达到 100 时执行一次 facts-only 主动诊断，并据此检查最近连续先行工作碰撞是否只是同一关键词盆地造成。候选不从新方法名称出发，而从四种可干预状态出发：不确定工具副作用下的重复执行、局部工具观察的完备性、含噪候选选择的赢家高估，以及相同证据集合在不同到达顺序与自适应停止下的路径依赖。

本版本的问题不是这些风险是否存在，而是其中是否至少有一项同时满足三条条件：当前 Run 未经同构检验或关闭；公开先行工作尚未覆盖核心计算；本地非安全敏感实验的正反结果会显著改变论文级剩余贡献差分。

主动诊断只提供机械事实，不产生候选裁决。主研究者必须把诊断提示与 Run 内实验、负记忆和公开论文逐项对照后再决定是否注册实验。
