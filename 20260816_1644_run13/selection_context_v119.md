# v119 选择上下文

v118 离开纵向文本修订后，v119 从最新公开论文选择了一个结构不同且原则上可执行的载体：环境变化后，智能体需要重写可执行物理机制，而不是更新自然语言报告。论文中的参数公开控制也排除了“再告诉模型发生了什么”这一弱解法。

精确审计显示，剩余操作仍不是新的改变计算。定位并挖空失败片段是反例引导程序修复；以性质反例替代标量反馈是性质引导综合；用结构差异逃离固定并用验证保留方向是质量—多样性搜索。当前作者仓库又尚未发布任务工件，无法用公平实验识别更细差分。

v119 因此在实验前关闭，但这不是 PACE-Bench 的科研反证，也不是 Run 终局。下一前沿离开代码重设计、自演化搜索和执行框架更新，优先检查工具接口本身是否把任务所需的合法行为从可表达空间中删除，并要求剩余解法改变接口语义而非增加提示。
