# v143 研究地图

## Envs-FORGE 的公开计算与证据

- [Envs-FORGE](https://arxiv.org/abs/2608.14312) 先在原种子上估计当前策略通过率，再为“增难/减难/多样化 × 深度/广度”六个动作计算固定偏移后的预测通过率，以距目标通过率 0.5 的高斯效用为主目标选择动作；随后同步改写指令、夹具、标准答案、测试和容器。
- 预测难度使用固定偏移：增难为 -0.25、减难为 +0.25、多样化为 0，广度方向再乘 0.65。论文明确说明这些偏移不是每个材料化任务真实难度变化的经验断言。
- 后生成“金标准验证”只证明标准答案可通过生成测试、任务可运行和内部一致；论文又明确区分该奖励与估计学习难度所用的下游策略奖励。材料化后没有再次运行当前策略来检查是否真的接近 0.5。
- 报告实验让 100 个种子各导出一个环境，并使用带软技能覆盖的索引化求解；论文承认，在相同候选池上增加“关闭求解器”的比较才会给出选择器的组件级分析。现有比较同时改变按种子动作、技能子图、制品编辑掩码和提示内容。
- 公开结果跨 4B、9B、27B、35B 模型和三个基准同向，因而不能把效果写成不存在；但这些下游结果不能单独识别“材料化后位于学习前沿”这一承重机制。

## 公开工件核验

- 论文链接到 [DataArc 合成数据工具包](https://github.com/DataArcTech/DataArc-SynData-Toolkit)。2026-08-17 的只读 GitHub 树检查覆盖公开可见的 `main`、`dev`、`SynAgenticData` 三条分支；路径中未发现 `forge`、`frontier`、`milp` 或 `scip` 实现。
- `SynAgenticData` 分支最后可见提交为 2026-06-30；其中 `sdgsystem/agentic_data/terminal_bench.py` 提供一般终端任务合成和深度/广度演化，但文本核查未发现 FORGE、前沿、混合整数规划、SCIP、通过率或投影选择实现。
- 这只说明当前链接工件不足以复核目标选择器；不推断不存在未公开代码，也不把工件缺失当作科研反证。

## 直接方法先行

- [自动目标生成](https://arxiv.org/abs/1705.06366) 已用当前策略的中等成功区间标注“适当难度”目标并训练生成器，让课程随策略能力移动。
- [基于遗憾的演化课程](https://arxiv.org/abs/2203.01302) 已编辑环境实例，并以策略遗憾筛选位于能力前沿的材料化关卡。
- [无监督环境设计](https://arxiv.org/abs/2012.02096) 已让环境生成器通过主角—对手遗憾构造结构化、可解且随策略变化的训练环境。
- [优先级关卡回放](https://arxiv.org/abs/2010.03934) 已按经验学习潜力选择训练关卡，而不是只依赖静态难度标签。
- 因此，把固定偏移替换成动作条件的经验难度模型、材料化后策略探针、遗憾、学习进展或上下文老虎机，会直接回到自动课程与环境设计的最近方法族。

## 其他 v143 入口

- [StructAgent](https://arxiv.org/abs/2607.11388) 的验证状态若因后续写入变陈旧，修复就是 v012 已关闭的版本化读集、依赖失效和执行前刷新；最小充分状态又与 v124 的任务相对充分移交重合。
- [BoardroomAI](https://arxiv.org/abs/2608.13046) 的决策图、影响传播、保留未受影响节点和选择性重算，与当前 Run 的依赖闭包、跨段一致性和 Matrix 来源治理负记忆同构。
- [本体约束项目记忆](https://arxiv.org/abs/2608.13662) 的生命周期、来源、替代链、否定与集合完备查询属于结构化知识图和完备性查询；不能把向量 top-k 的固有限制转化成新方法差分。
- [能力层积](https://arxiv.org/abs/2608.13228) 自身报告真实仓库上层积选择器相对匹配非上同调选择器无显著优势，确认划分仍密封；论文已正确保留负结论。

## 决定

v143 保留 Envs-FORGE 的跨规模正向现象，但拒绝把未复测的固定难度投影当作已识别机制。自然修复已被自动目标生成、无监督环境设计、遗憾课程和学习潜力回放覆盖；其余入口又与 Run 内精确负记忆碰撞。本版不注册实验，不生成 Seed、Reviewer、Formal 或 Review-support 证据。
