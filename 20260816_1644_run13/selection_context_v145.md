# v145 选择上下文

Wyvern 给出了真实系统、完整基线与主张修订前后对照，因此不能把它简单归为“只有框架图”。不过其主张修订差分已经是原子事实分解、来源蕴含与局部改写；引用召回的提升又同时受允许删除主张影响。缺少的是受支持信息保留或相同信息量下的落地比较，而不是新的修订算子。

图像路径暴露了更尖锐的实现边界：选择与放置只消费图像的文本代理，最终核验又只处理文本主张。论文明确报告了错放、说明过泛和裁剪后图注不一致。但给系统增加像素级视觉核验，会直接复用现有科学图表视觉问答、图注偏置和缺失证据可靠性方法；在宽 `TEXT_AND_TOOL_LLM_AGENT` Charter 下也不应把视觉语言模型模块集成提升为新的文本/工具智能体贡献。

因此 v145 不下载当前返回不可用的公开仓库链接，不把工件可用性当科研反证，也不做小规模图表实验。该路径归档，Run 继续寻找结构不同的前沿。
