# v172 当前记忆

## 新增正向证据

- 论文复现不能只判断名义终值；离名义配对响应能提供额外的机制等价证据。
- 真实复现基准已经大量检查实现细节和部分已发表消融，不能把它们概括为“只比较目标图”。
- PaperBench 公开评分表中几乎没有显式、评分器另行生成且对复现者留出的干预响应检查；这是可审计的基准加固缺口，不自动等于新方法。

## 新增负记忆

- 不把“给论文复现加隐藏扰动”包装为新方法；差分测试和蜕变测试已覆盖验证原理。
- 不把候选响应分歧最大化包装为新的科学评分采集；主动测试、查询委员会与顺序诊断已覆盖选择逻辑。
- 不用手工构造终值相同而响应不同的候选来证明方案；这种实验把结论写进数据生成过程，只能做管线自检。
- 词法评分表审计只能证明显式文字分布，不能断言大语言模型评分器没有隐式检查等价行为。

## 安全与 Run 状态

v172 未研究、执行或改进安全过滤绕过；未运行外部论文代码、模型、容器或智能体。只静态读取官方 PaperBench 数据并运行本地 JSON 文本审计。v029 保持外部执行边界，Run 保持 `ACTIVE / AUTONOMOUS`，无 Seed 或终局。
