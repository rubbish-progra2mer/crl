# v066 失败归因

## 失败标签

`FALSIFIED_BY_EFFECT_LABEL_REVERSAL`

## 证据

- `qwen2.5:7b` 在普通描述下保持任务为 9/12、领取任务为 12/12；普通描述没有达到预注册的消费型观察盲区支持门槛；
- 增加不含推荐答案的效果标签后，保持任务从 9/12 降至 7/12，而非提升至少 3/12；
- 效果标签条件保持正确率也低于 10/12 下限；
- 两条件均无 JSON 格式错误，领取任务均为 12/12，不能把失败归因为输出格式或一律拒绝消费型接口。

## 非归因

- 不是网络或宿主安全边界：实验只调用本机模型接口，表示性的访问接口从未执行；
- 不是公开安全过滤绕过研究：所有任务均为良性合成资源读取；
- 不是答案泄露：描述中没有 `best` 或推荐行，消费角色、工具顺序及二者交叉均平衡；
- 不把未运行的 `qwen3:8b` 当作支持或反证。

## 决策

否决“稳定消费型观察盲区可由显式效果标签修复”这一候选，不把 3 个普通描述错误包装成跨模型方法贡献。按预注册规则早停第二模型。Run 保持 `ACTIVE`，下一版本转向结构不同的现象或评价载体。
