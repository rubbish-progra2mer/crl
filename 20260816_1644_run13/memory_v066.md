# v066 记忆

- 现象记忆：低成本消费型读取在普通描述下造成 3/12 个保持任务错误，错误理由会把已明示的消费副作用误述为状态不变；这是局部观察，不是已建立的跨模型规律。
- 负记忆：给普通文档增加 `CONSUMES_CURRENT_ITEM` / `PURE_READ` 标签不能被假定为修复；本实验中保持正确率反而从 9/12 降至 7/12。
- 实验设计记忆：领取配对任务成功排除了“一律选择纯读”，角色与顺序交叉平衡排除了单一名称/位置解释，但单模型早停不支持跨模型外推。
- 选路记忆：不要把线性资源或效果类型的名称本身包装成智能体方法；下一 frontier 应改变现象或评价载体，而不是继续改标签措辞。
