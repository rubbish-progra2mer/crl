# v150 当前记忆

- 大规模真实数据库与专家裁定可以证明完整系统有用，但没有组件对照时不能把收益归因于多智能体编排。
- 跨领域保持模型权重却修改抽取模式和验证规则，不是零工程迁移；必须报告规则/模式开发成本。
- 文档级全局填充状态、可靠字段优先、跨字段约束复用和多轮辩论已有 SudokuFill 直接方法与固定骨干消融。
- 非结构化文档的分解、算子改写、验证提示和成本—准确率计划搜索已有 DocETL/MOAR。
- 页级来源追踪提高可审计性，但不能修复上游光学字符识别、表格结构或召回遗漏；地球化学属性召回 0.35 是明确边界。
- 不再从“解析器—识别器—标注器—验证器—追踪器”的角色拆分派生新候选。
- 下一 frontier 离开文档抽取、来源追踪、跨字段填充和人工复核。
