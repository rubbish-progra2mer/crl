# v036 研究图谱

## 工具调用先行覆盖

- HammerBench 已定义 `API Repurposing`：用户在一次函数调用后更新部分参数，同时保持其他参数不变，并构造 1,066 个实例。
- HiTEC 的全局与局部错误清单已包含冗余参数错误：查询未指示的可选参数不应出现在函数调用中；其两轮上下文学习和偏好优化方案都直接纠正参数误填。
- 因而“只序列化用户实际触及的字段”不是未被识别的工具调用失败类型。

## 差分表示先行覆盖

- RFC 7396 的 JSON 合并补丁已经规定对象成员的差分语义：未出现的成员保持不变，值为 `null` 的成员被删除，其他值被添加或替换。
- JSON Whisperer（`arXiv:2510.04717`）已让大语言模型从自然语言生成 RFC 6902 差分补丁，而不是重生成完整 JSON；其 EASE 表示进一步处理数组索引漂移。
- PatchBoard（`arXiv:2605.29313`）已使用经过模式约束、运行时不变量验证和事务提交的 JSON 补丁来更新智能体共享状态。

## 候选差分审计

拟议的 `KEEP/CLEAR/SET` 中间表示，与差分补丁中的无操作、删除和添加/替换一一对应。确定性序列化器只是把成熟补丁语义映射到更新型工具模式；即使本地实验观察到完整参数重生成导致破坏性覆盖，也不能证明该表示具有新的计算改变。

## 判定

当前候选同时被工具参数冗余纠错、部分参数更新基准和自然语言差分补丁方法覆盖。无需运行只会重复验证已知现象的实验。
