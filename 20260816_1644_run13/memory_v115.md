# v115 当前记忆

- OADD 的“抽象构念→数据库可实现测量束”是公开、可执行且仍有明显缺口的工具智能体问题；现象本身不得再作为新贡献。
- 问题单独输入的组件查询扩展在本地盲样本上略高于直接 BM25，但该差分未与公开 OADD 智能体或更强查询扩展公平比较，不提升为候选。
- 不再尝试无置信度的角色—组件均匀轮转、简单集合覆盖或“每组件至少取一项”排序；当前实验显示它增加部分组件触达却损害完整组件与精确列召回。
- 若未来重访 OADD，必须改变组件假设的可识别性，例如提供独立验证信号、学习组件可信度或可证伪的交互反馈；不得只改轮转权重、查询措辞或输出预算。
- v029 继续只作为宿主安全控制形成的外部执行边界；v115 全程使用本地良性公开数据，不产生与其相关的科研证据。
