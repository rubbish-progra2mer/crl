# v080 选择上下文

v080 通过本 Run 机制级去重、一次非权威事实诊断和公开直接工作审计完成。诊断显示 v080 没有已注册实验，Run 内已有大量先验碰撞与少量记录实验；它不作科研裁决。主研究者据此优先检查“先实验还是先判差分”，而非机械增加一次合成运行。

候选的用户价值成立：深度研究报告必须说明某条引用是生成时得到支持、当前仍得到支持，还是只保留历史证据。但方法核由三块现成计算组成：稳定证据单元/执行溯源、历史网址或归档状态检查、双时间检索。局部合成实验无法产生新的实证信息，因而在实验注册前停止。

下一 frontier 不再从“保留更多轨迹、证据包、时间戳、版本号或哈希”生成候选；应寻找输出本身的可裁决语义失效，且干预必须改变语言模型与工具之间的计算，而不是套用数据库或可复现性基础设施。
