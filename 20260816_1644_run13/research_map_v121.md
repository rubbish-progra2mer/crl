# v121 研究图谱

- [CAM-DF](https://arxiv.org/abs/2607.27083) 在五个工具使用领域共 1,343 个任务上学习排序前缀的停止策略。其目标以“现在停止”和“任一更长前缀中的最佳收益”之差的符号作标签、绝对值作错误权重，并证明该训练目标与贝叶斯停止决定对齐。
- 该方法只选择固定相关性排序的前缀，把 $2^m$ 个子集压缩为 $m+1$ 个深度；工具在任何一个被选工具执行前全部确定，运行时不观察工具输出再更新选择。
- Retail 端到端评测把暴露的读工具从 7 个降到平均 4.4 个，观察到的成功率为 0.67，对比全访问为 0.58；论文明确说明 McNemar 检验未发现差异并不建立非劣效性。
- 论文自己的边界控制显示：在 MCP-Atlas 的部分收益、高成本压力和高成本离散度条件下，非前缀的得分/成本规则以 0.042 的收益优势胜过前缀策略，因为它能跳过昂贵的中间工具。论文据此承认价值—成本结构而不是前缀策略承载主要增益。
- CAM-DF 的命题 2 已给出加性价值下的非前缀最优集合：保留所有价值/成本比超过成本压力的工具；命题 3 又证明仅按相关性单调获取不能恢复异质成本下的最优集合。因此“按成本重排或跳过工具”已在目标论文的理论和基线中出现。
- [Online Pandora’s Box for Contextual LLM Cascading](https://arxiv.org/abs/2606.07392) 已把输出自适应获取形式化为序贯查询：每次查询后观察生成结果和实际成本，再按上下文保留指数决定下一接口与停止时机，并给出在线学习和累积遗憾界。
- [Calibrate-Then-Act](https://arxiv.org/abs/2602.16699) 已直接研究大语言模型智能体中的成本感知探索；[TASR](https://arxiv.org/abs/2606.13814) 已研究迭代检索的免训练自适应停止；[CostBench](https://arxiv.org/abs/2511.02734) 已把动态环境中的多轮成本最优规划与适应作为工具智能体评价对象。
- 目标论文还明确把“观察工具输出后更新获取决定”列为当前未覆盖范围，同时在相关工作中承认序贯停止、在线潘多拉盒和成本感知多轮工具使用；因此该限制不是无人占据的方法空白。

结论：固定前缀的弱点是真实的，但非前缀价值—成本选择已被论文自身形式化并实证；输出自适应扩展则落入成熟的序贯信息获取与在线停止族。两条都不能形成新的改变计算。
