# v144 选择上下文

v144 没有把 VALG 的大规模公开案例误写成层级路由的因果证据。公开系统确实提供了细致、可审计的研究流程，并保存来源范围、定理契约、依赖图、局部证明、评审和失败历史；但决定修复深度的核心判断仍由大语言模型评审智能体产生，确定性控制器只消费其标签。

对当前候选而言，最关键的强基线不是“单次整篇证明”，而是已有证明依赖图、分解—审查—修订循环及预算化重试。论文没有冻结模型、问题、预算与候选池后拆除全局诊断或层级路由，也没有报告定位准确率、修复成功率或相对平坦重试的成本—质量曲线。此时做一个更小的本地合成证明任务，只会测量当前本地模型和提示，不能识别论文组件。

因此 v144 归档该路径，不生成 Seed、实验、Reviewer 或 Formal。下一 frontier 必须离开轨迹不确定性、不可约冲突和证明图/评审状态机组合。
