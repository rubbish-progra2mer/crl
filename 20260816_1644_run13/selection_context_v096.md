# v096 选择上下文

该候选最初看似能离开陈旧状态、一般核验和来源计数：问题不是观察是否新鲜，而是观察是否由待验证动作或假设本身诱导。然而最近执行溯源已经同时表示环境动作、状态变化、证据支持和生成关系，经典执行性预测又直接处理决策依赖的数据分布。

在假设驱动检索一侧，POPPER、Fisher-R1 与 Evidence-Informed LLM Beliefs 分别覆盖序贯证伪、统计推断有效性和随证据演化的搜索奖励。当前 Run 的 v023、v055、v084 进一步吸收通用候选维护、选择偏差和科研流程评价。

本地合成实验若显式给出来源边，结果退化为有向图祖先检查；若隐藏来源边，则失败由不可识别性构造决定。若只要求模型选择反证查询，则是 POPPER 的低规模复现。因此没有高信息量实验，下一前沿离开内生证据、自我确认和通用序贯证伪。
