# v172 选择上下文

v172 从扩展后的近期 `cs.AI`、`cs.CL`、`cs.SE` 与 `cs.LG` 扫描中选择论文复现评分，主动避开所有安全过滤、绕过、后门与攻击主题。该问题与 v169 的多保真试验、v170 的结构搜索、v171 的规则维护都不同，关注科学复现物的机制等价验证。

本版没有停在摘要层：完整检查 Replica 的评分单位和质性案例，读取 PaperBench、ReplicationBench、SciReplicate-Bench 及相关测试先验，并静态克隆 OpenAI 官方 `frontier-evals` 仓库的 PaperBench 子树。对 23 份真实评分表的可复现脚本审计确认：实现忠实度检查很密集，已发表消融也被评分，但没有显式评分器生成的留出干预响应运动。

这一缺口不足以保留候选。最小候选由蜕变关系生成、参考—候选配对差分执行和分歧驱动主动测试三部分组成，每一部分都有直接先行；将它们串到论文复现基准只改变应用对象。v029 外部执行边界保持不变，本版只做良性公开论文研究、官方仓库静态读取和本地文本分析，Run 继续 `ACTIVE / AUTONOMOUS`。
