# v137 Recorded 实验计划

## 实验名

`refind-dedup-granularity-counterexample`

## 目的

检验 ReFind 公开状态转移中“局部窗口观察—父会话整体排除”的粒度不一致，比较三种细粒度控制是否保留同会话远距证据。

## 固定实现

- Python 标准库实现 BM25、会话分数求和、RRF 和窗口展开；
- 不调用任何语言模型，不下载数据，不访问真实聊天记录；
- 随机性只用于生成干扰文本、目标位置和会话顺序，种子固定为 0–100；
- 输出单一 JSON，包含聚合指标、逐种子结果、配置和预注册断言。

## 处理组

1. `session`：一旦某会话返回过，后续全部候选轮排除；
2. `none`：不做跨轮去重；
3. `hit_turn`：只排除先前直接命中的轮；
4. `observed_interval`：记录每次返回窗口覆盖的轮，只排除扩展后没有任何新轮的候选。

## 通过条件

- 101/101 个种子中，`session` 第二证据不可达；
- 101/101 个种子中，其余三组第二证据可达；
- 101/101 个种子中，`observed_interval` 不重复完全覆盖的第一窗口；
- 101/101 个种子中，`none` 重复第一窗口。

## 解释边界

通过只支持“目标语义存在一个确定性的粒度反例”和“区间去重是有效修复基线”；不支持真实基准总体退化、不否定论文平均结果，也不支持区间记账的新颖性。
