# v154 选择上下文

本版首先发现 Second Thought 把未知观察前生成的推测接在真实观察之后，表面上可能造成陈旧推测获得位置优势。但当前 Run 的全文回忆立即命中 v106 和 v131：观察守卫已被判定为经典异步投机提交，而且负记忆明确禁止重开。该命中说明 v153 重建全文索引发挥了实际作用，候选在注册实验前即被去重。

CrEST 是本版真正的新训练算子。精读源码后，关键边界不是需要另做一个小型反例：论文附录已经明说逐词元符号保留不推出聚合梯度方向、驻点或全局性能上限。当前资源可以精确构造梯度抵消见证，但那只会复述作者的限定；加入聚合投影又是成熟梯度手术。8 张 H200、单训练种子的主体结果也无法在本机做公平复现。

Harness-IF 则提供了罕见的执行级跨表面遵从数据，并诚实报告裁判交换的不稳定性。目标模型逐规则有／无注入配对会比共享反先验标签更接近因果遵从，但它仍是测量设计，不是新智能体方法；本地两模型合成任务不能把这一标准消融升级为 CCF-B 方法贡献。

所以 `v154` 保留三项边界事实而不强行实验。下一 frontier 继续避开异步提交、一般梯度对齐、提示表面放置和因果评价外壳。
