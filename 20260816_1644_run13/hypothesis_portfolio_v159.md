# v159 假设组合

## H1：部署前用等价编码做闭环变形测试

- 机制：为同一状态生成多个保持语义的观察映射，检查动作分布和闭环终态是否满足预定关系。
- 判定：Semantic Invariance in Agentic AI 已把语义保持变换用于智能体变形测试；当前 Run `v083/v131/v135` 也已关闭同类测试算子。

## H2：对多个编码的动作分布做集成

- 机制：同一状态并行呈现为圆矩、表格和区间等表示，再投票或平均动作概率。
- 判定：一般自一致性／提示集成；且 GPT 与 Claude 的方向反转表明不能用固定“最佳编码”作无标签真值。若用环境回报选权重，则回到策略优化。

## H3：训练编码不变的语言模型策略

- 机制：对语义等价观察的动作分布加入一致性损失，同时保持任务回报。
- 判定：Flip-Flop Consistency、提示扰动一致性学习和不变策略优化已分别覆盖伪标签对齐、扰动正则和跨域最优动作不变性。

## H4：把状态先规范化为类型化数值对象

- 机制：由确定性适配器解析状态，模型只接收规范字段或由外部控制器直接计算动作。
- 判定：若仍序列化给语言模型，表面敏感性不能保证消失；若外部程序直接消费数值，则贡献转为经典控制器／接口编译，不再是新的语言模型智能体推理方法。

## 决定

四个假设均不注册为 Seed。本版保存强现象与跨模型方向反转，不用新的应用标签复活语义不变性、变形测试或提示一致性训练。
