# v161 当前记忆

## 新增正向证据

- 在按技能依赖组织的长任务序列上，保留历史通常提高结果，但大部分平均收益可以由上下文与反馈适应解释，不要求显式技能库。
- 显式技能的优势具有任务条件性：精确格式和可执行评测可能受益，开放式量表任务可能因早期标准过拟合而受损。
- 更大的技能库和更高的技能调用数不是效用证明；较弱模型可能积累更多、更碎片化且更少复用的技能。

## 新增负记忆

- 不再从持续技能碎片化派生有／无技能配对验证；HDSO 已直接覆盖。
- 不再把技能调用频率、自动质量分或文本相似度用作未经验证的持久化依据。
- 不再派生通用效用维护、技能子集—数量—顺序联合解码或技能集成回报；SkillOps、SkillComposer 和 SAGE 已有直接先行。
- 解释归一化回报时必须同时查看原始回报，因为前者只在两种条件都产生有效输出的交集上计算。

## 安全与 Run 状态

v161 仅研究良性的技能效用归因，没有执行外部技能或连接受限服务，没有研究过滤绕过。v029 仍是外部执行边界。Run 保持 `ACTIVE / AUTONOMOUS`，无实验、Seed 或终局。
