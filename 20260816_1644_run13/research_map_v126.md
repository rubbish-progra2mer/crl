# v126 研究图谱

- [SteerBench-Work](https://arxiv.org/html/2608.12654) 发布 106 个构造的单轮提交边界场景，其中 56 个应继续、50 个应阻断；30 个模型条件各运行五次。按所有者标签，错误阻断为 28.1%，错误放行为 1.0%，原始错误数为 471 对 15。排除 17 个由关键词规则推断风险标志的场景后，方向仍为 19.4% 对 1.25%；改用未经协调的三人多数标签后为 41.1% 对 0.36%。因此，当前发布集上的方向性现象成立。
- 论文的 13 个事件镜像保持事故表面而反转证据状态：模型在公共伤害锚点上准确率为 98.5%，镜像为 63.8%。但论文明确指出，该差距本身不识别原因，而且在三人多数标签下缩小到约 4 个百分点；检测器冲突集也不是与镜像匹配的比较组。故“著名事故记忆压过当前证据”只能保留为未识别解释，不能晋级为机制事实。
- 17 个场景的 `success_criterion_change` 由关键词匹配推断；Apple Card 与 Amazon 镜像中的 `eval` 和 `score` 仅因出现在签名审计工具引用里而触发标志。排除该切片后方向仍在，但这同时说明风险标志、授权证据与文本表面尚未被严格析因。
- 论文明确把目标写为：先检测风险触发，再依据风险是否仍未解除决定阻断或继续；未来训练还要求在不增加错误放行的条件下降低错误阻断。因此，“风险检测器 + 解除证据验证器”的自然分解已经是基准作者声明的训练目标，而不是本 Run 新提出的方法核。
- [Temporary Authority, Permanent Effects](https://arxiv.org/html/2607.10487) 已把提交授权形式化为新鲜性、因果先后、效果绑定和提交资格四个条件，并实现 CommitGuard 在耐久效果边界验证授权见证；这直接覆盖“当前解除证据是否仍许可这一具体提交”的执行层计算。
- [Capability Gates Are Not Authorization](https://arxiv.org/abs/2606.28679) 已用 ScopeGate 在每次工具调用前执行范围、授权、金额上限、幂等性和默认拒绝的确定性策略决策，覆盖“不能只凭工具可用性或语言模型判断来授权”的自然修复。
- [Mandato](https://arxiv.org/abs/2608.14074) 已把工具、参数约束、上下文条件、时限和代表关系编码为数字签名的授权委托，在协议层逐调用允许或拒绝并保存证据链。它直接占据“签名解除证据作为可执行授权契约”的设计空间，但当前论文只给出实现状态和量化评估计划，不能把尚未报告的实验当作结果。
- [ContractGuard](https://arxiv.org/abs/2606.18550) 已通过签名来源、类型化契约证明和运行时效果验证保护门控所依赖的工具契约，进一步覆盖“先验证解除证据与实际效果契约，再允许执行”的结构。
- SteerBench-Work 自身承认：场景是构造的单轮描述，不执行真实工具，不测阻断后的行为；继续/阻断池只匹配数量而未匹配创作难度，也没有逐项难度分。因此，当前证据支持基准内的错误方向，不支持部署发生率、历史记忆因果解释，或排除项目难度选择效应。

结论：问题与测量信号有效，但最自然的计算分解同时被基准作者和近期提交授权系统直接覆盖。做一个本地“风险标志 + 签名清除凭证”的二分类玩具实验，只会把已陈述目标改写成规则程序，既不能识别错误阻断的模型机制，也不能形成新的智能体计算。
