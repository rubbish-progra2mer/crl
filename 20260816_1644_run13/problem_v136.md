# v136 问题

v136 延续现象优先的前沿筛选，但不把 v135 的任务坐标运输继续改名。它检查两类结构不同的公开结果：一类是开放式交互评价中的相对优势中心化，另一类是代码智能体外壳的自演化与跨生态迁移。

本版的两个问题分别是：

1. ARC 在同策略内比较相对优势时，是否同时删除了应当消除的策略风格主效应和自主选择策略所需的“任务×策略”交互；能否只抑制前者而保留后者？
2. 当自演化外壳同时包含跨生态共享纪律与生态专属机制时，能否用“共享核心＋局部残差”形成新的可检验计算，而不是重复迁移、蒸馏或原生再演化？

两问都先接受精确先行工作和当前 Run 去重。没有候选通过该门槛，因此不注册实验。v029 仍只记为宿主平台施加的外部执行边界；本版没有研究安全过滤器、绕过技术或其可操作实现。
