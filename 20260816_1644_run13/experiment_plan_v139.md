# v139 Recorded 最小实验计划

## 研究问题

SkillShapley 用“不包含已删除步骤的全部联盟平均效用”检验步骤排序。实验检验：该单步删除目标是否精确对应班扎夫值，以及它能否与沙普利首位排序分离。

## 预注册构造

四个步骤记为 `p1,p2,p3,p4`。构造 33 个确定性二元基准实例，联盟成功数为：

`c(S) = 1[p1 in S] + 8 * 1[p2 in S] + 24 * 1[{p1,p3,p4} subseteq S]`，

联盟效用为 `v(S)=c(S)/33`。这等价于一项只需 `p1`、八项只需 `p2`、二十四项需要 `p1,p3,p4` 协同完成的基准；增加步骤不会降低成功数，因此游戏单调且效用位于 `[0,1]`。

程序将精确枚举 16 个联盟，使用有理数计算：

1. 四个步骤的精确沙普利值；
2. 四个步骤的归一化班扎夫值；
3. 全联盟平均效用与删除每个步骤后的论文式平均效用；
4. 所有 `a,b,t in {1,...,32}` 的同族游戏 `a*1[p1]+b*1[p2]+t*1[{p1,p3,p4}]`，统计出现“沙普利唯一首位为 p1、班扎夫唯一首位为 p2”的构造数量，并检查删除恒等式。

## 预注册判据

缺口成立必须同时满足：

- 预注册游戏对集合包含单调，且全部效用位于 `[0,1]`；
- 沙普利值唯一首位为 `p1`；
- 班扎夫值唯一首位为 `p2`；
- 删除 `p2` 造成的全部联盟平均效用下降严格大于删除 `p1`；
- 每个步骤都精确满足 `全联盟均值 - 删除后均值 = 班扎夫值 / 2`；
- `1..32` 整数网格中至少存在一个同类排序反转，且所有网格游戏的删除恒等式零违例。

任一条件失败则关闭 H1。全部通过只证明第一删除点的验证目标与班扎夫精确对齐且可与沙普利排序分离；不评价真实 SkillsBench 数据，不否定沙普利的公平分摊公理，也不评价 BAES 对沙普利值的近似精度。

## 安全与资源

实验只运行 Python 标准库的集合枚举和有理数运算，不调用网络、模型、智能体、外部应用或安全过滤器；预计少于一秒完成。
