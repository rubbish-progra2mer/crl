# v148 当前记忆

- 比较无记忆助手只能识别“使用历史的完整系统”效应，不能识别编译相对检索的优势。
- 公平编译—检索比较必须固定抽取出的规则内容、基础模型、总调用、词元预算、质量筛选和任务样本；否则独立上下文、更多计算与个性化内容混杂。
- 独立专用智能体若只携带提示和多步蓝图，仍是适用技能/程序性记忆的路由与执行，不因另起一次模型调用自动成为新记忆范式。
- 不再从行为/任务模式分离、嵌入加问卷路由、批评者门控或风格减弱派生候选；它们分别属于偏好作用域、级联分类和技能验证。
- 触发后胜率不能替代全流量系统效果；必须同时报告未触发、误触发、代价和准确性损失。
- 合成用户与同家族语言模型裁判不能建立真实个性化收益，`v088` 的外部效度边界继续适用。
- 下一 frontier 离开长期记忆、技能编译、个性化路由与合成角色评价。
