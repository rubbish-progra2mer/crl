# v134 研究地图

## 跨环境委托协商：直接方法覆盖

- [SocialRL](https://arxiv.org/abs/2608.13787) 已在 Deal-or-No-Deal、CaSiNo、Craigslist、求职协商、日历协调和市场议价六类环境中，用可核验经济回报训练代表委托人的 4B 策略。
- 论文不只测量协商结果，还直接实现跨环境专家强化学习、按迁移关系排序的级联强化学习，以及按教师—学生剩余差距分配蒸馏预算的 MOPD；其行为分析已覆盖选择性让步、拒绝、底线保护和更坚定的承诺。
- “按剩余协商能力缺口自适应分配训练”也不是残差：SocialRL 已明确以差距闭合采样，并证明移除几乎没有教师余量的 CaSiNo 更好。当前 Run v107、v110 与 v119 又已覆盖预算、训练信用和选择性更新。

## 相似性信号诱导合作：现象真实，修复计算不新

- [Do LLMs Take Care of Their Own?](https://arxiv.org/abs/2608.12125) 首次系统扫描分级相似性信号，并给出相似性均衡的博弈论模型。论文发现，相似性分数来自哪个数据域对合作率几乎没有影响；即使分数来自随机硬币/骰子，极高分数仍可诱导合作。
- 论文进一步把外生答案一致率与模型自评相似度分开；模型看到对方解释时会系统性高估相似，且只暴露标量分数，不向行动者泄露底层轨迹。因而“无关相似标签充当说服信号”是被隔离出来的现象，而非本版臆测。
- 最自然的防御是只准入能预测当前战略行为的相似性信号，并用无关域或破坏信号作负对照。但 [When Do Institutions Beat Intelligence?](https://arxiv.org/abs/2608.11357) 已把报告权、有效性验证、共享状态更新与行动表示写成制度算子，并要求有效—破坏信号交互后才给机制信用；当前 Run v009 又已保存来源独立性与无根复制不增益。把“相似性”换成新的信号名不改变准入计算。

## 抵抗错误同伴与接受正确同伴：前沿与选择性计算

- [Conformity Mitigations in Large Language Models Lie on a Single Resistance–Receptivity Frontier](https://arxiv.org/abs/2608.11247) 在 23 个开放权重模型、19 个条件和三个数据集上同时测量抵抗与接受。五种快速回答缓解法都以更低接受率换取更高抵抗率，均落在同一前沿。
- 先推理再看同伴只在可推导的 MMLU 子集上同时提高两轴；对事实回忆、GPQA 与 SimpleQA 不形成稳定越界。自然候选“先判断任务可推导性，再选择独立推理或同伴更新”本质上是按可核验性分配推理预算的选择性路由，而非新的社会交互原语；当前 Run v057、v061、v107 与 v119 已覆盖可达证据、信息价值和预算路由。
- v009 已直接记录反从众讨论与证据根聚合；重新加入反从众提示、质疑者或独立作答是精确方法族重复。

## 策略译码器表型：目标论文已做干预复核

- [Not a Monolith](https://arxiv.org/abs/2608.10262) 固定 GPT-5.4 Mini 把不同模型生成的自然语言策略转换成 Python 策略，以隔离生成能力与编码能力；又预注册抽取 10% 策略改用 DeepSeek V4 译码并重跑 500 次 Moran 过程。
- 复核保留了攻击性均衡结构，却令若干合作—中性多数类别翻转。论文因此把攻击性结论与译码器敏感的细粒度结论分开，没有把译码器视为无误测量层。
- “多译码器不确定性区间”只扩展论文自身的译码器稳健性复核；更一般的自然语言—可执行语义差分又与当前 Run v021、v030、v044 和 v105 的协议可识别性、跨工件执行核验及描述—行动断裂重合。

## 结论

v134 没有幸存候选。协商训练和跨域合并由 SocialRL 直接完成；相似性相关性门归约为有效信号准入；反从众越界归约为可导出性条件下的选择性计算；译码器敏感性已被目标论文直接干预测量。未注册本地实验。
