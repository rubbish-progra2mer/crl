# v159 选择上下文

v159 从数据库、程序语言和信息检索交界处扩展搜索后，排除了安全攻击型持久实体路线，没有下载或运行任何注入、插件或过滤绕过材料。最终选择状态编码论文，因为它完全是良性的闭环动力学实验，而且提供当前 Run 最近版本所缺的强现象层证据：同一个由系统自身产生的物理场被重新编码后，动作分布和群体终态都改变。

该工作还做了三个重要控制：相同场内重放隔离编码算子、同编码跨块复测给出噪声底、Claude/Gemini 微观复现与 Claude 闭环复现检查跨模型。跨模型方向反转反而否定了“某种压缩天然更好”的简单解释，支持把观察映射视为模型—接口联合策略的一部分。

但本地复现没有新的决策价值。目标论文已完成数千次相同场调用和十万量级闭环调用；用本机小模型重做几个等价表格只会再次证明提示敏感。候选修复也已有直接归属：已知等价关系用于变形测试，多个编码投票属于提示集成，损失对齐属于一致性训练，从任务数据选择编码属于模型条件化提示／策略优化。

因此本版不注册实验。这里的“不实验”不是资源不足，也不是安全控制；它来自现象已充分验证而方法空间已被先行覆盖。v029 的外部边界保持原样。
