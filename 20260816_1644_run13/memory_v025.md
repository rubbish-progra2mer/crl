# v025 记忆

- 负面记忆：当目标是检测一段候选文本相对参考文本的局部语义变化时，完全隐藏候选的单边测试生成会产生覆盖负担；少量通用情景不一定触及实际变化位置。
- 负面记忆：把直接文本比较拆成“生成见证—分别执行—比较动作”并不自动获得稳健性；中间接口会引入模式失败、自校验淘汰和执行不一致。
- 负面记忆：无损输出归一化可以修复评测口径，但不能被当成方法收益；修复前后结果必须分别保留。
- 正面事实：短而明确的操作政策对上，同模型直接成对判断可能远强于表示相似度门；后续方向应寻找直接判断仍失败且可由新计算修复的现象，而不是预设多阶段计算更可靠。
