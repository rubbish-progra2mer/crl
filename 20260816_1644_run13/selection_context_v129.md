# v129 选择上下文

v128 关闭不可约个人记忆冲突后的效用识别问题。v129 刻意跨越聚合统计、世界模型、评测停止和电子表格结构推理四个层级，减少连续检索落在同一类澄清/风险问题上的局部性。

计数尺度漂移是真问题，但原论文已推导其原因并给出校准似然聚合；数字孪生路线的自然增强被主动探索、部分可观测建模和反例引导综合吸收；贝叶斯停止对题目顺序的依赖也被论文明确列为可交换性假设，分层随机化是经典修复。三者都不值得用本地模拟重复已知性质。

SheetCompass 的交集定义提供了最尖锐的形式反例：共享交集不能覆盖只属于单个子任务的必要节点。但把交集改为逐步子图或并集只是一处集合语义修正。由于匿名代码域触发宿主拒绝，本版本只把它记录为论文规范矛盾，不推断代码行为，也不尝试绕过访问限制。

因此 v129 是有明确反例但无论文级剩余内核的负结果。下一前沿离开通用证据投票、测试时世界模型、序贯评测停止和电子表格子图拼接。
