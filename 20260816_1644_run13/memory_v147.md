# v147 当前记忆

- 工程生命周期的完整性不等于方法计算的新颖性；必须分离角色编排、证据追踪和真正改变决策的算子。
- 版本绑定、候选变化后旧批准失效、模拟证据标签和人类最终发布权是良好治理实践，但当前公开证据没有识别其边际效果。
- 不再从“所有者—开发智能体—模拟用户—测试智能体”多角色组合派生候选，除非有组件消融或真实使用者比较。
- 语言模型扮演所有者不能验证责任、信任校准或复核成本；真人外部效度不能由本地合成角色替代。
- 行为能否由个人控制与是否依赖他人可能影响干预成功，但它属于真实社会行为边界；仅添加字段不是新计算。
- 下一 frontier 离开来源治理、责任账本、虚拟用户、意图确认和发布门控。
