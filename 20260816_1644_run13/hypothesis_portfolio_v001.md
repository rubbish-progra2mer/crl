# v001 假设组合

## H1：工具结果状态语义混叠

- 状态：`METHOD_KILLED_PHENOMENON_SURVIVES`
- 假设：即使原始响应含有足够事实，代理仍会把合法空、明确失败、未知副作用、语义无操作和已确认成功混叠；显式分面契约会改善下一动作选择。
- 最小测量：五类结果、每类两个表面模板、三个本地模型；动作集合固定为 `FINISH / RETRY / VERIFY / REVISE`。
- 最强吸收基线：同一模型读取相同原始响应，先自行抽取分面状态再决策。
- 致命结果：自解析或通用策略提示与显式分面契约等效。
- 结果：在可稳定解析的 `qwen2.5:7b` 与 `qwen3:8b` 上，显式分面契约均为 10/10；通用策略提示也均为 10/10，自解析分别为 9/10 与 10/10。显式契约未形成独占增益。
- 结论：通用方法候选死亡；原始条件下两个稳定模型都曾把一个“提交后连接丢失、服务端结果未知”的案例误判成直接重试，故现象仍存，但不足以单独构成方法贡献。
- 测量警告：`qwen3:4b` 每个条件仅有 6--8 个可解析结果，存在输出截断，不能用于方法比较。
