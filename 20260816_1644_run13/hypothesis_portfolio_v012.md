# v012 假设组合

## H1：资源版本驱动的工具观察失效

- 状态：`PRIOR_COLLISION`
- changed computation：读取结果携带资源版本和读集；写操作推进版本并使依赖旧版本的观察失效；使用陈旧观察的动作在执行前必须刷新。
- 最强基线：ToolCacheAgent 的依赖感知缓存失效 + Matrix 的事实依赖选择性失效 + MemTX/并发异常工作的版本化事务保护。
- 未执行实验：在日历、库存和文件工具中注入读后写与外部更新，候选会按构造阻止陈旧读取，但无法产生超出直接基线的方法差分。
- 终止理由：核心计算已被直接先行工作覆盖，剩余差异只是单智能体工具运行时的工程配置。
