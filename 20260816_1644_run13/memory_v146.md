# v146 当前记忆

- 大语言模型生成或修改代码，不会自动把传统差分故障注入变成智能体方法；要区分被测对象与测试算子。
- 共享注入点、相同确定性故障和逐对旧/新比较是强验证设计，但只证明所测故障空间中的离线行为一致。
- 不再从“为技能或智能体生成异常路径”派生新候选；`v062` 已表明生成式变异未超过程序化固定变异。
- 同语义内容下，结构化 JSON 与丰富自然语言对代码正确性的差异绝对值不超过 `0.023`；格式不是计算。
- 丰富要求可能改善静态质量却降低功能通过率，任何契约增强都必须同时保留任务主目标并与等语义自然语言基线比较。
- 下一 frontier 离开软件变异/差分测试、异常路径注入和表示序列化。
