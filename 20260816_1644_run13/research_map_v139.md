# v139 研究地图

## 目标工作

- [SkillShapley: Boundary-Adaptive Shapley Valuation for Skill Step Attribution in LLM Agents](https://arxiv.org/abs/2608.13173) 将固定技能的语义步骤作为参与者，联盟效用是固定基准子集上的平均成功率。
- 它先用精确沙普利值验证步骤排序，再提出边界自适应边采样（BAES）以较少的唯一技能变体近似沙普利值。
- 核心删除验证的纵轴是“不包含已删除参与者的全部联盟的平均成功率”；论文比较 Individual、Leave-One-Out、Random Removal、LeastCore 和完整沙普利，但全文没有班扎夫基线。
- 论文的三个精确技能只各用三个基准实例，联盟效用取值为 `0, 1/3, 2/3, 1`；作者承认 BAES 在有限自适应预算下是面向排序恢复的有偏近似。

## 最近公平基线

- 班扎夫值是所有不含参与者的联盟上边际贡献的简单平均；沙普利值则先在每个联盟规模内平均、再对规模等权。二者是不同的经典半值。
- UAI 2022 的 *Improved Feature Importance Computation for Tree Models Based on the Banzhaf Value* 明确给出班扎夫的均匀联盟边际公式，并比较其与沙普利的不同权重和归因性质：<https://proceedings.mlr.press/v180/karczmarz22a.html>。
- AISTATS 2023 的 *Data Banzhaf* 已把班扎夫值用于机器学习数据估值并分析其稳健性：<https://proceedings.mlr.press/v206/wang23e.html>。
- 因而若缺口成立，最直接修复不是新归因方法，而是把验证目标与经典半值对齐，并同时报告沙普利公平分摊目标与班扎夫均匀删除目标。

## 代数关系

令 `N` 为全部步骤，`v(S)` 为联盟效用，全部联盟的均值为

`mu = 2^-n * sum_{T subseteq N} v(T)`。

删除步骤 `i` 后的论文式单步分数为

`r_i = 2^{-(n-1)} * sum_{S subseteq N\{i}} v(S)`。

归一化班扎夫值为

`beta_i = 2^{-(n-1)} * sum_{S subseteq N\{i}} [v(S union {i}) - v(S)]`。

逐项配对可得 `mu - r_i = beta_i / 2`。因此论文删除曲线在第一步的最陡下降排序与班扎夫排序完全相同，而不必与沙普利排序相同。

## 当前 Run 去重

- v011 关闭的是闭环智能体中静态未来拼接和路由标签，不涉及合作博弈半值或删除评价目标。
- v106/v131 关闭的是消息反事实价值和技能适用性门控，不涉及沙普利—班扎夫权重错配。
- 全 Run 既有问题、研究图谱、失败归因和记忆中没有班扎夫或技能联盟删除目标的精确对象。

## 进入实验的残余

需要一个取值在 `[0,1]`、可解释为多个二元基准实例平均成功率、且单调的四步骤合作博弈，使沙普利唯一首位与班扎夫/单步删除唯一首位不同。若存在，则只证明验证目标不专属于沙普利；不证明目标论文三个真实技能的经验排序错误。

## Recorded 结果

- `skillshapley-removal-target-counterexample-001` 成功完成，层级为 `RECORDED_NON_SUPPORTING`；八项预注册判据全部通过。
- 33 个二元实例的单调构造中，沙普利值为 `p1=3/11`，`p2=p3=p4=8/33`，故 `p1` 唯一首位。
- 班扎夫值为 `p1=7/33`、`p2=8/33`、`p3=p4=2/11`，故 `p2` 唯一首位。
- 全联盟平均效用为 `5/22`。删除 `p1` 的下降为 `7/66`，删除 `p2` 的下降为 `4/33`，所以论文式第一删除点选择 `p2`，与班扎夫首位一致而与沙普利首位相反。
- `a,b,t in 1..32` 的 32,768 个单调同族游戏中有 887 个出现相同首位反转；全部游戏、全部步骤的 `删除下降=班扎夫/2` 恒等式零违例。
- 结果不触及目标论文三个真实技能的经验排序，也不触及 BAES 逼近沙普利的数值性能。它只说明删除验证的第一点不能作为沙普利目标独有的行为验证。

## 方法判断

将验证基线改为班扎夫或同时报告两种半值，可以修正目标—评价对齐，但班扎夫是经典合作博弈量，并已有机器学习归因与数据估值方法。这是有价值的评价审计，不形成新的智能体计算或 CCF-B 方法 Seed。
