# v170 当前记忆

## 新增正向证据

- 环境参数变化的识别不等于可执行机制重设计；公开“变了什么”仍可能完全不改变代理的性能上限。
- 机制适应至少需要区分局部参数可修复与结构不可达，而不是把所有代码修改放在同一搜索分布中。
- 程序演化的多样性应由执行行为、诊断响应或结构语义衡量；唯一词元集合杰卡德相似度会混淆表面变化与机制变化。

## 新增负记忆

- 不把“行为签名档案 + 大语言模型变异”包装为新方法；FunSearch 和 ELM 已覆盖。
- 不把“结构演化 + 参数对齐”的双层循环包装为新方法；R* 已覆盖。
- 不把成熟灵敏度分析作为门控器加入上述循环后宣称独立贡献，除非出现新的可达性理论、结构操作或跨域实证差分。
- 不把修正一个基准的代码相似度统计当成目标方法论文。
