# v157 失败归因

## 类型

`ADAPTIVE_API_ABSTRACTION_CLOSED_BY_TOOL_INTERFACE_SYNTHESIS_ROUTING_AND_EXECUTABLE_POLICY_PRIORS`

## 直接原因

- VAKRA 已跨 62 个领域确认接口范式、跨源跳数和自然语言政策会显著改变表现，现象不缺少小规模验证；
- 按任务／模型选择接口粒度属于工具路由与工具集选择；
- 把稳定多跳链封装为宏端点属于验证式工具制造和标准流程编译；
- 自然语言政策转为允许能力边界属于确定性访问控制与能力—效果推理；
- 跨源实体参数映射属于模式对齐、动态依赖与参数溯源；
- 上述模块组合没有新增状态、更新规则或验证边界。

## 非原因

- 不是否认 VAKRA 的模型排名反转、跳数退化或不可回答政策失败；
- 不是因本机无法运行 8,000 余个接口而跳过可改变结论的实验；
- 不是宿主安全控制或任何安全绕过尝试；
- 不是 Run 终局。

## 决定

不注册实验或 Seed。保留 VAKRA 作为接口抽象、跨源参数传递与政策约束的综合验证基准；Run 保持 `ACTIVE`，下一版离开接口粒度、工具制造和访问控制方法族。
