# v084 研究图谱

## 多模型评审与错误独立性

- 《当智能体看起来相同：量化蒸馏导致的工具使用行为相似性》用响应模式相似度和动作图相似度区分必需行为与非必需偏好，并在 8 个提供方的 18 个模型上验证蒸馏导致的行为收敛。
  - https://aclanthology.org/2026.acl-long.478/
- 《大语言模型有多独立？》直接把共享预训练、蒸馏和对齐造成的行为纠缠用于验证器集合审计，并按推断出的独立性重加权，较多数投票最高提高 4.5%。
  - https://arxiv.org/abs/2604.07650
- 《大语言模型中的相关错误》在超过 350 个模型上报告显著错误相关；《量化思维多样性》进一步给出按准确率调整的正确性相关与集合增益之间的经验规律，并包含多轮工具使用任务。
  - https://arxiv.org/abs/2506.07962
  - https://arxiv.org/abs/2607.17384
- 当前 Run v009 已关闭把共享证据转述数当独立证据，v014 又在不假设独立的条件下处理组合可靠性。按供应商、模型名或表面角色选择“独立评审员”没有剩余方法差分。

## 执行动作与最终陈述一致性

- 《从自信收尾到静默失败》在 8 个模型家族的 9,876 条 tau2-bench 轨迹和 4 个模型家族的 1,879 条 AppWorld 轨迹上直接研究“环境状态失败但智能体声称成功”；语言模型裁判的曲线下面积不超过 0.65，而轻量域校准检测器达到 0.83 和 0.95。
  - https://arxiv.org/abs/2606.09863
- Goal-Autopilot 已把终止时允许声称什么建模成独立于能力的诚实性约束，并以状态门和覆盖条件保证失败时诚实停滞。
  - https://arxiv.org/abs/2606.11688
- DialogTool 已把工具创建、感知、选择、执行、响应生成和角色一致性纳入完整生命周期；《通过规划对齐智能体》的全轨迹奖励又明确要求最终回答与工具输出一致。
  - https://aclanthology.org/2025.findings-acl.284/
  - https://aclanthology.org/2026.acl-long.1062/
- 当前 Run v076 已专门关闭“部分完成却宣称全部交付”，v054 已处理可独立核验的交付残留物。动作—陈述一致性不是空白。

## 科研分析的有效性与复现

- P-Bench 包含 425 个跨经济学、生物学和医学的开放式假设检验任务，要求选择统计方法、计算概率值并形成结论；Fisher-R1 直接用可验证统计奖励训练智能体。
  - https://arxiv.org/abs/2608.07437
- ARAC-Bench 把自主科研过程拆成提案、实验和综合三条可追踪维度，对 11 个框架的最好对齐分仅为 67.9/100，并报告与博士生排序 0.8141 的相关。
  - https://arxiv.org/abs/2608.12788
- Replica 构建可扩展论文复现任务空间，并用低噪声、与人工一致的量表裁判训练 27B 科研智能体。
  - https://arxiv.org/abs/2608.13331
- 当前 Run v044 已审计论文声明与代码执行差分，v055 已处理自适应科研搜索中的验证污染，v059 已处理不可靠科学前提。再做假设检验检查表、复现代理或过程量表属于直接基准/训练路线。

## 工具置信与按实例路由

- ProbeCal 已校准工具智能体对提示和执行轨迹实际有效性的内部概率，并据此选择提示和路径。
  - https://aclanthology.org/2024.findings-emnlp.978/
- 《置信二分》直接比较证据工具与验证工具造成的不同校准行为，并联合优化任务正确性和校准奖励。
  - https://aclanthology.org/2026.acl-long.520/
- 《检测到效应不等于学会按实例行动》给出奖励信噪比可检测下限，并表明低于该下限时按实例获取策略不能胜过随机，能够实现的只剩设计时情境门。
  - https://arxiv.org/abs/2608.10441
- 当前 Run v043 已关闭逐步不确定性传播和异构分数校准，v081 已关闭一般信息效用/证据充分性停止。置信度阈值、校准器和按实例获取路由均没有新计算。

## 结论

四条入口都存在直接问题定义与相应评价或干预方法。公开证据远强于本机小样本复现；v084 不注册实验，Run 继续保持 `ACTIVE`。
