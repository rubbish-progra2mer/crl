# v079 选择上下文

v079 暴露出一次应如实保留的候选生成缺陷：v078 的下一前沿重新提出了 v038 已关闭的跨工具量纲问题。通过 Run 内文本检索在实验前发现并停止，未造成重复运行，但说明后续候选必须先对全部问题与负记忆做机制级去重。

多智能体并发和工具刷新是结构正交的备选，但 2026 年工作已经分别提供极端死锁现象、形式化协调保证、机器验证一致性层级、并发运行时和时间感知工具调用数据。增加锁、版本号、资源排序或时间戳都不形成新内核。

下一 frontier 转向深度研究智能体的引用时间语义：报告生成时真实支持主张的网页，可能在审计时保持同一网址却改变内容。必须区分“生成时支持”和“当前仍支持”，并先排除内容寻址快照、执行溯源、双时间检索和离线研究基准。
