# v164 当前记忆

## 新增正向证据

- 工具型智能体可能只是在工具输出后更可靠地服从，而不是用自身能力仲裁；更强骨干不保证更有怀疑能力。
- 评估必须至少拆分原始工具准确率、智能体—工具一致率、无工具替代和逐例可选动作神谕差距。
- 在已有特征上更换复杂路由器不能解决信息缺失；五种子和第二数据集都显示大部分逐例神谕空间无法由标准不确定性代理恢复。

## 新增负记忆

- 不再从盲目工具服从派生概率校准、分歧触发专家调用或信息价值探测；ProbeCal、DART、TRUST 与预算控制已有直接先行。
- 不把“没有调用工具”解释为选择性信任；必须先证明模型有可靠调用能力。
- 不把 Qwen 的极端服从幅度外推给 Mistral、OLMo 或所有工具类型；跨家族控制显示幅度有边界。
- 不依据单种子门控结果推广全局收益；该论文的五种子结果推翻了初始单种子增益。
