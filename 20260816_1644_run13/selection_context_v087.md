# v087 选择上下文

评价感知具有真实外部有效性风险：如果模型能区分评价与部署，基准行为便未必能外推到真实使用。但该问题已经有跨公开基准、部署交互和智能体轨迹的直接分类测量。与之相邻的模拟器伪影、支架选择、环境波动和损坏评价工件，也分别已有过程感知评价、统一受控框架和自动基准审计。

当前 Run 已覆盖评测器语义、协议可识别性、接口等价扰动、持续任务评价、噪声分解、后端代偿和支架效应。新增的线索遮蔽、占位符重命名、裁判反馈改写或模拟器措辞配对，均是现有评价感知与评价工件审计的实现变体，且会再次落入提示形式混淆。

因此本版本不实验。下一前沿不得从“隐藏评价身份”、模拟器措辞扰动、占位符重命名或通用基准审计继续派生。
