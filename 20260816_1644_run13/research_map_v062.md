# v062 研究图谱

## 最近方法

- [Beyond Local Accuracy](https://arxiv.org/abs/2608.13326) 给出有限冻结策略类上的碰撞审计与最小命中集支持综合，但明确不声称策略类穷尽。
- [AgentAssay](https://arxiv.org/abs/2603.02601) 为非确定性智能体工作流提供固定变异算子、变形关系、三值统计判定和预算分配。
- [Mutation-Guided LLM-based Test Generation](https://arxiv.org/abs/2501.12862) 在软件测试中生成当前未被杀伤的变异体及相应测试。
- [Property-Guided LLM Program Synthesis](https://arxiv.org/abs/2605.16142) 用可执行性质检查和具体反例修复规划启发式程序。
- [CodeARC](https://arxiv.org/abs/2503.23145) 让程序综合智能体查询隐藏函数并接受差分测试反例。

## 候选差分

上述反例循环的组成部分都存在，但“被综合对象”不同：候选不修复被测程序，而是生成与目标智能体在现有评测支持上行为等价的替代策略；“被补全对象”是评测协议支持。算法循环为：

1. 在当前支持上生成一致的受限行为程序；
2. 用完整本地判定器寻找其与目标策略的未观测差异；
3. 选择覆盖最多当前碰撞程序的区分状态；
4. 将该状态及目标动作加入支持并重复。

这仍可能只是把变异引导测试机械移植到智能体协议，因此必须以等预算固定变异集和随机支持为强基线，并检查跨生成模型迁移。
