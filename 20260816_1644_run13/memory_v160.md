# v160 当前记忆

## 新增正向证据

- 智能体记忆的端到端成本必须同时计算检索、回答与写入；仅以对话轮数或消息长度估计，在目标基准的多种记忆系统上有很大的留一误差。
- 外部记忆相对完整历史的盈亏平衡不是系统无关常数；记忆后端、推理骨干和推理强度会共同改变是否以及何时回本。
- 成本最低与准确率最高不是同一配置，记忆系统选择本质上是条件化的成本—质量决策。

## 新增负记忆

- 不再把“预测会话长度后切换记忆”作为论文级方法：已知长度是部署核算，未知长度的纯成本版本是经典在线切换。
- 不再从同一证据派生查询感知预算路由、记忆结构门控或固定检索预算；BudgetMem、FluxMem、ShardMemo 与 LightMem 已直接覆盖。
- 不再把延迟写入或按重复度触发整合当作开放机制；RecMem 已实现该计算。
- 不用目标论文跨成本单元复用的一次准确率测量训练长度条件路由器，也不把 Hindsight 列误当成完全受控比较。

## 安全与 Run 状态

v160 只处理公开论文中的非操作性成本测量和方法差分，没有调用外部记忆后端或受限网关，没有研究过滤绕过。v029 继续仅作为外部执行边界保存。Run 保持 `ACTIVE / AUTONOMOUS`，无 Seed、无终局。
