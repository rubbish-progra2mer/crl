# v126 假设组合

v126 不注册活动假设。

## 候选一：风险触发—解除证据双阶段门控

- 状态：直接方法碰撞。
- 原因：SteerBench-Work 已明确提出同一训练目标；CommitGuard、ScopeGate、Mandato 与 ContractGuard 分别覆盖提交时见证验证、逐调用授权、签名委托和契约完整性验证。

## 候选二：事故记忆抑制器

- 状态：因果未识别，不能晋级。
- 原因：锚点—镜像差距在所有者标签下很大，但在三人多数标签下缩小到约 4 个百分点；检测器冲突不是匹配比较组，文本难度和非提交风险标志也未均衡。现有数据不能区分事故记忆、证据解析失败、标签差异或项目难度。

## 候选三：基于签名清除凭证的本地合成门控

- 状态：实验前关闭。
- 原因：确定性检查签名、范围、时效和效果绑定会复现已有授权执行机制；让语言模型仅对合成文本做继续/阻断分类又无法验证真实提交边界。两种实验都不会改变先验碰撞或因果识别结论。

未运行本地实验，也未调用任何外部模型或真实工具执行环境。关闭依据是贡献差分与识别能力不足，不是宿主安全控制、科研反证或 Run 终局。
