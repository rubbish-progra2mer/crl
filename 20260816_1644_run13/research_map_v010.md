# v010 研究图

## Run 内固定知识库

- P040：智能体会出现错误成功判断，支持“局部结果被当作任务完成”的失效背景。
- P074：工具契约若缺少真实后置条件，会把错误状态提交为已验证状态。
- P085：工具检索标签并不穷尽相关工具，说明“未检出”不能自动等价于“不存在”。
- P030：状态有效性需要授权读出，而不能由语言模型自行判定。

## 当前直接最近邻

- DADL（arXiv:2605.05247）：声明式描述接口的认证、分页、响应整形与访问级别；分页可设为 `auto`，由运行时透明抓取全部页面，也可设最大页数安全边界。
- Levy（VLDB 1996）：研究不完整数据库中何时仍能得到完整查询答案，并把查询完备性刻画为对插入更新的独立性。
- Fan 与 Geerts（TODS 2010）：在部分闭世界约束下判断数据库相对某查询是否完整。
- Razniewski 等（arXiv:2305.05403）：系统总结开放世界知识库中的完备性、召回与否定推理。
- DADL 的自动分页负责获取覆盖；查询完备性理论负责判断当前覆盖是否足以支持完整答案。两者组合已吸收候选的核心义务门控。

## 结论

“覆盖携带型否定结论”是重要工程规则，但当前形式没有超出自动分页加查询完备性陈述的组合。
