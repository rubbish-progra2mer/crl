# v129 假设组合

v129 不注册活动方法假设。

## 候选一：机会感知的证据沉默建模

- 状态：`KILLED_BY_DIRECT_STATISTICAL_PRIOR`。
- 设想：把来源未检索、检索后无关、知情沉默和显式反证作为不同观测，再聚合决策。
- 失败原因：一旦这些状态可观测，计算就是多结果混淆矩阵、非随机缺失或带项目难度的标注者模型；若不可观测，又无法从现有输出识别。原论文已经明确区分检索遗漏与知情沉默，并给出多结果似然扩展。

## 候选二：反例驱动数字孪生的主动探测

- 状态：`KILLED_BY_CEGIS_POMDP_COLLISION_AND_RUN_MEMORY`。
- 设想：在提交动作前选择最大化环境模型版本空间收缩的探测，并在观测别名出现时引入历史状态。
- 失败原因：版本空间探测属于主动模型学习/反例引导综合，历史状态属于部分可观测状态提升；Twin 已把探测、回放和修复组合起来，本 Run 也已审计相邻计算，没有剩余方法原子。

## 候选三：覆盖约束的贝叶斯评测停止

- 状态：`KILLED_BY_CLASSICAL_SAMPLING_DESIGN_AND_RUN_MEMORY`。
- 设想：每个预声明题目层未达到最低覆盖前禁止全局停止，之后聚合分层后验。
- 失败原因：这是分层随机抽样与序贯停止的直接组合；论文已明示顺序可交换性边界，v055/v097 已覆盖自适应验证和评测预算。没有新的文本/工具智能体计算。

## 候选四：任务覆盖保持的电子表格子图组合

- 状态：`SPECIFICATION_BUG_NOT_METHOD_KERNEL`。
- 设想：以每步子图供该步编程，或使用子图并集覆盖全部步骤，把交集仅作为公共核心。
- 失败原因：反例与修复都由基本集合包含关系直接决定；即便官方实现确实使用交集，也更像实现/规范缺陷，而非可承载 CCF-B 方法论文的新内核。代码未能在宿主允许范围内核验，不能提升为实现事实。

本版本没有机器实验。上述四项的最小合成实验分别只会复现论文定理、经典部分可观测探索、抽样顺序偏差或空交集反例，均不会区分新方法与现有修复。
