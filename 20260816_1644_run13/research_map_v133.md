# v133 研究地图

## 记忆与事务：当前 Run 精确重复

- [ConsistencyGate](https://arxiv.org/abs/2607.22962) 以多次软支持评分做写入时准入，降低长期记忆中的幻觉事实污染；当前 Run v092 已完整记录该论文、三个基准、四个模型，以及经验跟随下的添加/删除策略。本版不重开。
- [Agentic Transaction](https://arxiv.org/abs/2608.13900) 把多工具工作流置于 ACID 事务语义；当前 Run v108 已以“智能体 ACID、语义原子性和持久副作用验证”直接关闭，v001、v008、v034、v075 与 v125 又覆盖后置条件、幂等重试、补偿、清理与恢复。
- [TANGLE](https://arxiv.org/abs/2608.13921) 研究个人记忆中的不可约冲突，但 v116 已记录其 541 个实例与冲突感知行动策略，v128 又审计了六类行动在缺少损失、提问成本和可逆性价值时的不可识别性及其信息价值碰撞。

## 自指响应不稳定：诊断而非方法

- [Self-Referential Induction Increases Response Instability](https://arxiv.org/abs/2608.13258) 在 Gemini、温度 0.7 上对每题采样 30 次，以压缩后核心主张的句向量余弦定义不稳定度；四个自指问题均值为 0.343，四个不可解哲学问题为 0.192，四个可核验问题为 0.105。
- 该结果只覆盖一个模型和每组四题，且测量依赖语言模型压缩与嵌入距离。论文明确不能区分输出分布欠确定、温度敏感或措辞自由度。自然下一步是测量复核，而非改变智能体在线计算；共识、稳定性门控或弃答又回到当前 Run 已关闭的方法族。

## 无环境轨迹判分

- [RubricForge](https://arxiv.org/abs/2608.13564) 已用带环境真值的少量轨迹反思式演化判分量表，冻结后以单次模型调用无环境判分。其在 tau-bench 上把失败轨迹误判通过率从 0.173 降到 0.115，但总体二值一致性对通用 G-Eval 的差异不显著；WebShop 排序较好而绝对校准较差。
- 目标论文已直接完成“从真值轨迹归纳可读量表”。剩余的轨迹渲染充分性是其明确承认的承重假设：若渲染后的观察不能识别环境结果，任何量表都无法恢复丢失信息。当前 Run v021 已用观察等价类和跨目标碰撞做协议级可识别性审计，v057 已覆盖证据/行动可达性，故不再派生渲染充分性方法。

## 开放式策略比较与科研候选选择

- [ARC](https://arxiv.org/abs/2608.13622) 已把开放式交互中的相对优势计算从同题混合策略组改为同题、同策略条件组，给出策略条件采样、方差分解、熵正则与 INTER³-86K 数据。训练时按策略分组、推理时移除策略提示是论文核心方法，不留“公平比较单位”残差。
- [AI Research Preference Models](https://arxiv.org/abs/2608.13940) 已用只推理偏好模型和可运行小规模先导实验的智能体偏好模型选择值得执行的科研候选，并报告相对无偏好模型的速度与得分改善。论文附录还主动给出负结果：最终节点选择中，验证分数与测试分数高度相关，偏好模型真正覆盖验证选择时胜率接近随机。
- “先估计廉价验证器尚有多少选择余量，再决定是否调用偏好模型”会归约为多保真优化、最佳臂识别或信息价值式选择性路由；当前 Run v107、v111 与 v119 已覆盖预算分配、门控候选和验证约束搜索。

## 跨上下文证据传输

- [Local verification cannot detect non-transportability](https://arxiv.org/abs/2608.11252) 把上下文覆盖表示为神经，证据表示为一阶上链，证明路径无关当且仅当证据精确，并以第一上同调的完整性刻画不同有效路径的分歧。
- 论文不只提出现象，还直接给出 Kṣetra：余边界投影、霍奇分解、谐和能量弃答、冲突三分处理和细化覆盖的数据收集指令；并在两个结构不同领域共 2,400 次模拟中与总残差门控比较。因而“从局部核验升级为闭环一致性”已经是完整直接方法。

## 结论

本版没有幸存候选。记忆、事务和不可约冲突是精确 Run 重复；自指不稳定只支持测量复核；量表归纳、策略条件优势、科研候选选择和全局证据传输均由目标论文自身完成。未注册本地实验。
