# v100 选择上下文

facts-only 主动诊断显示，99 个既有科学版本中记录级尝试为 13 次、正式/评审支持尝试为 3 次，而最近版本再次集中于先行工作审计。这一事实促使主研究者把优先级从“继续命名相邻方法”转为“寻找 Run 内尚未处理的可干预状态”，但诊断没有替代科研裁决。

本版本依次审计不确定副作用、局部观察完备性、含噪选择和证据顺序/停止。前两条是 v008/v010 等版本的直接重复；第三条被 2026 年选择后大语言模型评测协议及 v020/v055 吸收；第四条既受 v005 零效应约束，又被顺序信念修订、长搜索诊断和有损块顺序优化包围。

因此 v100 不用低信息量实验制造“有进展”的外观，也不把百版本或连续碰撞解释为 Run 终局。当前关闭范围仅限上述四条结构残余；Run 保持 `ACTIVE`，v101 必须更换分析单位或贡献形态，并继续要求公开材料与本地可执行杀手检验同时存在。
