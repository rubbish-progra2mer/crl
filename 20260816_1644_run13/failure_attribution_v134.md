# v134 失败归因

## 类型

`SOCIAL_INTERACTION_FRONTIERS_CLOSED_BY_DIRECT_TRAINING_SIGNAL_ADMISSION_AND_SELECTIVE_COMPUTE`

## 直接原因

- 委托协商、跨域迁移排序和剩余差距蒸馏由 SocialRL 直接实现；
- 无关相似性诱导合作虽是强现象，但相关性修复归约为有效信号准入与机制破坏对照；
- 抵抗—接受前沿的唯一可能越界依赖可推导性，归约为选择性推理路由；
- 策略译码器敏感性已由目标论文的第二译码器重跑直接测量，并与 Run 内执行语义差分重合。

## 非原因

- 不是科研反证：没有注册或运行实验；
- 不是现象不存在：无关相似性诱导合作、错误同伴压力和译码器敏感性都保留为实证现象；
- 不是 v029 宿主安全边界造成；
- 不是 Run 终局。

## 决定

关闭 v134 的协商训练、相似性准入、反从众路由和策略译码器执行线。Run 保持 `ACTIVE`，下一版先做 facts-only 轨迹诊断，再转向结构不同的 frontier。
