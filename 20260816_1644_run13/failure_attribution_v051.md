# v051 失败归因

## 类型

`KILLED_BY_DIRECT_PRIOR_AND_RUN_COLLISION`

## 直接证据

- MCPWorld 仅把两类工具并集交给模型，没有显式路由，因此它只提供现象和评测入口。
- ToolCUA 已直接优化图形界面—工具切换点和轨迹级路径，并用下一状态截图落地工具效应。
- EE-MCP 已把模态互补建模为混合策略学习。
- ToolGate 已用后置条件决定工具结果能否写入可信状态。

## 归因

步骤路由发生精确方法碰撞；跨表面核验的“另一表面”只替换了后置条件的观测通道，没有改变提交门控计算。v012、v034 的 Run 内负面记忆进一步消除了把它包装成新状态协议的空间。

## 杀伤范围

杀死图形界面—程序接口路由、切换点学习和双表面后置条件门控作为独立方法候选；不否定混合计算机使用基准或其他不依赖路径选择/提交验证的新机制。
