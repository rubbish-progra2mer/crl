# v108 研究地图

## 查询量词与分页停止

- 初始现象是：同一个分页结果中的 `has_more` / `next_token`，对“返回任一项”“返回前 K 项”和“返回全部项”应产生不同停止义务；模型可能把当前页满足条件误写成全局完成。
- Run v010 已精确定义“当前页没有匹配项不能推出全局不存在”，并以自动分页、查询完备性、部分闭世界语义和覆盖义务关闭该方向。将存在量词、前 K 或全称量词加入停止条件只是在同一查询完备性计算上实例化目标谓词。
- 因而该候选与 v010 是同一失败族，不重复调用模型验证。

## 失败链污染与模型升级

- 初始现象是：弱模型失败后把完整推理链交给强模型，可能造成锚定；只移交问题、已核实事实和失败类型可能优于完整转发。
- [Not All Tokens Are Equal: Inflation-Aware Routing for Agentic LLM Systems](https://arxiv.org/abs/2608.13571) 已提出丢弃失败链后再升级的 `fresh-escalation`，并报告把失败链转发给更强模型会显著降低准确率。
- 因而“净化后移交”最多是对直接策略增加字段筛选，无法独立形成新计算。

## 事务原子性与安全失败

- [Agentic Transaction: Towards ACID-Compliant Agent Systems](https://arxiv.org/abs/2608.13900) 已把语义原子性、一致性、隔离性和持久性定义为智能体事务保证，并给出探索—执行—验证循环与事务状态管理。
- [LegacyWorld: Atomicity-Aware Evaluation of GUI Agents for Legacy Workflows](https://arxiv.org/abs/2608.14131) 已把成功完成、安全失败和非原子副作用区分为不同运行画像，并用初态、目标态和任务验证器评价持久化副作用。
- Run v034、v068、v071 和 v075 又已覆盖副作用、环境外部性、补偿与清理义务。为多工具工作流增加提交/回滚边界没有剩余方法差分。

## 话语作用域与长期记忆准入

- 初始现象是：长期记忆可能把“如果我住在上海”“同事喜欢爵士乐”“我不喜欢辣食”或引用中的陈述都压平成关于用户的正事实。候选计算会在写入前保持说话人、否定、模态/假设、来源跨度和断言状态。
- Run v092 已记录 Hindsight 的世界、经验、观察和意见逻辑网络，以及写入准入、记忆污染和来源治理；v045 已关闭当前意图与记忆可用性过滤。
- [TrajWiki](https://arxiv.org/abs/2608.00967) 已将记忆组织为来源锚定的演化轨迹、不可变快照和逐声明的新增/修订/废弃操作，并能回到源消息合成答案。
- [RECON](https://arxiv.org/abs/2607.16716) 已直接评价来源冲突、级联失效、反事实推理和时间约束；[ReFind](https://arxiv.org/abs/2608.12888) 进一步表明智能体可直接检索未改写的聊天记录并从收集证据回答。
- 把话语作用域字段加入这些来源锚定/类型化记忆，只得到自然语言事实抽取的元数据增强；若保留源消息并做查询时蕴含判断，又落回源记录回查。该候选不能支持新的智能体方法声明。

## 其他邻近入口

- [Act2Intention](https://arxiv.org/abs/2608.14132) 已覆盖从连续图形界面动作理解、预测并执行用户意图，因此“把非命令动作当作隐式请求”不作为下一版本候选。

## 结论

四个主入口均在实验前被 Run 内精确重复或直接先行计算关闭。v108 不注册实验或 Seed；下一版本不继续分页、升级、事务或记忆字段变体，而从尚未被这些状态原语表达的良性跨模型现象重新构造探针。
