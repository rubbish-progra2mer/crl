# v004 正式实验结果

## 尝试身份

`attempt-corpus-001` 因 Windows 默认编码读取官方 telecom 策略文件失败，退出码 1，无输出，证据/输出契约未通过，不支撑结论。`attempt-corpus-002` 切换为 UTF-8 后成功，但输入仍指向含大量第三方临时文件的 Git 副本，故被卫生重绑定取代。`attempt-corpus-003` 使用同字节 telecom 数据与 LF 规范化评价文档成功重建，语料 SHA-256 为 `58382bf30a30bb2ead059ebf390da2b4be065e79da09ea15b9f1032bf1ccb310`。`attempt-core-002` 的结果 SHA-256 为 `e6c9ef3e39ca157df7fe7514025c374e9d6464a1f07be19af948de550453d4ce`，与先前核心尝试逐字节相同。最终两个支撑尝试退出码均为 0、未超时、证据与输出契约均通过。

## 独立外部数据

telecom 语料来自官方 tau2-bench v1.0.1 提交 `363133ada1936491fb5bcec33cd62c3518a99f65`。方法、必选锚点、对照和失败条件在运行 telecom 前冻结。构建器执行每个变体后，仅以参考动作终态的智能体数据库与用户数据库双散列给实际标签，不导入 v004 评估器。

语料共 94 个含写任务。74 个任务同时具备训练正确、训练有害、保留正确和保留有害类别，形成公平分母 103 条保留正确轨迹与 148 条保留有害轨迹；20 个任务不满足双类条件而不进入主评估。

## 主要比较

- 无约束精确最小化：部署 74/74，正确接受 95/103（92.23%），有害误接受 6/148（4.05%）。45 个任务选择调用总数，29 个选择变更数量。
- 只允许语义特征但不强制锚点：部署 74/74，正确接受 103/103（100%），有害误接受 6/148（4.05%）。全部选择变更数量。
- v004 语义效果锚点：部署 74/74，正确接受 103/103（100%），有害误接受 0/148（0%）。全部选择变更路径—终值摘要。
- 完整终态双散列上界：103/103 与 0/148。
- 同信息通用锚点强基线：与候选逐字段结果相同，103/103 与 0/148。

声明成本只用于固定策略内部选择，不是运行时间或存储测量；不据此提出性能主张。

## 不变性审计

103 个官方终态正确保留变体与参考轨迹比较：写次数变化 35 次、写名称变化 103 次、写参数摘要变化 103 次、总调用数变化 35 次、调用名称变化 103 次。变更数量、变更路径、变更路径—终值摘要和终态双散列的变化次数均为 0。这支持“轨迹语法量不尊重终态语义商”的解释。

## 开发回归

airline/retail 已参与锚点选择，只算开发回归。候选接受 261/261 条正确轨迹并接受 0/196 条有害轨迹；v003 的两个有害误接受均被拒绝。

## 负对照

每类 2,000 例中，效果帧漏掉附带变化与执行层伪造已接受摘要的运行时绕过率均为 100%。若碰撞有害报告已在编译时声明，部署拒绝率为 100%。并发修订下，不比较修订号的旧事实沿用率为 100%，同修订比较后使用降为 0%，正常接受率为 100%。

## 解释与限制

独立 telecom 结果支持一个窄的表示层主张：观测综合若不先对任务终态等价关系取商，就会让精确最小化器选择伪轨迹特征；只排除语法量仍不足，必须保留完整效果身份锚点。它不支持新的集合覆盖、事务、散列、变化捕获或密码学算法，也不支持端到端安全或性能收益。正式结论依赖效果帧完整、适配器真实、SHA-256 抗碰撞与修订比较后使用；telecom 仍是确定性变体而非生产轨迹。
