# 研究种子 v004：语义效果锚定的轨迹商观测证书

## 一句话结论

工具型大语言模型智能体的运行时观测器不能只在有限训练轨迹上做成本最小化；它必须先按任务终态语义对轨迹取商，排除不保持该等价关系的调用语法特征，并强制一个覆盖完整声明效果帧的变更身份锚点。否则即使使用精确最优选择器，也会同时误拒终态正确轨迹和误接受未知有害轨迹。

## 研究问题

现有工具监控常把调用名称、参数、次数、读取/写入顺序和局部状态摘要混成一个候选特征库，再寻找能区分“正常/异常”样本的便宜子集。该做法隐含假设：训练集中最便宜的区分量也尊重真实任务语义。

tau2-bench 的官方语义给出反例：其动作列表只是一条参考解，任何产生等价数据库终态的工具序列都应通过。幂等重复、读取重排或写入顺序变化可能改变轨迹语法，却不改变正确性。相反，两个不同终态可能拥有相同调用数或相同变更叶数量。

因此问题不是“如何更精确地求集合覆盖”，而是“什么观测有资格进入优化器”。

## 方法核

设任务初态为 `s0`，执行轨迹为 `τ`，声明效果帧上的终态为 `F(s0, τ)`。定义轨迹等价关系：

`τ1 ~F τ2` 当且仅当 `F(s0, τ1) = F(s0, τ2)`。

候选使用三道门：

1. **轨迹商不变性门**：只有能写成 `g(s0, F(s0, τ))` 的观测才可进入可信事实身份。调用次数、调用名称和写参数序列被排除，因为它们可在同一等价类内变化。
2. **效果身份门**：部署观测必须包含 `D_F(τ)`。它把完整声明效果帧内所有发生变化的叶路径与终值规范化排序，再计算 SHA-256 摘要。变更数量和路径集合可以辅助，但不能替代终值身份。
3. **修订门**：`(D_F, trusted facts)` 与见证修订 `r` 绑定；消费者只有在当前修订仍为 `r` 时才能比较后使用。

编译时从正确轨迹登记允许的效果摘要签名。若任一已声明有害轨迹与正确轨迹在强制锚点上碰撞，编译器拒绝部署。可选语义观测仍可按一般可诊断性或精确集合覆盖选择，但优化器不是贡献。

## 与 v003 的真正计算差异

v003 允许全部轨迹/终态特征进入精确最小化，因而在外部数据上经常选择写参数摘要、调用总数或变更数量。v004 在优化之前增加静态表示门，并把完整变更终值摘要从“可选昂贵量”改为“必选身份量”。这改变了部署计算，而不只是改写解释：telecom 中无约束方法选择调用总数或变更数量，v004 在全部 74 个可评估任务选择变更值摘要。

## 可证伪主张

### 主张 A：表示失效

在官方终态语义任务上，有限训练可分离与精确成本最优不足以保证未见轨迹正确性。冻结 telecom 结果中，无约束精确方法接受 95/103 条正确轨迹并误接受 6/148 条有害轨迹；精确求解没有避免表示伪相关。

### 主张 B：锚点修复的独立对应

在方法冻结前未查看结果的 telecom 域中，强制完整效果摘要的候选在 74 个可评估任务上接受 103/103 条官方终态正确保留轨迹，接受 0/148 条官方终态有害保留轨迹。仅使用语义特征但允许选择粗粒度变更数量时仍误接受 6/148，说明决定性因素是效果身份锚点而非“语义”标签。

### 主张 C：条件性而非端到端安全

若效果帧漏字段或摘要可由执行层伪造，候选在负对照中 100% 被绕过。正式保证只在效果适配器完整、真实、散列抗碰撞且修订比较后使用的前提下成立。该方法不检测未进入效果帧的变化，也不证明权限、意图或自然语言通信正确。

## 实验证据

独立 telecom 语料由官方环境执行 94 个含写任务的参考轨迹与确定性变体，标签仅比较参考终态和变体终态的智能体数据库/用户数据库双散列。构建器不导入评估器；方法和失败条件在 telecom 运行前冻结。

74 个任务具有完整训练/保留双类，形成统一分母 103 条正确与 148 条有害轨迹：

| 方法 | 正确接受率 | 有害误接受率 |
|---|---:|---:|
| 无约束精确最小化 | 92.23% | 4.05% |
| 语义精确最小化、无强制锚点 | 100% | 4.05% |
| v004 效果锚点 | 100% | 0% |
| 完整终态双散列上界 | 100% | 0% |
| 同信息通用锚点基线 | 100% | 0% |

103 个正确变体的不变性审计中，写名称和写参数摘要各变化 103 次，调用总数变化 35 次；四个终态语义量变化 0 次。开发集 airline/retail 上，锚点还修复了 v003 的全部 261 条正确轨迹与 196 条有害轨迹回归，但该部分不算独立验证。

## 公平基线与贡献上界

拥有相同效果摘要、同一允许签名和相同修订规则的通用强基线与候选结果完全相同。精确子集枚举、加权集合覆盖、SHA-256、状态差分、后置条件和事务提交都不是新算法。

最近的 Cordon 已给出任务级语义事务、执行投影不可区分性和效果边界完整性；ToolGate 已验证后置条件后再更新可信状态；一般可诊断性研究已综合最小成本观测；执行证明已更强地处理签名、散列、效果和重放真实性。

所以本种子的贡献上界很窄：把“任务终态等价类不变性”作为智能体观测综合的显式前置类型约束，并用独立跨域反例证明缺少这一约束会使精确最小化器学到伪轨迹特征。它是值得扩大验证的表示层方法种子，不是完整安全系统或成熟论文主张。

## 最大剩余风险

- telecom 变体是确定性扰动，不是生产轨迹或主动攻击者生成轨迹。
- 当前摘要由完整初态/终态差分计算，没有真实变化数据捕获适配器，也没有延迟、吞吐或存储测量。
- 终态数据库任务天然适合效果摘要；对外部消息、文件发布、权限委派和不可逆网络效果，完整效果帧更难定义。
- SHA-256 只处理碰撞风险，不提供来源真实性；需要独立执行器、签名、可信日志或执行证明。
- 20/94 个 telecom 任务缺少公平双类保留条件，没有进入主分母。
- 终态相同不代表过程安全。若策略要求禁止读取秘密、限制中间外发或满足调用顺序，必须把这些语义效果/策略事实显式纳入效果帧，不能被终态商抹掉。

## 下一步决定性实验

1. 在至少两个真实变化数据捕获后端实现完整效果适配器，分别注入漏字段、乱序、重复、伪造和跨后端部分提交。
2. 将效果帧扩展到数据库状态、文件写入和待发网络消息的联合事务，测试同终态但过程违规的反例是否被显式策略事实区分。
3. 与 Cordon 风格完整事务记录、ToolGate 风格逐工具后置条件和执行证明风格真实性绑定做同能力比较，而不是弱化基线。
4. 在未参与方法设计的生产或人工审计轨迹上评估正确等价类覆盖、未知有害效果拒绝、适配器成本和拒绝服务风险。

若这些实验显示强制摘要只是在完整事务记录外再套一层散列、没有降低验证复杂度或提高跨工具可迁移性，则该种子应被 Cordon 与一般可诊断性综合吸收并停止扩展。
