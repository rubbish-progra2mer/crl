# 同轮研究记忆 v001

## 当前假设与证据

- 假设：返回体契约无法证明持久效果。支持：ToolGate 的契约定义及缺失响应模式时 `Q=True` 的原文；模拟中所有错误返回均通过返回契约。
- 假设：按调用标识读取只是必要信息，不足以替代充分性谓词。支持：同信息弱见证仍错误接受全部重复与带标识旁路故障，整体错误提交率 33.05%。
- 假设：变异覆盖可把效果见证从“正样例检查”变成缺陷区分器。支持：候选在 46,226 个主失败终态上 0 错误接受，同时正常接受率 100%。

## 已复现反证棘轮

- 伪造读取面：1,200/1,200 错误通过。
- 未标记旁路污染：1,200/1,200 错误通过。
- 处置：两者已收缩为外部信任前提，Seed 不得再使用无条件保证语言。后续版本若继续，必须把这两项保留为回归/边界对照，除非方法范围实质改变。

## 若假设错误会影响什么

- 若真实工具无法提供完整调用关联索引，候选退化为需要新基础设施的设计，而非可直接包裹现有 API 的通用方法。
- 若真实并发与最终一致性导致高误拒绝，需加入稳定性窗口、版本租约或有界重读；当前结果不能推断可用性。
- 若最近工作已包含“按调用标识读取当前效果 + 变异充分性编译”，新颖性上界将显著下降，可能需要 No-Go 或转向任务级组合见证。

## 下一项最高信息量实验

在 tau2-bench 或 AppWorld 的真实状态工具上，为可写动作人工提供少量效果模板，比较目标终值读取、弱调用见证和编译见证的错误提交/误拒绝与额外调用成本；同时保留伪造读取与未标记旁路负对照。
