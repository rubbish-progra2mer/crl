# v003 运行内记忆

## 已确认事实

- 有限语义空间含 6 条正确轨迹、3,990 条有害轨迹和 11 个观测特征；全部 2,048 个观测子集已经穷举。
- 72 个子集可分离，1,976 个不可分离；编译器对不可分离子集拒绝部署，可分离子集中的危险部署数为 0。
- 单参考轨迹只接受 1/6 正确轨迹；语言证书接受 6/6，且接受 0/3,990 有害轨迹。
- 精确优化在完整特征配置下成本为 7/18；贪心算法只在 12/72 个可分离配置上达到同成本，最坏成本比为 1.5714。
- 通用精确加权集合覆盖与候选优化完全相同，算法新颖性为零。
- 外部语料来自官方 tau2-bench 提交 `363133ada1936491fb5bcec33cd62c3518a99f65`，共 130 个含写操作任务；构建器仅按参考终态的双数据库散列标注。
- 外部评估中 114 个任务满足双类训练与双类保留条件。261 条保留集正确轨迹接受率为 88.51%，196 条保留集有害轨迹误接受率为 1.02%（2 条）。
- 主要误拒来自编译器选择写参数摘要或调用次数：官方终态正确的幂等重复、顺序变体和读取重复被当作语法上不同。两条误接受分别来自参数扰动和写顺序反转。
- 2,000 个修订模拟中，不绑定修订的旧事实在并发变更用例中 100% 被错误沿用；比较后使用协议把该比例降为 0%，正常接受率为 100%。这只是协议回归，不是开放系统证明。

## 反证棘轮

v003 的外部失败必须在后续版本中继承。下一版不得通过删除失败任务、重命名分母或把保留变体移入训练集来消除它；必须让方法范围实质改变，使观测对官方终态语义等价类保持不变，并保留两个有害误接受作为回归用例。

## 下一版方向

把候选特征分成“终态语义不变量”和“轨迹语法量”。证书只允许从前者选择，并要求至少包含能够绑定目标效果身份的语义锚点。与拥有相同语义观测和成本预算的通用强基线公平比较；若修复退化为完整终态散列且没有可辩护的方法变化，则应考虑当前 Run 无交付收口。
