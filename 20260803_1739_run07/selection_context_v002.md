# v002 选择上下文

## 可选路线

1. 只给 v001 加未声明字段检查，然后继续声称运行时见证优于基线；该路线会被人工完整后置条件直接吸收，淘汰。
2. 把完整模板、可信谱系、稳定读取全部列为前提，保留固定精确检查；这是合理工程方案，但没有清晰的方法问题，淘汰为主要候选。
3. 把研究对象改为“观察接口与验证器是否足以区分有害轨迹”，输出不可见证反例、区分证书和低成本投影；该路线直接回应三审反例和公平基线，选为 v002。
4. 当前直接无交付终止；由于 v002 存在可证伪的编译目标并已在正式实验中显示安全—覆盖权衡，暂不选择。

## 选择理由

v002 不试图赢过知道完整真值的人工专家，而把人工专家容易遗漏且读取接口可能根本无法表达的问题变成机器可检查条件。正式实验同时出现：危险配置被拒绝、经验安全配置的保守误拒绝、完整人工基线持平。这三项共同构成了可继续扩大的研究问题，而不是只展示完美分数。

## 当前去留风险

- 一般程序变异与可观测性分析可能已经包含同构编译；
- 权威闭世界效果规格的成本可能高于方法收益；
- 完整、不可伪造谱系可能需要 Cordon 级基础设施，使候选只剩很薄的静态审计层；
- 抽象变异与隐藏故障仍概念同源，必须由独立缺陷来源攻击；
- 35% 左右的经验安全配置被保守拒绝，实际工具覆盖可能不足。
