# 最近先行科研解释

> 本文件属于主研究者解释，可在阅读候选、PDF、Evidence 和实验后继续修订；它不进入机器事实快照哈希。

- 审计标识：`prior-001`
- 碰撞类型：`ANALOGICAL_REDUCTION`

另有方法级部分重合，不能宣称“首次用反事实扰动测工具影响”。

## 真正的 nearest prior

1. Giloni 等，**CAIR: Counterfactual-based Agent Influence Ranker for Agentic AI Workflows**，EMNLP 2025。CAIR 逐个替换多智能体工作流中间智能体的输出，重放后用最终输出嵌入距离和工作流编辑距离估计影响力。它已经占据“扰动中间生成物并观察终局变化”的一般计算谱系。
2. Meng，**Policy-Conditioned Counterfactual Credit for Verifiable Reinforcement Learning of Long-Horizon Language Agents**，arXiv:2606.05263（2026 预印本）。其反事实贡献估计显式包含工具输出扰动，并以可验证终局奖励训练长程智能体；这是当前最接近的方法级风险。
3. Gupta，**ReliabilityBench: Evaluating LLM Agent Reliability Under Production-Like Stress Conditions**，arXiv:2601.06112（2026 预印本）。它把变形测试用于智能体评价，以等价任务扰动和终态等价定义行动变形关系，并注入部分响应、模式漂移等工具故障。
4. 共享知识库中的 P039（ToolFailBench）、P040（False Success）、P074（ToolGate）、P097（ReLoop）与 P099（Verus-SpecGym）分别占据结果忽略分类、环境终态真值、工具后条件、领域行为扰动及双向可执行规格测试。

## 实质组件重合

- 与 CAIR 重合：黑盒中间输出干预、重复执行、比较终局响应；因此不能把“反事实影响”本身作为贡献。
- 与 CVT-RL 重合：工具输出扰动、反事实贡献语义；因此不能把“工具结果的因果贡献”作为未经限定的新方法主张。
- 与 ReliabilityBench 重合：无完整文本真值时用执行间关系作评价；因此一般“智能体变形测试”已经被占据。
- 与 P039/P040 重合：要诊断调用后忽略和虚假成功；问题本身并非新发现。

## 仍存贡献增量

当前只保留一个窄增量，尚待实验：**不是测某个中间输出有没有影响，而是用相关字段应变 + 无关字段应不变的双向关系，测这种影响是否与任务语义方向一致。**

- CAIR 的终局嵌入变化只能给出影响大小；一个无关字段驱动答案大幅变化也会被视为高影响，无法判定“正确采用”。
- CVT-RL 需要可验证终局奖励来估计训练信用；H001 试图只依赖字段级变形关系，不使用完整答案真值，也不训练模型。
- ReliabilityBench 扰动用户任务并要求终态等价，主要测输入鲁棒性和故障容忍；H001 固定任务与工具模式，直接干预工具返回中的相关/无关字段，测证据进入最终回答的因果对齐。
- 双向联合是必要限定：只有相关应变会把普遍不稳定或显著字符串复制误判为采用；只有无关不变会把始终输出同一答案的忽略策略误判为可靠。

若上述差异不能在公平组合基线上带来额外可辨识性，H001 即被 `CONSTRUCTIVE_COMPOSITE` 吸收。

## 最危险替代解释

1. 回答变化只是字符串复制，不代表任务推理。
2. 采样噪声或提示位置效应同时制造相关应变和无关变化。
3. 人工声明的“无关字段”实际上通过语义歧义影响任务。
4. CAIR 式输出距离加字段引用覆盖率已能达到相同诊断能力。
5. 用完整答案真值训练或筛选变形关系，暗中破坏“不依赖完整真值”的边界。

## 最小区分实验

构造具有已知信息流的工具返回和三类策略（真实采用、结果忽略、无关字段依赖），在确定性策略与至少两个真实本地模型上比较：

1. 单次最终答案；
2. 工具字段引用覆盖率；
3. CAIR 式任意输出变化；
4. 仅相关字段应变；
5. 相关应变 + 无关不变的双向关系。

必须另做完全相同输入的重复重放估计采样噪声，并交换字段顺序、表面 token 与干预方向。杀手条件是：双向关系对已知错误类型的区分不稳定，或相对第 2/3 项没有实质增量。

## 方法死亡后仍存现象

即使 H001 的评价计算被组合基线吸收，“工具结果已被调用但未被语义正确采用”仍是 P039/P040 支持的现象；可转向寻找该现象在结构化多字段返回、长上下文或冲突证据下的稳定边界，而不是保留虚假方法新颖性。

## 背景与身份未解决项

- `prior-001` 的 Semantic Scholar 路线因 HTTP 429 降级，arXiv 原始查询噪声较高；其 machine-owned 快照不能单独支持无碰撞结论。
- CAIR 为正式 EMNLP 2025 论文；CVT-RL、ReliabilityBench 为 2026 arXiv 预印本，均需在任何交付前核对 PDF、代码和版本身份。
- 当前没有证据表明“双向字段关系”已被直接占据，也没有证据证明它足够新或有效；结论保持未决。
