# v011 三路线主研究者裁决

- 日期：2026-08-13
- 科学版本：v011
- 权威：主研究者裁决；Research Subagent 报告仅为非权威输入。
- 结论：三条路线均在实现前死亡；不构成 Run 终局，继续正交扩张。

## 1. 跨应用实体绑定

原始计算是：解析用户提及到外部实体，携带来源证据跨步骤传播，在副作用工具调用前验证目标并在歧义时澄清。

该外层计算已被 *Entity Binding Failures in Tool-Augmented Agents*（arXiv:2606.30531）的解析前置条件、候选比较、置信门控、来源记录与澄清直接覆盖；PACT（arXiv:2605.11039）已提供参数语义角色、跨步值来源与作用域解除证书；IGAC（arXiv:2606.22916）已提供请求到资源/效果边界、提交前载荷一致性与状态见证。跨数据库实体解析、记录链接和带来源的实体修复又占据身份连接本体。

子智能体提出的最窄残余“来源折叠、不可循环的跨命名空间身份连接证明”不予保留，原因有二：

1. 若上游根关系不可见，则同一字段集合可来自一个复制根或多个独立根，证明标签不可识别，直接触发 v009 的反复活规则；
2. 若系统额外获得可审计上游根与派生关系，则计算退化为带数据来源约束的经典实体解析，再接 PACT/IGAC 门控，没有新的不可约算子。

故整条路线状态为 `source_occupied_and_anti_revival_blocked`，不注册候选，不运行 AppWorld 身份扰动实验。

## 2. 目的绑定的多跳授权流

原始计算是：把根用户目的编译成可衰减权限，沿子智能体、工具和返回值传播，禁止工具返回扩权，并在最终副作用前验证完整授权链。

Conseca 已覆盖每目的即时策略；Progent 已覆盖任务到工具/参数策略和 SMT 单调收缩；PAuth 已覆盖自然语言任务切片与参数来源包络；AIP/IBCT 已覆盖 MCP/A2A 多跳追加式衰减链、目的上下文与完成块；SEAgent/FORGE 已覆盖多智能体信息流/因果图上的提交前检查；Macaroons、Biscuit 与目的型访问控制提供经典基础。

“委派子图精化证明”也不保留为候选。其计算可逐项拆成 PAuth 的任务程序切片、AIP 的衰减令牌、PAuth/CaMeL 的值来源包络和 FORGE 的因果图约束。若父任务图由语言模型生成，正确性仍依赖未解决的语义预言机；若父图由人工给定，则新增部分只是程序精化检查的应用。

故路线状态为 `source_occupied_by_composite_baseline`，不执行 192 轨迹探针。

## 3. 决策条件化可观测性

候选定义：给定与当前轨迹一致的可能世界集合 `H`、拟议不可逆动作 `a` 和判定 `d_a(h) in {ALLOW,DENY}`，选择带成本只读查询 `q(h)`；仅当剩余版本空间上的 `d_a` 为常数时允许执行，否则继续查询或弃权。

令 `f(h)=d_a(h)`，则该问题精确等价于离散函数求值的最优/近似决策树：

- 无先验、确定性查询：最坏成本函数求值或区分测试；
- 有先验/噪声：等价类判定、EC2/主动分类；
- 查询改变状态或后续可用查询：部分可观测强规划/主动诊断；
- 目标是最小化未来动作不确定性：任务导向主动感知。

智能体侧的外层也已有直接邻居：PolicyGuard 覆盖变更调用前拦截、全轨迹/策略检查和缺失只读调用或下一问题；ToolGate、求解器辅助验证、PCAS 与 SAGE-Agent 分别覆盖契约门、反模型、参考监控和成本化主动澄清。剩余只能是“从工具模式/策略文本学习测试模型 + 经典区分查询”，同时重演 v010 的动作/测试模型学习碰撞。

故路线状态为 `method_level_reduction_collision`，不注册候选，不实现查询合成器。

## 4. 诊断解释与下一步

`workbench_v011/diagnosis/v011-orthogonal-space-audit` 的机器事实显示，FTS Recall 为 `READY`，semantic Recall 因缺少索引为 `DEGRADED`；诊断器没有识别到标准实验条目。Recall 仍索引 AppWorld 隐藏终局目录，因此继续禁止用 Recall 选择任务、构造程序或支持 AppWorld 科学结论。

主研究者解释：v011 的三条路线虽然问题对象不同，但合成都共享“生成图/证书或测试模型，再接提交门”的结构；继续窄化只会回到 v002、v009、v010 的已杀盆地。下一版本必须改变失败对象和干预算子，而不能再以来源传播、证书、图闭包、状态覆盖或提交门作为方法核。

## 5. 反复活条件

- 实体绑定只有在出现不依赖隐藏来源根、且经典实体解析/PACT/IGAC 无法表达的新可观测对象时才可重开。
- 授权流只有在存在 AIP + PAuth/Progent + FORGE 无法表达的系统性攻击族，并有独立终局分离时才可重开。
- 可观测性只有在查询目标不再是可能世界上的决策标签函数，或查询生成不再依赖已知动作/测试模型时才可重开。
- 新基准、新提示、新证书序列化或把同一检查放到 MCP 中间件，均不满足重开条件。
