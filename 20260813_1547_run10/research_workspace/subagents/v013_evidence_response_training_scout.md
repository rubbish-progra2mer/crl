# v013 原生研究子智能体草案：科学智能体的证据响应训练

> 身份与权限：这是 Codex App 原生 Research Subagent 的非权威独立预勘探，只供主研究者裁决。本文没有修改 `hypotheses`、`portfolio`、`Decision` 或 Run 状态，也没有读取其他 Run。检索截止时间为 2026-08-13（Asia/Shanghai）。

## 一、结论先行

**问题真实，但当前“固定前历史与实验，只干预工具结果，再训练置信更新、下一实验与保留/淘汰”的方法核应杀死，不应按现状晋升为 CCF-B 方法种子。**

- **当前裁决：KILL。** 现有定义同时被“已知后验时的组件组合吸收”和“未知似然时的监督标签不可识别”夹死。
- **CONDITIONAL SURVIVE 仅适用于另立的新方法核，不适用于本候选改名复活。** 它必须把最窄不可约计算改成：在未知或失配似然下，从独立可执行实验、重复样本或交换性统计量估计带有限样本覆盖/任意时有效保证的证据强度区间，并在不能保证时输出 `UNKNOWN`；置信更新与动作决策仍交给显式控制器。只有该证据估计算子在留出机制族上越过模拟式推断、顺序 e 值和 MDA，才有条件存活。

真实问题有直接证据：Corral 的大规模诊断报告，科学智能体在 68% 的轨迹中没有吸收证据，只有 26% 出现反证驱动的信念修订；HEP 进一步显示普通规划式智能体没有显式信念更新，而其协议虽能外显假设—测试—证据—信念循环，置信值仍是模型自报而不是统计计算。这说明“实验结果没有正确改变科学策略”值得研究。

但当前候选没有留下独立的新计算。它可以被如下组合逐项重构：

1. **结果成对干预与动作等变训练**：本 Run 的 v003 已经精确提出“固定任务与历史，只改变工具结果；相关变化应改变下游动作，无关变化应保持动作”的成对训练。把下游动作改成“置信值、下一实验、保留/淘汰”仍属于同一计算族。
2. **规范概率更新的蒸馏**：同行评议工作“贝叶斯教学”已经用可精确计算的贝叶斯智能体生成交互轨迹，微调大语言模型去近似概率信念更新，并展示跨任务迁移。候选若拥有已知似然或可执行数据生成过程，就是把该教学信号迁到科学工具结果。
3. **科学假设检验的可验证训练**：Fisher-R1 已用可执行合成数据生成过程、标准分析的数值答案、p 值接近度和拒绝/不拒绝结论训练科学假设检验智能体；POPPER 已用顺序 e 值决定继续试验或拒绝零假设。
4. **显式信念、下一实验与假设池控制**：MDA 直接计算模型/假设后验，以信息价值选择下一实验，并在预测检查失败时扩张假设池；BayesEvolve 也用显式后验和不确定性采集规则选择下一候选。候选把这些输出改为神经策略预测，并不改变决策对象。
5. **信念轨迹训练与科学过程奖励**：EDIT 已用中间后验探针和信念漂移奖励做监督微调加强化学习；Sci-PRM/DataPRM 已训练科学工具结果解释和环境验证的过程奖励模型。
6. **匹配反事实、置信报告与重放**：Resist and Update 已在已知后验的匹配贝叶斯见证基准上，只改变合法证据/禁止压力路径，用交换干预与反事实钳制同时评价答案、置信和保留意见的正确响应；AttriGuard、Causal Agent Replay、AgentCheck 又分别占据反事实观察替换、向前重执行和单工具结果替换回放。

因此当前可诚实描述的 changed computation 只有：

> 用 AttriGuard/CAR/AgentCheck 风格的结果反事实生成科学轨迹对，借用 HEP 的显式信念与生命周期输出，以贝叶斯教学/Fisher-R1/EDIT 式监督或奖励训练 v003 的结果—动作等变关系；下一实验和终止标签由 POPPER/MDA 式统计控制器提供。

这是强组件组合，不是一个新的方法核。

## 二、致命的“已知后验—未知似然”二难

令固定输入为

\[
x=(H,\mathcal H_t,e_t,y_t),
\]

其中 `H` 是当前假设，`\mathcal H_t` 是实验前历史，`e_t` 是已选实验，`y_t` 是此次工具结果。候选要求策略输出

\[
\pi(x)=(p_{t+1}(H),e_{t+1},d_{t+1}),
\]

其中 `d` 是保留、淘汰或继续观察。

### 2.1 若似然已知，标签可直接计算

正确更新需要至少知道先验和结果似然：

\[
p(H\mid y_t,e_t,\mathcal H_t)=
\frac{p(y_t\mid H,e_t,\mathcal H_t)p(H\mid\mathcal H_t)}
{\sum_{H'}p(y_t\mid H',e_t,\mathcal H_t)p(H'\mid\mathcal H_t)}.
\]

如果数据生成过程、候选机制或有效统计检验已知，后验、贝叶斯因子、p/e 值或至少方向和幅度可以由独立程序算出。此时：

- “成对/多值结果”只是训练样本生成方式，对应 v003 的干预等变性；
- “让模型近似更新”对应贝叶斯教学或 BOND 式后验蒸馏；
- “科学数据上的数值与结论奖励”对应 Fisher-R1；
- “下一实验”对应 MDA 的信息价值或经典贝叶斯实验设计；
- “继续/停止”对应 POPPER 的顺序安全检验或标准贝叶斯决策。

训练可以有工程价值或摊还推理价值，但没有出现新的规范计算。

### 2.2 若似然未知，正确幅度不可识别

构造两个对智能体可见输入完全相同的潜在世界，先验均为 `p(H)=0.5`，观察到同一个文本结果 `y`：

- 世界 `W+`：`p(y|H)=0.9`、`p(y|¬H)=0.1`，正确后验为 `0.9`；
- 世界 `W-`：`p(y|H)=0.1`、`p(y|¬H)=0.9`，正确后验为 `0.1`。

若似然模型、可靠性或可执行机制没有进入输入，两世界给出相同的 `(H,历史,实验,结果)`，却要求相反的更新方向和幅度。任何确定性或随机策略都不能同时正确。支持/反证/无信息三类语言标签也不能解决：同一个“显著增加”“未复现”或“无差异”结果的证据强度取决于实验功效、选择机制、噪声、先验、停止规则与多重比较。

下一实验与保留/淘汰更难：后验相同并不决定行动。实验成本、剩余预算、错误淘汰损失、替代假设、可用工具和终局效用不同，最优下一实验与停止决策可以相反。若这些量不在输入中，标签不可识别；若全部进入输入，则回到经典贝叶斯实验设计或部分可观测决策过程。

这不是数据规模不足，而是候选当前问题定义缺少决定标签的可观测量。

## 三、与本 Run 既有路线的边界

### 3.1 v003：直接、方法级精确碰撞

`h-v003-001` 的输入是同一任务、真实工具返回和后续动作；计算是对同一返回做成对干预，相关值变化要求动作按映射变化，无关元数据变化要求动作保持；输出是下游动作约束或执行前选择。当前候选只是：

| v003 | v013 当前候选 |
|---|---|
| 工具结果相关值/无关元数据干预 | 实验结果支持/反证/无信息干预 |
| 下游一般工具动作 | 置信值、下一实验、保留/淘汰动作 |
| 映射等变/无关不变 | 更新方向/幅度等变与策略不变 |
| 轨迹监督或运行时选择 | 监督微调/强化学习 |

v003 已因 AgentCheck、AttriGuard、Causal Agent Replay、ACCORD、返回消费训练和依赖建模共同挤压而判为 `prior_collision`。限定为科学策略输出没有解除反事实等变训练的反复活条件。

### 3.2 v009：问题不同，但“反证实验与停止”不能成为新颖性

v009 的宽路线针对文本主张触发预期证据、竞争假设检索和继续/停止，当前候选针对已经执行的实验工具结果如何改变信念，二者的直接问题不相同。因此不能用 v009 单独杀死当前问题。

但一旦当前候选把输出扩为“下一反证实验、继续或淘汰”，POPPER 的顺序反证、HEP 的生命周期和 MDA 的信息价值设计已经提供更直接的科学邻居；不能把 v009 已淘汰的通用反证义务换成“证据响应”后复活。

### 4.1 组合吸收裁决

主线程要求核对的组合可以逐项完全覆盖候选：

| 候选所需能力 | 已有组件 |
|---|---|
| 明确假设、证据、置信与生命周期 | HEP |
| 固定上下文，只改变允许/禁止的证据路径 | Resist and Update；v003 |
| 生成反事实结果续跑及因果分歧 | AttriGuard / CAR / AgentCheck |
| 用内部后验和结果接地定位训练错误 | EDIT |
| 对科学工具分析提供可验证数值奖励 | Fisher-R1；Sci-PRM/DataPRM |
| 严格继续/拒绝与可选停止 | POPPER |
| 后验、下一实验、假设扩张/淘汰 | MDA / 贝叶斯实验设计 |
| 把规范更新摊还进语言模型 | 贝叶斯教学 / BOND |

当前候选没有指出上述组合无法表达的输入、状态、约束或输出。因此应判为 **HEP + 贝叶斯教学/Fisher-R1/EDIT + v003/反事实重放 + POPPER/MDA 的方法组合**。

## 五、最强公平基线

不能只与普通提示、终局奖励或裸 HEP 比较。至少需要两个同预算强基线。

### 5.1 显式统计控制器基线

`HEP 注册表 + 可执行似然/顺序 e 值/顺序蒙特卡洛 + 信息价值`：

1. HEP 只负责记录假设、证据、置信和生命周期；
2. 对可形式化统计检验使用 POPPER/Fisher 的 p/e 值；对机制模型使用 MDA 的后验；
3. 用信息价值选择下一实验，用预注册损失/阈值做保留、淘汰或继续；
4. 语言模型只翻译自然语言假设、生成候选实验和解释结果，不承担数值更新。

这是最强的正确性基线，因为它不需要学习一个已知公式的近似。

### 5.2 同数据、同模型的摊还训练基线

`贝叶斯教学/Fisher-R1 式训练 + v003 成对结果等变损失 + EDIT/Sci-PRM 奖励`：

- 与候选使用完全相同的结果对、教师标签、基础模型、训练令牌、工具调用和强化学习预算；
- 单轨迹目标学习后验/结论，成对目标只加“相关结果改变、无信息结果不变”的 v003 约束；
- 用同一外部统计程序给数值标签，用同一 HEP Schema 输出三个头；
- AttriGuard/CAR 只作为配对与续跑工具，不另算候选优势。

如果候选无法指出相对这一基线新增的可执行算子，它在实现前已经被定义等价吸收。

## 六、公开可运行基准与独立终局

### 6.1 首选：NeuronBench

[NeuronBench 官方仓库](https://github.com/murphyk/neuronbench) 在审计时 HEAD 为 `c354622458c460b419cab821d482c879f0578377`，MIT 许可，包含确定性/随机神经元世界、预算化干预接口、隐藏真实机制、留出干预预测评价器和纯语言模型参考基线。它不向方法提供真实机制或求解器，也不捆绑似然、粒子滤波、顺序蒙特卡洛或信息价值。

这使它适合做独立终局：训练目标可以是后验与策略，但正式评价使用方法未生成的 `spike_forecast_mse` / `feature_forecast_mse`、实验预算和隐藏干预终局。候选不能靠输出一个看似校准的置信值获得高分，必须让结果响应改善新的实验选择和留出预测。

## 七、最小 killer experiment

### 7.1 零训练的识别性杀手

先构造 64 个匹配实例，每个实例固定自然语言假设、历史、实验和结果文本；成对改变一个隐藏的似然表：

- `W+` 中该结果的贝叶斯因子大于 1；
- `W-` 中同一结果的贝叶斯因子小于 1；
- 再加入贝叶斯因子等于 1 的无信息实例；
- 对下一实验另做成本/信息价值互换，对停止决策另做错误损失互换。

检查候选的数据规范是否把似然、实验功效、成本和损失暴露给策略。

- 若未暴露，同输入要求冲突标签，路线因不可识别直接杀死；
- 若暴露，程序化贝叶斯/信息价值控制器可精确解，候选必须说明为何不是它的蒸馏。

这个检查不需要模型训练，信息量高于先做成对微调。

### 7.2 仅在主研究者坚持重构后执行的最小实证

在 NeuronBench 选择 4 个训练世界、2 个按机制类别完全留出的测试世界；每个训练历史固定当前实验，使用候选机制模拟器生成三类结果（支持当前 MAP、支持竞争机制、低信息/噪声重叠），由独立顺序蒙特卡洛＋信息价值教师生成后验与下一实验。训练相同 7B/8B 基础模型，比较：

1. 普通轨迹监督；
2. HEP 提示/显式注册表；
3. 贝叶斯教学式单轨迹蒸馏；
4. Fisher-R1 式可验证终局奖励；
5. 单轨迹蒸馏＋v003 成对等变约束＋EDIT 式漂移奖励（最强摊还基线）；
6. 显式顺序蒙特卡洛＋信息价值控制器（非语言模型强基线）；
7. 当前候选。

所有方法共享结果对、教师、模型、训练令牌、实验预算和可见工具；测试世界不给真实机制、教师后验或未来结果。评价必须分开：

- 后验：Brier 分数、对数损失、可信区间覆盖、相对独立教师的方向与幅度误差；
- 因果耦合：只钳制报告置信而不改历史时，下一实验/停止动作是否真正随信念改变；
- 决策：下一实验相对精确信息价值的遗憾、无信息结果下的错误动作率、错误淘汰率；
- 独立终局：固定预算后的 NeuronBench 留出干预预测均方误差；
- 成本：每个真实实验、每次语言模型调用、训练与推理总令牌、墙钟时间。

### 7.3 kill 条件

满足任一项就继续杀死当前或重构路线：

1. 候选的数据格式不提供决定正确幅度/行动的似然、成本或损失，却声称有唯一金标。
2. 在同模型、同数据、同预算下，候选不显著优于“贝叶斯教学＋v003＋EDIT/Sci-PRM”强基线，或差异只来自更多教师调用/采样。
3. 报告的置信更校准，但下一实验、淘汰决定或留出干预预测不改善；即 BOND 所揭示的“信念报告可评分、信念—动作耦合仍弱”。
4. 显式顺序蒙特卡洛/POPPER 控制器更准、更便宜或拥有更严格错误控制，候选只近似已有算子。
5. 对训练未见的似然族、噪声模型或机制类别，更新方向/幅度崩溃，收益只来自模板记忆。
6. 无信息结果仍引起大幅置信漂移，或结果双射/无关元数据改变科学动作，说明没有学到证据强度。
7. 正确标签由同一个大语言模型教师自报而不是独立执行/统计终局生成，无法排除同源评价。

## 八、允许的窄重构与其边界

当前候选不建议小修复活。唯一可能值得另立候选的研究对象是：

> **未知或失配似然下，可验证的实验结果证据强度估计与保守弃权**：从可执行实验模型、重复试验或交换性统计量中估计带不确定区间的似然比/e 值；当覆盖不足或模型失配时输出 `UNKNOWN`，而不是强迫语言模型给出置信幅度；再把这个有覆盖保证的证据对象交给显式决策控制器。

这会改变输入和计算：研究重点从“配对结果训练策略响应”转成“如何取得可验证证据强度及其覆盖保证”。它也会立即进入模拟式推断、神经后验估计、顺序安全检验、保形/任意时有效推断和 MDA 的邻域，必须重新做最近先行审计，不能沿用本候选的新颖性。

### 8.1 最窄不可约计算

不是“看到不同结果后给不同答案”，也不是“让置信、下一实验与淘汰标签联合变化”；这些都已可由反事实数据生成、后验蒸馏和显式决策器表达。尚可能不可约的计算只有：

\[
(\text{可执行机制族、重复结果、停止历史})
\longrightarrow
[\underline{\lambda}_t,\overline{\lambda}_t]\ \text{或}\ \texttt{UNKNOWN},
\]

其中区间是对证据强度（如似然比或 e 值）的校准不确定集，且覆盖或任意时有效性质由语言模型之外的独立程序验证。策略只消费这个证据对象；它不负责凭文本猜出“正确后验”。若没有可验证区间、失配检测或弃权，这个重构仍退化为当前已杀路线。

### 8.2 anti-revival 规则

以下改动均不得用于复活当前候选或声称新版本：

1. 仅把“动作等变”重命名为“证据响应”“科学信念对齐”或“反证敏感性”。
2. 仅增加 HEP 注册表、信念草稿、理由文本、支持/反证/无信息三分类或多头输出。
3. 仅把 AttriGuard/CAR/AgentCheck 的回放结果用于监督、偏好学习、过程奖励或一致性损失。
4. 仅用隐藏真实机制直接算后验/信息价值，再蒸馏给语言模型；这属于贝叶斯教学/Fisher-R1/MDA 的摊还实现。
5. 仅报告置信校准或更新方向改善，而没有独立的下一实验遗憾、错误淘汰率和留出机制终局。
6. 仅加入更多合成结果、链式思维、同模型教师、自一致采样或更大模型。
7. 把似然、成本和损失补进提示后仍没有超出显式贝叶斯/顺序检验控制器的新算子。

任何后续版本若命中以上任一项，应引用本负结果直接杀死，不再重复做成对微调实验。

重开至少需要同时满足：

1. 不使用隐藏真实机制、测试终局或同源语言模型自评来给证据强度；
2. 对似然失配、工具噪声和未覆盖结果有可校准的 `UNKNOWN` 或风险界；
3. 在留出机制族上优于同预算的显式贝叶斯/顺序 e 值/模拟式推断基线；
4. 方法贡献落在新的证据估计算子，而不是 HEP Schema、成对数据增强或奖励拼接。
