# Task Boundary

- `boundary_id`: TB-v001-01
- `accepted_task_setting`: 具有两步及以上依赖关系的文本/结构化工具任务；工具可能返回语法有效但语义错误、陈旧、不完整或相互矛盾的结果；智能体必须在有限额外预算内决定是否验证、回滚或继续。
- `rejected_task_setting`: 候选方法可见测试真值或隐藏状态；候选独占额外检索源、工具权限或无限调用预算；错误仅表现为显式异常码；只比较提示措辞且无计算变化；完全依赖人工在线介入。
- `accepted_input_output_scope`: 输入限于任务文本、工具规范、可见动作与工具返回；输出包括普通工具动作及显式验证、回滚、重规划决策。核心指标需包含独立终局成功率、工具预算和错误恢复行为。
- `excluded_subfields`: 具身/视觉智能体、纯模型训练、单轮问答事实核查、纯安全攻防、纯多智能体通信协议。
- `resource_notes`: 首轮优先使用冻结共享知识库和本 Run 可复查检索记录；需要最近工作判定时使用 Run-local Prior Audit 与实时来源。任何本机实验前完整阅读 `CRL_ENVIRONMENT.md`。
