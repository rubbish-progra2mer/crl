# v002 Scratch：带覆盖证书的否定观察

## 结论

这个 Scratch 验证了一个必要语义事实：分页未闭合、权限视图不足、读取失败或新鲜度未建立时，把“未看到”直接解释为“不存在”会过度闭世界化；三值输出可以在这些反例上把错误的 `ABSENT` 降为 `UNKNOWN`。但它没有建立新的方法核，也没有测量智能体终局收益。

当前实现的核心只是人工声明覆盖义务后的规则合取。数据库查询完整性、结果受限接口可回答性与 CROWN-QA 已分别占据“何时缺失可作为否定证据”的语义、规划与证书化任务形式；Verified Tool Calls 又占据在线 `TRUE/FALSE/UNKNOWN` 控制。因而本结果是可复查的语义载体与负结果，不支持把 h-v002-002 提升为候选。

## 执行边界

- 基准：AppWorld 固定提交 `a072b7a86e7c1d5b1d7175659d750ebb9b79f10a`，数据版本 `0.2.0`。
- 数据切分与任务：开发集 `6171bbc_1`；没有读取或使用测试集终局真值。
- 输入给分类器的信息：公开接口文档、具体读取参数、原始响应或错误、人工声明的范围要求。
- 评价对象：单次读取的 `PRESENT / ABSENT / UNKNOWN` 语义，不是多步智能体任务成功率。
- 工件：`coverage_types.py`、`run_scope_probe.py`、`test_coverage_types.py`、`scope_probe_results.json`。
- 机械验证：六个单元测试通过；相关文件通过 `py_compile`。最初一次从错误目录运行 `py_compile` 因找不到相对文件失败，改用绝对路径后成功；最初一次从错误目录调用 AppWorld 因找不到数据失败，改到固定 AppWorld 源码目录后成功。

## 八个真实接口配对观察

| 情形 | 朴素首屏解释 | 覆盖证书输出 | 关键原因 |
|---|---|---|---|
| 首屏存在 | PRESENT | PRESENT | 有正见证 |
| 目标藏在后页，仅读首屏 | ABSENT | UNKNOWN | 分页未闭合 |
| 继续翻页后找到 | ABSENT | PRESENT | 后页正见证 |
| 匿名视图看不到私有项目 | ABSENT | UNKNOWN | 权限视图不足 |
| 正确凭据可见私有项目 | PRESENT | PRESENT | 有正见证 |
| 认证所有者范围已闭合且确实不存在 | ABSENT | ABSENT | 仅支持该凭据、该端点、该时点范围内的否定 |
| 读取错误 | ABSENT 或错误依模型而定 | UNKNOWN | 没有成功观察 |
| 已闭合但写后新鲜度无契约 | ABSENT | UNKNOWN | 新鲜度未建立 |

逐案原始结构化结果见 `scope_probe_results.json`。

## 证明了什么

1. 在这个开发任务的真实 AppWorld 接口上，分页、权限、错误和新鲜度四类覆盖缺口都能被构造成可执行反例。
2. `UNKNOWN` 能阻止至少三类朴素假阴性：首屏截断、权限不可见和读取错误；缺乏新鲜度契约时也能阻止写后过早否定。
3. 同一凭据的闭合读取最多支持“该凭据视图中的不存在”，不能升级为全局世界中的不存在。

## 没有证明什么

1. 没有证明覆盖义务能从任意工具规范自动合成。当前实现需要人工设置权限充分性和新鲜度等条件。
2. 没有证明 `UNKNOWN` 能改善独立程序化终局，也没有与同读取预算的固定穷尽、统一重查、手写验证器或模型自报置信度比较。
3. 没有覆盖真实最终一致性、多租户权限结构、重复页或漏页、非纯读接口、跨端点查询重写等难点。
4. 没有证明四个布尔覆盖标志本身是新计算。

## 最近先行反证与裁决

- Razniewski 与 Nutt（PVLDB 2011）及后继查询完整性工作已形式化可用数据库、理想数据库与何时查询否定可被完整回答。
- Amarilli 与 Benedikt（PODS 2018 / LMCS 2022，arXiv:1810.07822）已经对含分页或限量的结果受限接口判定查询可回答性并合成取回全部答案的计划。
- CROWN-QA（arXiv:2608.04591）把“无正证据且证据完整覆盖查询范围”直接定义为可认证否定，否则为未知，并要求结构化覆盖证书。
- Verified Tool Calls（arXiv:2608.02645）已有在线只读验证与三值控制。

因此，h-v002-002 的当前计算可以被“查询完整性/结果受限可回答性 + 在线三值验证”公平组合基线吸收。若没有无需人工完整性规则的运行时证书编译、不可区分世界推理或新的最小观测求解器，仅保留四项规则不能形成方法论文种子。h-v002-002 应按最近先行碰撞终止；该结论只杀死 v002 局部盆地，不结束 Run。
