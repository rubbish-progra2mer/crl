# v010 广义并发核碰撞裁决

## 被淘汰的宽核

“从并发工具调用抽取读写集、构建冲突图、阻止不可串行化提交并局部重放/补偿”不再作为候选：

- CoAgent/MTPO 已把多智能体共享外部状态、足迹声明、固定串行次序、冲突通知、局部语义修复、Saga 撤销与最终可串行化连接成近乎同题协议。
- Atomix 已提供作用域事务、资源前沿、提交/中止、缓冲副作用与补偿，并在 `tau-bench` 强制同订单并发重叠。
- Verified Concurrency Anomalies 已形式化过时生成、因果级联、工具效果错序和工具注册表幻读，并提供检测/预防实现。
- Cordon、MemTX、SagaLLM 与依赖引导回滚分别占据在线语义沿袭、事务信念提交、补偿和选择性重放。

因此事务、冲突图、可串行化、补偿、局部重放本身均不计作 v010 的新计算。

## 暂存窄核

只审计“无人工足迹时的反事实语义足迹编译”：在隔离快照中对同一工具调用做参数、先验状态和调用次序的配对扰动，从前后状态差分、响应句柄变化和后续可见性变化中归纳资源表达式与 `R/W/CREATE/DELETE/EMIT` 的保守置信集合；在线实例化为具体资源键，并将任何未解析依赖保留为 `UNKNOWN`。其输出只供已有事务协议使用。

若这一计算可由 REST API 有状态测试/依赖推断、CoAgent ToolSmith、Cordon 沿袭或简单代码/日志插桩复现，或无法在未见工具留出上提供高冲突召回，则立即淘汰。
